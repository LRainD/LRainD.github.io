## 关键技术结论

1. **验收脚本 `scripts/check-app-ready.mjs` 当前无法通过**：`typecheck` 阶段全项目 116 个错误，分布在约 20 个**既有**文件中（`src/common/VariantSwitcher.tsx`、`src/common/ThemeShell/types.ts`、`src/themes/antd-new/templates/*`、其他 prototypes 等）。错误码以 TS2604（57 处，JSX 元素无可调用签名）+ TS2724/TS2614（模块导出名不匹配）为主，判断为 antd v6 / lucide-react 升级后未完成的历史迁移问题。**本次新增页面 0 类型错误**。验收脚本在 typecheck 阶段即中止，因此任何页面都无法拿到 READY。

2. **antd v6.5.3 的 Drawer 用 `size` 而非 `width`**（`width` 已废弃）。

3. **本机无法用 agent-browser 自带 Chromium 截图**：内置 Chrome 155 与 macOS 12.5.1 不兼容（`Symbol not found: _objc_claimAutoreleasedReturnValue`）。可用替代方案：
   - 无头截图：`"/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" --headless=new --no-sandbox --disable-gpu --window-size=1680,1050 --virtual-time-budget=8000 --screenshot=out.png <url>`
   - 交互验证：系统 Chrome 启动 `--remote-debugging-port=9222 --no-sandbox --disable-gpu`（必须 `--no-sandbox`，否则沙箱初始化失败），再用 Node 内置 `WebSocket` 直连 CDP；截图须用 `Page.captureScreenshot` + `clip`，**不要用 `Emulation.setDeviceMetricsOverride`**（会导致截图全白）。

4. macOS 无 `timeout` 命令，需改用其它方式限制时长。
