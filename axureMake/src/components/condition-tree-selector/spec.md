# ConditionTreeSelector 组件规格

## 组件概述

资格审查条件项树形选择器，点击后展开树形面板，支持分类浏览和选择。

## Props

| 属性 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| value | string | - | 当前选中的值 |
| onChange | (value: string, treeKey?: string) => void | - | 选中变化回调 |
| placeholder | string | '请选择' | 占位提示文字 |
| treeData | TreeDataNode[] | defaultConditionTreeData | 自定义树形数据 |
| panelMinWidth | number | 320 | 下拉面板最小宽度 |
| expandUp | boolean | true | 是否向上展开面板 |

## 默认树形数据

- 风险信息（未在经营异常企业名单、未在严重违法失信名单、未在失信被执行人名单、未在涉诉限用名单）
- 基础信息（企业名称、统一社会信用代码、注册资本、成立日期、企业类型）
- 业绩信息（类似业绩数量、类似业绩金额）
- 资质证书信息（质量管理体系认证、环境管理体系认证、职业健康安全管理体系认证）
- 荣誉奖项信息（国家级奖项、省级奖项）
- 人员资质信息（注册建造师数量、中级以上职称人员数量）
- 自定义

## 交互说明

- 点击触发器展开/收起面板
- 面板内展示搜索框 + 树形结构
- 点击树节点选中并关闭面板
- 点击外部区域关闭面板
- 支持向上或向下展开面板
