# Breadcrumb 组件规格

## 组件概述

用于页面顶部的面包屑导航。组件只负责按层级渲染文案与分隔符，不负责路由跳转、页面标题或业务数据。

## 文件位置

`src/components/breadcrumb/`

## Props

| 属性 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| items | string[] | - | 面包屑文案，按层级顺序传入，最后一项为当前页 |
| className | string | '' | 自定义样式类名 |

## 视觉与交互

- 容器内边距 `12px 24px`，字号 `12px`，基础文字色 `#6b7280`。
- 分隔符固定为 `>`，左右间距 `8px`，颜色 `#9ca3af`。
- 非末项为链接态：鼠标手型，悬停变色为主色 `var(--color-primary)`，默认兜底 `#1677ff`。
- 末项为当前页：颜色 `#374151`，无悬停效果。
- 文案为空数组时不渲染任何内容。

## 使用示例

```tsx
<Breadcrumb items={['投标/报价管理', '投标/报价列表', '投标/报价详情']} />
```
