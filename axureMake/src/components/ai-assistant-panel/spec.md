# 数字合规官AI悬浮助手组件 (AIAssistantPanel)

## 📋 业务与功能

### 1.1 核心目标
该组件为集采业务系统提供全局常驻的 AI 智能助手与快捷服务入口，由右侧常驻悬浮胶囊和右侧滑出式抽屉对话面板组成。
- **业务定位**：扮演“数字合规官”角色，协助采购管理人员实时识别合规风险、核查流程节点合规性，并提供快捷业务支持通道（联系客服、权限助手、掌上作业）。
- **用户价值**：无缝嵌入采购各业务节点，无需跳离当前操作上下文即可快速唤起风控排查、合规预警问答与会话记录回溯，提升风险识别与合规处置效率。

### 1.2 功能清单
- **常驻悬浮胶囊栏（Side Helper Capsule）**：
  - 数字合规官头像与入口胶囊（点击唤起抽屉对话面板）
  - 快捷服务组合胶囊（联系客服、权限助手、掌上作业三合一入口）
- **滑出式对话抽屉面板（Chat Drawer）**：
  - 支持展开/收起过渡动画，配套半透明遮罩与多触发关闭（点击遮罩/关闭按钮/外部状态控制）
  - 顶部状态区：在线标识、新建会话按钮、历史记录切换按钮
- **多会话管理与历史记录（Session & History）**：
  - 会话新建与自动切换
  - 历史会话列表展示（会话名称、最新消息摘要预览、更新日期）
  - 会话关键词过滤与模糊检索
  - 会话重命名模态弹窗（Modal）
  - 会话删除（保障至少保留一条会话的兜底约束）
- **智能问答与风控预警卡片（Interactive Chat & Risk Warning）**：
  - 用户消息与数字合规官消息流式/结构化展示，自动滚动至底部
  - 预设快捷提问标签（“查看合规风险”、“项目状态查询”）
  - 风险节点交互卡片：树形展开/收起风险流程节点（如采购发起、发布采购公告、报名与资审汇总等）
  - 风险节点点击联动：向外部业务页面通知被点击的节点 key（`onRiskNodeClick`）

### 1.3 交互要点
- **打开/关闭抽屉**：
  - 点击“数字合规官”独立胶囊卡片 → 展开右侧抽屉，遮罩淡入显示，触发 `onOpen` 回调。
  - 点击右上角关闭按钮或背景遮罩 → 收起抽屉，遮罩淡出，触发 `onClose` 回调。
  - 支持受控模式（`isOpen` 外部驱动）与非受控模式（内部自管状态）双模共存。
- **消息发送与智能反馈**：
  - 输入框输入文本后回车或点击发送按钮，即刻追加用户消息。
  - 包含“风险”关键词的消息 → 延迟 500ms 呈现“合规预警节点”树状卡片；其他文本 → 回复合规助手引导说明。
- **预警节点折叠与穿透**：
  - 点击预警主节点卡片（如“采购发起”）可展开/收起子级规则检测列表。
  - 点击具体子项节点（如“编制采购清单”、“发布采购公告”）触发 `onRiskNodeClick(nodeKey)`，方便父级页面联动或跳转。
- **会话管理交互**：
  - 点击“新建会话”生成新会话并自动成为当前激活会话，重置预警节点展开态。
  - 历史记录视图下，点击会话卡片切换上下文并返回对话视图；点击编辑图标弹出重命名弹窗；点击删除图标移除会话。

## 📊 内容规划

### 2.1 信息架构
```
AIAssistantPanel (组件根节点)
├── ai-side-helper (固定定位悬浮胶囊栏)
│   ├── ai-helper-card-officer (数字合规官独立胶囊)
│   │   ├── ai-helper-avatar (形象头像)
│   │   └── ai-helper-text ("数字合规官")
│   └── ai-helper-card-group (快捷操作组合胶囊)
│       ├── ai-helper-group-item ("联系客服")
│       ├── ai-helper-divider (分割线)
│       ├── ai-helper-group-item ("权限助手")
│       ├── ai-helper-divider (分割线)
│       └── ai-helper-group-item ("掌上作业")
├── 抽屉遮罩 (fixed inset-0 bg-black/5)
└── 滑出式对话面板 (fixed right-0 宽度 480px)
    ├── Panel Header (头部操作区)
    │   ├── 标题与在线状态 / 返回按钮
    │   └── 操作按钮组（新建会话、历史记录、关闭）
    ├── Panel Body (主视区)
    │   ├── 对话模式：消息气泡流 / 合规预警节点展开树 / 自动滚动
    │   └── 历史模式：搜索过滤栏 / 会话列表卡片（重命名、删除）
    ├── Panel Footer (输入与快捷提问区，仅对话模式展示)
    │   ├── 文本输入框 + 发送按钮
    │   └── 快捷推荐标签（查看合规风险、项目状态查询等）
    └── Edit Session Modal (修改会话名称模态窗)
```

### 2.2 数据来源与关键字段
- **数据源**：内部状态管理（`chatSessions`、`chatMessages`、`currentSessionId`）+ 外部 Props 联动。
- **关键数据结构**：
  - 会话对象（`Session`）：
    - `id`: `number`，会话唯一标识符（时间戳）
    - `name`: `string`，会话名称（如“新会话 1”）
    - `preview`: `string`，列表摘要预览
    - `messages`: `Message[]`，会话消息列表
    - `timestamp`: `number`，最后更新时间戳
  - 消息对象（`Message`）：
    - `id`: `number`，消息 ID
    - `sender`: `'user' | 'bot'`，发送者身份
    - `type`: `'text' | 'risk-nodes'`，消息类型（普通文本或合规预警节点卡片）
    - `text`: `string`，消息内容

### 2.3 内容示例
- **机器人默认开场白**：`您好，我是您的数字合规官。今天是2026年09月29日，请问有什么可以帮您？您可以询问关于项目的"风险"情况。`
- **兜底问答文本**：`我尚未掌握此信息。作为数字合规官，我主要协助识别与应对数据、隐私及监管相关的合规风险`
- **合规预警节点示例**：
  - 采购发起（已完成 3个子项，预警）：
    - 编制采购清单（已完成）
    - 发布采购公告（检测到 2 项校验规则不通过，预警）
    - 报名与资审汇总（检测到 2 项校验规则不通过，预警）

## 🎨 布局与结构

### 3.1 整体布局
- **悬浮胶囊栏**：
  - 定位：`position: fixed; right: 4px; top: 180px; z-index: 99;`
  - 胶囊宽度：`52px`，全圆角 `border-radius: 26px`，纯白背景带有柔和投影。
  - 数字合规官胶囊内头像规格：`44px × 44px` 圆形头像。
  - 快捷服务胶囊：垂直三项平分，带浅灰色水平细线分割（宽 34px）。
- **抽屉面板容器**：
  - 定位：`position: fixed; top: 0; right: 0; height: 100%; z-index: 1000;`
  - 宽度：固定 `480px`（大屏/桌面端提供充足的风控树展开和多行文本阅读体验）。
  - 过渡效果：`transition-transform duration-300 ease-in-out`（展开为 `translate-x-0`，收起为 `translate-x-full`）。
- **主内容排布**：
  - 垂直 Flex 布局：Header (`px-5 py-4` 高度自适应) + Content (`flex-1 overflow-y-auto p-5`) + Footer (`px-5 pb-5 pt-3 border-t`)。

### 3.2 响应式与层次处理
- **桌面端（≥1200px）**：面板以 480px 固定宽度自右向左滑出，不遮挡主操作视区关键信息，且遮罩透明度适中（`bg-black/5`），保证背景沉浸度。
- **层级管理（Z-Index）**：
  - 悬浮胶囊：`z-index: 99`（浮于普通页面元素之上）
  - 抽屉背景遮罩：`z-index: 999`
  - 抽屉对话面板：`z-index: 1000`
  - 修改会话弹窗：`z-index: 1001`（浮于抽屉面板最上层）

## 🎨 视觉规范

### 4.1 设计规范来源
- **设计规范来源**：主题 `/src/themes/antd-new` + Tailwind CSS
- **设计依据**：遵循集采运营后台整体风格与 Ant Design 企业级设计规范。

### 4.2 自定义设计要点
- **合规主色与强调色**：
  - 品牌与助手蓝：`#3b82f6` / `#1677ff`（用于用户气泡、按钮、在线指示器）
  - 预警/警告橙：`#f97316` / `#ff7d00`（用于合规预警标签、风险节点图标背景）
  - 校验通过绿：`#10b981` / `#52c41a`（CheckCircle 标识）
- **胶囊视觉特征**：
  - 独立胶囊悬浮态：白色背景、圆角胶囊 (`rounded-full`)、悬停时微上浮动效（`transform: translateY(-2px)`）与增强投影。
  - 胶囊文字排版：双行紧凑字样（如“数字/合规官”、“联系/客服”），字体 `11px`，居中对齐。

### 4.3 组件状态定义
- **默认态（Default）**：胶囊稳定吸附于屏幕右侧，抽屉收拢于屏幕右边界外。
- **悬停态（Hover）**：
  - 数字合规官胶囊浮起，阴影扩大。
  - 快捷项目透明度微降至 0.75。
  - 历史会话卡片边框高亮，操作按钮（编辑/删除）呈现对应语义色背景。
- **激活/选中态（Active/Selected）**：
  - 历史记录列表中当前会话浅蓝背景 (`bg-blue-50/50`) 与蓝边框高亮。
- **展开态（Expanded）**：
  - 风险节点点击后平滑展开子级节点清单，指示箭头由向下 (`ChevronDown`) 切换为向上 (`ChevronUp`)。
- **禁用态（Disabled）**：
  - 当仅剩 1 个会话时，删除按钮灰化置灰不可点击，避免数据清空导致面板异常。

## ⚙️ 组件接口与属性 (Props)

### 5.1 属性定义 (Props)

| 属性名称 | 类型 | 必填 | 默认值 | 说明 |
|---------|------|:---:|-------|------|
| `isOpen` | `boolean` | 否 | `undefined` | 外部控制对话框打开与否，不传时内部自动管理状态 |
| `onOpen` | `() => void` | 否 | - | 打开面板/点击合规官头像时的回调通知 |
| `onClose` | `() => void` | 否 | - | 点击关闭按钮或遮罩关闭面板时的回调通知 |
| `onRiskNodeClick` | `(nodeKey: string) => void` | 否 | - | 点击具体合规风险节点时的穿透回调（如 `'list'`, `'announcement'`, `'registration-summary'`） |

### 5.2 暴露事件与节点标识 (Risk Node Keys)

| 节点 Key | 对应流程项 | 说明 |
|---------|-----------|------|
| `'list'` | 编制采购清单 | 已完成状态节点 |
| `'announcement'` | 发布采购公告 | 预警节点（检测到2项校验规则不通过） |
| `'registration-summary'` | 报名与资审汇总 | 预警节点（检测到2项校验规则不通过） |
