# ComplianceModal 规格文档

## 1. 概述
组件主要包含两层逻辑弹窗：
1. **数字合规官检测中** 弹窗：包含动画/流式文字展示大模型及各规则校验过程。
2. **风控预警提醒** 弹窗：在检测完成后自动弹出展示各项合规/风控结果，并提供操作项（反馈、满意度评价、详情查看等）。

## 2. API 规范
- **`ref.current.startFlow()`**: 开始完整的检测流（自动弹出检测中弹窗，在完成后弹出风控预警结果弹窗）。
- **`ref.current.showDetection()`**: 仅展示检测中弹窗。
- **`ref.current.showRiskWarning()`**: 仅展示风控预警结果弹窗。
