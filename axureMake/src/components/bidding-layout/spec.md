# BiddingLayout 投标系统通用布局

投标系统的通用外壳布局，包含顶部导航栏和左侧菜单栏。

## 1. 布局结构

- **顶部导航栏 (Header)**:
  - 左侧：Logo、主导航（寻源工作台/投标工作台）、搜索框
  - 右侧：功能图标（筑共赢、寻源平台等）、用户信息/头像
- **左侧菜单栏 (Sidebar)**:
  - 包含合作、投标、分供、合同等业务模块入口
  - 支持选中状态高亮
- **主内容区 (Main Content)**:
  - 位于右侧，自适应剩余空间

## 2. 组件属性 (Props)

| 属性 | 类型 | 默认值 | 说明 |
| :--- | :--- | :--- | :--- |
| `children` | `React.ReactNode` | - | 页面主体内容 |
| `activeNav` | `'寻源工作台' \| '投标工作台'` | `'投标工作台'` | 顶部主导航选中项 |
| `activeSidebar` | `string` | `'投标'` | 左侧菜单选中项标签 |

## 3. 视觉规范

- **Header 高度**: 56px
- **Sidebar 宽度**: 56px
- **主色调**: `#fa8c16` (云筑蜂王橙)
- **背景色**: `#1a1a1a` (Header), `#ffffff` (Sidebar), `#f5f5f5` (Page)
