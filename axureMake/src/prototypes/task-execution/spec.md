# 检查任务详情页面规格文档

## 1. 页面概述

检查任务详情承载单次自查、互查、稽查任务的检查执行、整改、复核和历史记录查看。页面由“我的任务”操作列进入，并通过 `taskId` 与 `mode` 查询参数恢复当前任务及办理模式。

## 2. 页面结构

- 顶部：面包屑、返回任务列表按钮、页面标题、任务编号和当前状态。
- 任务信息：检查类型、采购项目、合同信息和当前办理事项。
- 检查项处置明细：展示检查项、标准、原始判定、问题原因、整改轮次及当前操作。
- 办理区：检查时填写检查结论；整改时填写整改说明；复核时逐项选择通过或不通过并补充意见。
- 任务流转记录：展示任务派发、检查提交和当前待办等关键业务事件。

## 3. 交互规则

- “检查”用于自查、互查、稽查待处理或进行中任务，可保存草稿并提交检查。
- “整改”用于待处置或复核不通过任务，合同经办人填写整改说明后提交，生成原检查人的复核待办。
- “复核”用于待复核任务，原检查人逐项给出通过或不通过结论。
- “查看”以只读方式展示任务明细与流转记录。

## 4. 视觉规范

- 复用集采工作台布局和 Ant Design 卡片、表格、描述列表、时间轴组件。
- 页面背景使用浅灰，信息模块采用白色卡片；风险和待处置提示使用黄色，状态标签按任务状态展示。
