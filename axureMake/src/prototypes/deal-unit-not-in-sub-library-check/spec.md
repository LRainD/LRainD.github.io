# 成交单位未在本下级库内（规则页迭代）

> 本文档仅记录**本次迭代**的新增内容，供研发评审使用。页面整体结构、左侧规则树、公共配置项、明细表格的公共列等通用能力均由组件 [risk-rule-config-page](file:///Users/liurundong/Desktop/云端演示项目/LRainD.github.io/axureMake/src/components/risk-rule-config-page/index.tsx) 提供，不在本文展开。

## 一、迭代目标

在风控预警中心「规则管理」下新增一条规则页：**校验成交单位是否存在于所选组织范围的库内**，成交单位不在本下级库内时触发预警/拦截。

## 二、规则信息

| 项 | 值 |
|----|----|
| 规则名称 | 成交单位未在本下级库内 |
| 规则说明 | 校验成交单位是否存在于所选组织范围的库内，未在本下级库内将会预警/拦截 |
| 默认开关 | 开 |
| 挂载位置 | 规则树「招投标」分组，默认选中本规则 |
| 规则 key | `deal_unit_library_check` |

## 三、专有配置列（本次迭代重点）

在明细表格公共列之后追加 1 个必填列，将「组织」「范围」合并为一列展示（样式参考「负面分供商清单校验」页的「是否校验组织、范围」列）：

### 1. 组织、范围（合并列）
- 列 key：`orgScope`
- 布局：列内纵向两行，第一行「组织:」+ 控件，第二行「范围:」+ 控件

| 行 | 标签 | 控件 | 数据 / 选项 | 默认值 |
|----|------|------|-------------|--------|
| 1 | 组织 | `TreeSelect` 组织选择树 | 以「中国建筑股份有限公司」为根节点，演示包含四局（第一建设、第二建设、安装工程、建设发展）、二局、三局等下层级组织 | 空 |
| 2 | 范围 | `Select` 下拉单选 | 本级 / 本下级 | 本级 |

- 组织控件交互：`treeCheckable` 树形多选，`showCheckedStrategy=SHOW_PARENT`（选中父节点即代表其下全部子节点）

> 组织 + 范围共同确定「本下级库」的判定范围：系统在所选组织的「本级」或「本级 + 下级」范围内校验成交单位是否存在。

## 四、规则配置项取值

本次迭代沿用组件公共配置项，取值如下（供评审确认）：

| 配置项 | 取值 |
|--------|------|
| 适用组织范围 | 本下级 |
| 下级独立配置 | 不允许 |
| 预警级别 | 中风险 |
| 是否去重 | 不去重 |
| 规则类型 | 合规风险 |

## 五、接入方式

整页复用 `RiskRuleConfigPage`，本次仅传入以下规则差异项：

| Prop | 值 |
|------|----|
| `ruleName` | 成交单位未在本下级库内 |
| `ruleDescription` | 校验成交单位是否存在于所选组织范围的库内，未在本下级库内将会预警/拦截 |
| `defaultRuleEnabled` | `true` |
| `config` | 见上表 |
| `extraColumns` | 组织、范围合并为 1 列（组织选择树 + 本级/本下级） |
| `treeData` | 组件默认规则树 + 「招投标」分组追加本规则 |
| `defaultSelectedRuleKey` | `deal_unit_library_check` |
| `tableScrollX` | `1650` |
