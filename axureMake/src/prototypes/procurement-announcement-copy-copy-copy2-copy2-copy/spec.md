# 编制采购（资格预审）公告 - 智能推荐一键引用

> **文档类型**：PRD（产品需求文档）  
> **适用对象**：产品、研发、测试评审  
> **关联页面**：编制采购（资格预审）公告页

---

## 1. 背景与目标

### 1.1 背景

在「编制采购（资格预审）公告」页面中，系统会基于采购公告内容，通过智能解析向用户推荐：

- **资格审查附件组成**：报名阶段需要供应商上传的附件清单。
- **资格审查条件**：供应商参与投标前必须满足的条件清单。

目前推荐结果以弹窗表格形式展示，用户需要逐行确认后手动引用到下方配置区。当推荐项较多时，操作繁琐且容易遗漏。

### 1.2 目标

在两个智能推荐弹窗中增加**一键引用**能力：

- 用户点击一次按钮，即可将弹窗中所有「可引用」的推荐项批量写入下方对应配置表。
- 被引用后的推荐项在弹窗内自动变为「已设置」状态，避免重复引用。
- 整个过程不破坏原有业务规则，仅作为提升操作效率的前端辅助功能。

### 1.3 用户价值

- 减少重复点击，降低操作成本。
- 降低遗漏推荐项的概率。
- 保持原有审查逻辑不变，不引入新的业务风险。

## 2. 功能范围

| 功能 | 范围 | 说明 |
| --- | --- | --- |

| 智能资审条件推荐弹窗 | ✅ 本次新增 | 弹窗内增加「一键引用」按钮，批量引用到「资格审查条件」表格。 |

| AI 解析标签 | ✅ 本次新增 | 对通过推荐弹窗引用的行，在下方配置表对应行展示「AI 解析」标签，仅前端展示。 |

### 2.2 可复用场景（不在当前页面，但后续沿用）

本次定义的「一键引用」交互与数据规则，同样适用于以下两类资审项推荐弹窗，后续会按相同模式扩展：

- **集中资格预审 - 资审项推荐弹窗**：在集中资格预审流程中，系统向用户推荐资审项后，允许一键引用到资审项配置表。
- **后审场景 - 资审项推荐弹窗**：在后审（资格后审）流程中，系统推荐资审项后，同样支持一键引用到对应配置表。

以上两个场景的页面不在本次原型范围内，但产品规则、按钮位置、状态变化、数据映射逻辑均与本次「智能资审条件推荐弹窗」保持一致。

## 3. 需求详情

### 3.1 触发位置

在两个推荐弹窗的**表格区域右上角、表格上方**放置「一键引用」文字按钮。

- **附件组成弹窗**：按钮位于「附件组成智能推荐」弹窗内容区、推荐表格上方右侧。
- **资审条件弹窗**：按钮位于「资审条件智能推荐」弹窗内容区、「公告解析 / 历史推荐」标签页内、推荐表格上方右侧。

弹窗标题栏保持原样，不新增任何按钮。

### 3.2 可引用与不可引用

推荐弹窗表格的「操作」列会显示两种状态：

| 状态 | 样式 | 是否可被一键引用 |
| --- | --- | --- |
| 引用 | 蓝色，可点击样式 | ✅ 是 |
| 已设置 | 灰色，不可点击样式 | ❌ 否 |

一键引用**只处理状态为「引用」的行**；状态为「已设置」的行保持原样，不参与引用。

### 3.3 点击后的行为

1. 将弹窗内所有「引用」状态的推荐行，按照第 4 节的映射规则生成下方表格的新数据行。
2. 以**追加**方式写入下方对应表格，原有数据保持不变。
3. 弹窗内被引用的行，其状态立即由「引用」变为「已设置」，并切换为灰色不可点击样式。
4. 弹窗保持打开，用户可继续查看或手动关闭。

### 3.4 禁用态

当弹窗内所有推荐行都已为「已设置」（即没有可引用行）时：

- 「一键引用」按钮显示为灰色。
- 按钮不可点击，鼠标悬停为禁用样式。
- 点击无响应。

### 3.5 不打破旧有限制

- 已设置行不会被重复引用。
- 原有「资格审查附件组成」和「资格审查条件」表格的增、删、改、查逻辑保持不变。
- 原有「一键同步资审附件组成」功能保持不变。
- 原有弹窗关闭、标签切换等行为保持不变。

### 3.6 外部快捷入口「或 一键引用」

当智能推荐提示出现时（「智能附件组成推荐，点击查看！」及「智能资审条件推荐，点击查看！」），在「点击查看！」文案右侧追加「或 一键引用」快捷入口：

- **「或」字样式**：黑色文字（`text-gray-900`），与普通说明文案一致，不可点击。
- **「一键引用」样式**：蓝色可点击文字，与弹窗内「一键引用」按钮样式保持一致。
- **点击行为**：
  - 执行与弹窗内「一键引用」完全相同的批量引用逻辑。
  - 将当前所有「引用」状态的推荐行追加写入下方对应配置表。
  - 同步更新弹窗内推荐行状态为「已设置」，下次打开弹窗时显示为已引用。
  - 不主动打开或关闭弹窗，用户可继续在当前页面查看追加结果。
- **禁用态**：当弹窗内已无可引用行时，外部「一键引用」文字变为灰色不可点击，点击无响应。

### 3.7 AI 解析标签

对于通过推荐弹窗一键引用到下方配置表的文件组成项或资审条件项，在其对应行展示「AI 解析」标签：

- **展示位置**：
  - 资格审查附件组成表：挂在「文件项」列对应行的右上角。
  - 资格审查条件表：挂在「资格审查条件项」列对应行的右上角。
- **标签来源**：使用图片 `/assets/picture/image copy.png`，代表该项由 AI 解析推荐并引用。
- **数据规则**：
  - 仅前端当次展示使用，**无需后端保存该标记**。
  - 标记字段（`aiParsed: true`）随前端数据行存在而存在。
  - 当用户删除对应行数据时，该标记随数据行一并消失。
  - 当用户修改行的关键字段（资格审查附件组成表的「文件项」「文件项名称」；资格审查条件表的「资格审查条件项」「资格审查条件名称」及文件检测的附件选择）时，视为人工修正，该行的 AI 解析标记自动消失。
  - 通过「一键同步资审附件组成」等其他非推荐弹窗入口生成的行，不携带该标签。

## 4. 数据映射规则

### 4.1 附件组成推荐 → 资格审查附件组成

| 弹窗推荐字段 | 写入下方表格字段 | 说明 |
| --- | --- | --- |
| 文件项 | 文件项 | 如「法人身份证」「营业执照」等。 |
| 文件项名称 | 文件项名称 | 推荐中显示的具体名称；若文件项为「自定义」，则取自定义名称。 |
| 是否必须上传 | 分供商必须上传 | 直接沿用推荐中的「是 / 否」。 |
| AI 解析标记 | `aiParsed` | 写入时标记为 `true`，用于在前端展示「AI 解析」标签，不做后端持久化。 |

写入时，其他字段（如范本、样本文件）默认未上传状态，用户可后续补充。

### 4.2 资审条件推荐 → 资格审查条件

| 弹窗推荐字段 | 写入下方表格字段 | 说明 |
| --- | --- | --- |
| 资格审查条件项 | 资格审查条件项 | 优先匹配系统中已有的条件项树；若命中，则使用标准条件项。 |
| 资审条件强度 | 资审条件强度 | 如「强制条件」「一般条件」，直接沿用。 |
| 资格审查条件名称 | 资格审查条件名称 | 取推荐中条件名称的第一行作为默认名称。 |
| 文件检测类条件 | 资格审查条件项 / 分类 | 若命中「文件检测」类条件项，系统会标记为文件检测项，便于后续关联报名附件。 |
| AI 解析标记 | `aiParsed` | 写入时标记为 `true`，用于在前端展示「AI 解析」标签，不做后端持久化。 |

若推荐的条件项在系统标准条件树中无法匹配，则写入为「自定义」条件项，由用户手动完善名称和分类。

## 5. 边界与异常说明

| 场景 | 处理方式 |
| --- | --- |
| 弹窗内无可引用行 | 按钮禁用，点击无响应。 |
| 外部快捷入口「一键引用」无可引用行 | 文字变为灰色不可点击，点击无响应。 |
| 推荐行已设置为「已设置」 | 不参与一键引用，保持灰色不可点击。 |
| 资审条件推荐无法匹配标准条件树 | 写入为「自定义」条件项，由用户手动完善名称和分类。 |
| 用户重复点击「一键引用」 | 仅第一次生效，后续因无「引用」行而处于禁用态。 |
| 页面刷新 | 推荐弹窗数据与引用状态恢复为页面初始示例数据。 |
| 删除已带 AI 解析标签的数据行 | 标签随数据行一并消失，无需后端同步。 |
| 修改已带 AI 解析标签的关键字段 | 视为人工修正，该行的 AI 解析标记自动消失。 |
| 通过非推荐弹窗入口新增行 | 不携带 AI 解析标签。 |
