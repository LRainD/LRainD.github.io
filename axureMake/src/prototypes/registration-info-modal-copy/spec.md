# 报名信息弹窗

- 文档编号：PRD-Registration-Info-Modal
- 负责人：[@liurundong]
- 版本：v1.6
- 状态：进行中

## 1. 摘要

报名信息弹窗，用于供应商在采购系统中提交报名信息。本期在报名附件模块接入"文件助手"组件，并新增"一键导入"智能推荐能力，降低附件上传成本，提升报名效率。

## 2. 功能规格

### 2.1 联系方式
- 联系人（必填）
- 手机号（必填）
- 邮箱（必填）

### 2.2 报名附件

#### 2.2.1 附件是否使用电子签章（必填）
- 单选字段，选项：
  - **是**：使用电子签章上传，需进行电子签章后再提交
  - **否**：直接上传，传统附件上传方式
- 默认选中：**是**
- 选择后展开附件字段

#### 2.2.2 附件上传
- 附件上传（必填）

**选择"是"（电子签章）时：**
- 大小限制：100M
- 支持格式：.pdf
- 说明文字：电子签功能仅支持100M以内的pdf文件

**选择"否"（直接上传）时：**
- 大小限制：500M
- 支持格式：.jpeg、.jpg、.gif、.png、.doc、.docx、.xlsx 等
- 说明文字：大小限制：500M　支持格式：.jpeg、.jpg、.gif、.png、.doc、.doc_、.docx、.xl...（如需使用电子签功能，请上传100M以内的pdf文件）

#### 2.2.3 文件助手接入
- 选择"是"（电子签章）模式下，点击任一附件组的"添加附件"按钮，统一调用"文件助手"组件选择文件
- 接入"文件助手"组件，选择的附件使用追加模式，不覆盖已上传的附件

#### 2.2.4 一键导入（智能推荐）
- 入口：报名附件区域右上角"一键导入"按钮
  - 图标：加载中显示旋转动画，右侧带 Info 说明
  - 悬浮说明：文件助手将根据报名附件要求，推荐匹配相关附件并追加到对应文件组成
  - 展示条件：有文件组成且选择电子签章模式
- 交互流程：
  1. 首次进入页面即自动展示 Ant Design Tour 漫游引导，以半透明遮罩、阴影和目标区域高亮突出"一键导入"入口，并在高亮区域外显示引导卡片
  2. 引导标题为"一键导入，全新升级"，引导卡片不展示额外的 AI 图标或"AI 智能匹配"提示
  3. 引导说明为"文件助手会根据当前报名附件要求，从您的文件库中智能匹配相关附件。确认后，推荐附件将自动追加到对应的文件组成中，已有附件不会被覆盖。"
  4. 引导补充提示为"推荐结果仅供参考，请确认附件内容及有效期。"
  5. 引导提供关闭按钮、"不再提示"复选项和"确认导入"按钮；关闭不执行导入，确认导入后自动执行一键导入
  6. 原型仅展示"不再提示"的当前交互状态，不持久化；研发实现需将该偏好持久化到用户级本地配置，后续点击时跳过引导并直接导入
  7. 确认导入后，按钮进入 Loading 状态，加载完成前不可重复点击
  8. 文件助手根据报名附件要求，在"我的文件库"中匹配附件，并直接追加到对应附件组，不再打开推荐确认弹窗
  9. 追加时保留原有附件，并按文件唯一标识去重，避免重复导入
- 推荐结果展示：
  - 一个文件组成类型可追加多个推荐附件
  - 推荐附件右上角展示 AI 标识
  - 已上传附件采用紧凑单行文件框展示；推荐附件下方展示"推荐依据：{匹配说明}"，说明区域支持多行自然换行，用于解释文件名称、文件库标签或资质要求等匹配原因
  - 没有推荐数据的文件组成类型，在文件组成标题与"添加附件"按钮之间展示红色文案"接口返回的未推荐理由"
  场景包含：报名、投标/响应

### 2.3 操作按钮（联动规则）

按钮根据**附件是否使用电子签章**的选择进行联动：

| 附件是否使用电子签章 | 操作按钮 |
|---------------------|---------|
| 否 | 提交报名 |
| 是 | 发起电子签后报名 |

- 取消（始终显示）

### 2.4 电子签章流程

#### 2.4.1 提示弹窗
点击"发起电子签后报名"按钮后，弹出提示弹窗：
- 弹窗标题：提示（带橙色感叹号图标）
- 说明文字：以下附件将发起电子签章，签章完成后自动报名，最多支持20个文件发起签章
- 文件列表：显示当前所有附件，全部默认勾选，不可取消勾选
- 已选数量提示：已选X条（最多20条）
- 操作按钮：取消、确定

#### 2.4.2 签署状态标记
点击确定后，关闭提示弹窗，在主弹窗的对应附件左上角显示"签署中"标签：
- 标签样式：橙色背景（#f5a623），白色文字，圆角
- 标签位置：附件卡片左上角，略微超出卡片边界（-top-2 left-2）
- 标签文字：签署中

### 2.5 底部提示
- 仅在**选择"是"（电子签章）**方式下显示底部提示文字
- 提示内容：存在签章中/签章失败的文件时，请先点击"发起电子签后报名"完成电子签章。

### 2.6 提交报名反馈

#### 2.6.1 提交失败弹窗
当选择"否"（直接上传）点击"提交报名"时，如果附件列表中存在签署中/签章失败的文件，弹出提交失败弹窗：
- 弹窗标题：提交失败（带橙色感叹号图标）
- 提示内容：存在附件为签章失败/签章中状态，已为您暂存页面信息。签章中文件均签章成功时会自动为您完成报名（如果您已报名则会为您更新联系方式，但注意及时完成签章，否则报名截止时文件签章中/签章失败可能影响您的参与。如需撤销签章或签章附件错误您可删除文件后重新上传）
- 操作按钮：知道了

#### 2.6.2 报名成功提示
当选择"否"（直接上传）点击"提交报名"时，如果附件列表中不存在签署中/签章失败的文件，显示报名成功提示：
- 提示样式：顶部居中 Toast 提示
- 图标：绿色圆形勾选图标
- 提示文字：报名成功
- 关闭方式：点击右侧 X 按钮或 3 秒后自动消失
