# Excel 导出预览演示

## 📋 业务与功能

### 1.1 核心目标

> 面向产品经理做**导出需求评审**的演示页面。用「仿真 Excel 窗口」把"导出之后长什么样"直接演出来，替代口头/文字描述导出规则，让业务方与研发在评审现场就能对齐：导出了哪些列、字段怎么格式化、空值怎么处理、合计行怎么算、条数超限怎么办。

核心价值：
- 把抽象的导出规则变成**看得见、点得动**的表格，减少评审返工
- 一页同时承载「导出结果预览」与「导出需求说明」，作为需求文档的可视化附件
- 沉淀一套可复用的 Excel 仿真组件，后续其它列表页导出需求可直接套用

### 1.2 功能清单

**A. 仿真 Excel 窗口（核心）**
- **窗口外壳**：Excel 2019 风格标题栏（绿色 `#217346`）+ 文件/开始/插入…选项卡 + 窗口三大按钮
- **功能区（功能区"开始"页签）**：剪贴板、字体（加粗/斜体/下划线/字号/字色/填色）、对齐（水平/垂直/自动换行/合并后居中）、数字（常规/货币/百分比/千分位/增减小数位）、样式（条件格式/网格线/套用表格格式）、单元格（插入行/删除行）、编辑（自动求和/排序/筛选/查找/清除）
- **公式栏**：名称框 + `fx` + 内容框，选中单元格显示其原始值与公式（如 `=(F3-G3)/F3`、`=SUM(F2:F19)`），可在公式栏直接改值
- **网格区**：列头 `A~N`（点击选中整列）、行号（点击选中整行）、全选角标；单元格点击/拖拽/Shift 连选；双击进入编辑；表头冻结 + 筛选箭头
- **真实 Excel 视觉细节**：网格线 `#D4D4D4`、绿色选区框 `#107C41` + 右下角填充柄、被选行列头浅绿高亮、数值右对齐/文本左对齐、金额千分位、负数与高风险红字、Excel 条件格式（风险等级三色底）、合计行加粗带上框线、`#####` 列宽不足提示
- **Sheet 标签栏**：数据明细 / 字段说明 / 导出规则 / 评审要点 四个工作表可切换，含新建 Sheet 按钮
- **状态栏**：就绪/编辑状态、选区"平均值/计数/求和"、右侧缩放滑块（60%~160%）

**B. 导出流程演示**
- 顶部演示条：四步流程（① 业务列表筛选 → ② 点击导出 → ③ 生成文件 → ④ 打开预览核对）
- 「导出 Excel」按钮 → 三段式导出弹窗：读取筛选条件 → 生成文件（含进度） → 完成（文件卡片 + 文件名 + 条数 + 打开预览）
- 导出需求说明抽屉：入口与权限、导出范围、字段与格式化规则、边界与异常、性能与进度、操作日志

**C. Excel 交互命令（可真实操作）**
- 文本：加粗、斜体、下划线、字体颜色、填充颜色、自动换行
- 对齐：左/中/右、垂直对齐、合并后居中（可取消合并）
- 数字：千分位、货币（¥）、百分比、常规、增加/减少小数位
- 结构：插入行、删除行、清除内容、删除键、复制选区为 TSV（Ctrl/Cmd+C）
- 数据：按列升序/降序、按列筛选（多选去重值）、查找（高亮匹配 + 定位）、自动求和
- 视图：网格线开关、套用表格格式（隔行底色）、条件格式开关、缩放
- 键盘：方向键移动、Enter 下移、Tab 右移、Delete 清除、Esc 取消编辑

### 1.3 交互要点

- 单击单元格 → 选中（active cell 白底，选区绿框）→ 公式栏同步显示该格内容
- 双击 / 直接输入 → 进入编辑态（浮动输入框，光标定位）→ Enter 提交并下移、Tab 提交并右移、Esc 撤销
- 拖拽鼠标 → 连续选区；Shift + 单击 → 扩展选区；点击行号/列头 → 整行/整列选中
- 状态栏统计随选区变化：选区含数字时显示 平均值 / 计数 / 求和
- 点击表头筛选箭头 → 该列值多选面板 → 确定后隐藏不匹配行，箭头变强调色
- 任意功能命令执行后 → Excel 风格提示条（浅黄底 + 图标）提示"已执行 XX"，2.2s 自动消失
- 切换 Sheet → 换表不换壳（功能区/公式栏保留），非数据表 Sheet 为说明型内容
- 点击「导出 Excel」→ 弹窗自动播放三段进度 → 完成后可"打开预览"，同时右侧演示条高亮第 ④ 步
- 「演示脚本」按钮 → 抽屉内给出评审现场的口播顺序（讲什么、点哪里、看什么）

## 🎨 布局与结构

### 3.1 整体布局

- **布局模式**：单栏上下结构（顶部演示条固定 + Excel 窗口占满剩余高度）
- **容器宽度**：流式（`width: 100%`，页面无横向滚动；横向滚动交给网格区内部）
- **关键尺寸**：
  - 顶部演示条：高 64px
  - Excel 标题栏：高 32px
  - 选项卡：高 30px；功能区：高 96px（含提示条 28px）；公式栏：高 28px
  - 列宽：A 56 / B 200 / C 150 / D 150 / E 100 / F 140 / G 140 / H 90 / I 110 / J 170 / K 100 / L 120 / M 90 / N 180（px，缩放时等比放大）
  - 数据行高：23px；表头行高 26px；合计行 24px
  - Sheet 标签栏：高 30px；状态栏：高 24px
- **溢出策略**：网格区内部横向 + 纵向滚动，列头与行号分别 sticky 吸附（冻结首行首列）

### 3.2 响应式适配

- **桌面端（≥1200px）**：演示条单行，Excel 窗口全宽，右侧说明抽屉宽 560px
- **平板端（768-1199px）**：演示条步骤简化为图标 + 序号，抽屉宽 88%
- **移动端（<768px）**：演示条换行；Excel 窗口保持横向滚动，功能区工具组允许换行滚动（演示以桌面端为主）

## 🎨 视觉规范

### 4.1 设计规范来源

**设计规范来源**：主题 `/src/themes/antd-new`

**说明**：页面外壳（演示条、抽屉、弹窗、按钮）严格使用 Ant Design v6 令牌与组件；仿真 Excel 窗口属于"被演示的第三方软件"，按 Excel 2019 官方视觉还原，色值在 4.2 单独定义，不参与主题令牌映射。

### 4.2 自定义设计要点

**自定义色彩**（仿真 Excel 窗口专用）：
- `#217346`：Excel 主色（标题栏、文件页签、选中强调）
- `#107C41`：选区框、填充柄
- `#D6E7D6` / `#E8F3EC`：选中行列头 / 选中区浅填充
- `#F3F3F3` / `#F9F9F9`：选项卡条 / 功能区背景
- `#D4D4D4`：网格线
- `#F2F2F2`：表头行底色
- `#1F1F1F`：单元格常规文字
- 条件格式（对齐 Excel 内置样式）：高风险 `#FFC7CE`/`#9C0006`，中风险 `#FFEB9C`/`#9C6500`，低风险 `#C6EFCE`/`#006100`
- 提示条：`#FFF4CE` 底 + `#7A6A00` 文字

**自定义尺寸**：
- 单元格字号 13px（缩放时同比）；功能区图标 16px；按钮 24×24px
- 网格区最小高度 320px，超出滚动

**其他自定义规范**：
- 网格线为 1px 实线 `#D4D4D4`，用 CSS 变量 `--xl-grid` 控制，可与"网格线开关"联动
- 所有表格文字使用系统字体栈，数字使用等宽对齐感（`font-variant-numeric: tabular-nums`）

### 4.3 组件状态

- **默认态（default）**：白底、1px 网格线、常规文字
- **悬停态（hover）**：行列头悬停浅灰 `#E8E8E8`；功能区按钮悬停 `#E6E6E6`；单元格悬停不加底色（与 Excel 一致）
- **选中态（selected）**：绿色 2px 选区框 + 右下角填充柄；选中行列头浅绿；多选时 active cell 保持白底
- **编辑态（editing）**：单元格内浮动输入框，无边框、无内边距偏移，光标定位；公式栏内容同步
- **禁用态（disabled）**：非数据 Sheet 的功能按钮置灰，点击提示"当前工作表不支持该操作"
- **加载态（loading）**：导出弹窗进度条 + 分步文案
- **异常态（error）**：超限导出提示条（黄底警示）、空值统一显示 `-`
