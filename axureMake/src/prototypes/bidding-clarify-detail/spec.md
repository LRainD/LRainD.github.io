# 投标报价详情 - 澄清

- 文档编号：PRD-Bidding-Clarify-Detail
- 负责人：[@liurundong]
- 版本：v1.0
- 状态：进行中

## 1. 摘要

投标报价详情页「澄清」页签，用于供应商在采购方允许的提问周期内查看已澄清内容、发起提问并跟踪提问是否被采购商查看。本期迭代在**已澄清列表**补充「提问截止时间」列，并在**提问列表**中对超过截止时间的场景进行置灰拦截，让供应商在操作前就能明确当前是否仍可提问。

> 关联范围：投标报价详情页 - 澄清页签

## 2. 功能规格

### 2.1 已澄清列表

#### 2.1.1 新增「提问截止时间」列
- 展示该采购项允许提问的截止时间，精确到 **年月日时分秒**（`YYYY-MM-DD HH:mm:ss`）
- 列位置：位于「澄清时间」之后、「澄清说明」之前，与时间类信息相邻，便于对比
- 数据来源：采购项统一的提问截止时间（同一采购项下各条澄清记录取值一致）

#### 2.1.2 列结构（迭代后）

| 列 | 说明 |
|----|------|
| （序号） | 序号 |
| 澄清时间 | 采购商发布澄清的时间 |
| **提问截止时间**（新增） | 允许提问的截止时间，到年月日时分秒 |
| 澄清说明 | 澄清内容说明 |
| 附件数量 | 澄清附件数量 |
| 附件 | 附件下载入口，无附件显示 `--` |
| 状态 | 已查看 / 未查看 |
| 操作 | 行操作，暂无操作显示 `--` |

### 2.2 提问列表

#### 2.2.1 提问入口（超时置灰）
- **可提问**：当前时间 ≤ 提问截止时间，按钮为橙色主色可点击
- **已超时**：当前时间 > 提问截止时间
  - 「提问」按钮置灰（不可点击、`cursor: not-allowed`），不再响应悬停变色
  - 按钮**左侧**显示灰色小字提示：`已超过提问截止时间{提问截止时间}`（时间精确到年月日时分秒）
- 提示文案与「已澄清列表 - 提问截止时间」列取同一数据源，保证同一页面内时间口径一致

#### 2.2.2 列表结构（不变）

| 列 | 说明 |
|----|------|
| （序号） | 序号 |
| 提问时间 | 供应商发起提问的时间 |
| 提问说明 | 提问内容说明 |
| 附件数量 | 提问附件数量 |
| 附件 | 附件下载入口 |
| 是否已被采购商查看 | 未查看 / 已查看 |

### 2.3 其他页签

保持原有 Tab（采购(资格预审)公告、联系方式、报名附件、采购文件、澄清、答疑）与「已澄清列表」「提问列表」的折叠交互不变。

## 3. 交互要点

- **超时拦截前置**：在按钮点击前即通过「置灰 + 提示文案」告知用户已无法提问，避免点击后才报错。
- **时间口径统一**：提示文案与表格列使用同一提问截止时间，且统一到 **年月日时分秒**。
- **折叠交互**：两个卡片头部右侧的下箭头控制内容区展开/收起，超时提示不随折叠消失（跟随卡片头部）。

## 4. 视觉规范

### 4.1 设计规范来源

**设计规范来源**：主题 `/src/themes/antd-new`

### 4.2 自定义设计要点

**自定义色彩**：
- 主色/按钮色：`#fa8c16` - 可点击「提问」按钮
- 禁用按钮底色：`#d9d9d9` - 超时置灰按钮
- 提示小字色：`#999` - 超时提示文案（对比度满足 WCAG 2.1 AA）

**自定义尺寸**：
- 超时提示字号：`12px`

### 4.3 组件状态

- **默认态（default）**：按钮橙色底、白色文字
- **悬停态（hover）**：按钮底色加深为 `#e68a00`（仅可点击态生效）
- **禁用态（disabled）**：灰色底 `#d9d9d9`、白色文字、`cursor: not-allowed`，悬停无变化

## 5. 数据字段

```typescript
{
  clarifyTime: string;   // 澄清时间，YYYY-MM-DD HH:mm:ss
  askDeadline: string;   // 提问截止时间，YYYY-MM-DD HH:mm:ss（本次新增）
  clarifyDesc: string;   // 澄清说明
  attachCount: string;   // 附件数量
  attach: string;        // 附件，无附件为 '--'
  status: string;        // 状态：已查看 / 未查看
  action: string;        // 操作，无操作为 '--'
}
```
