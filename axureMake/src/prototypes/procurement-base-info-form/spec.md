# 采购基础信息 PRD

## 1. 文档信息

- **文档名称**：采购基础信息需求文档
- **适用页面**：采购基础信息
- **目标读者**：前端研发、产品、测试
- **文档状态**：评审稿

---

## 2. 背景与目标

### 2.1 背景

采购基础信息是采购发起流程的第一步，经办人需要在此页面填写采购名称、品类、组织形式、采购方式等关键字段，为后续采购响应、文件开启、采购评审、采购成交等环节提供数据基础。

### 2.2 目标

- 提供采购基础信息的录入与展示能力。
- 支持 AI 智能推荐，自动填充部分字段，降低录入成本。
- 对需要用户确认的字段（采购品类），通过气泡引导用户选择并确认。

---

## 3. 功能范围

本页面包含以下功能模块：

1. 基本信息录入
2. 发起来源展示
3. 附加信息展示
4. AI 智能推荐

---

## 4. 功能需求

### 4.1 基本信息

展示并编辑采购基础信息，字段包括但不限于：

| 字段 | 是否必填 | 说明 |
|------|----------|------|
| 创建人 | 是 | 固定展示当前用户 |
| 创建时间 | 是 | 保存后生成 |
| 采购编号 | 是 | 保存后生成 |
| 采购名称 | 是 | 手动输入 |
| 物料类别 | 是 | 下拉选择 |
| 合作品类 | 是 | 下拉选择 |
| 采购品类 | 是 | 下拉选择 |
| 组织机构 | 是 | 下拉选择 |
| 管控公司 | 否 | 下拉选择 |
| 经办人 | 否 | 固定展示当前用户 |
| 组织形式 | 是 | 下拉选择 |
| 采购方式 | 是 | 下拉选择 |
| 采购模式 | 是 | 下拉选择 |
| 合同类型 | 是 | 下拉选择 |
| 合同模板 | 是 | 下拉选择 |
| 概算金额 | 是 | 手动输入 |
| 分清单成交 | 是 | 单选 |
| 签约公司 | 否 | 标签展示 |
| 付款条件 | 否 | 下拉选择 |
| 国际贸易条件及附加 | 否 | 下拉选择 |
| 交易模式 | 否 | 下拉选择 |
| 买/卖 | 是 | 下拉选择 |

### 4.2 发起来源

展示当前采购计划的发起来源、来源类型、来源单据编号，仅做展示不可编辑。

### 4.3 附加信息

当前暂无附加信息时展示空状态。

### 4.4 AI 智能推荐

#### 4.4.1 触发方式

用户点击页面右上角「智能推荐」按钮，系统弹出二次确认弹窗，用户确认后进入 AI 推荐流程。

#### 4.4.2 推荐流程

1. 系统高亮并定位到「采购品类」字段，AI 小人旁弹出气泡，提示「请选择采购品类」。
2. 用户在下拉框中选择采购品类；选择后气泡中展示可用的【确认】按钮，但系统不会自动继续推荐。
3. 用户点击【确认】后，系统才继续按顺序自动推荐并填充剩余字段：合作品类、采购方式、组织形式、采购模式、合同类型、合同模板、买/卖。
4. 每个自动推荐的字段会展示「荐」标签，高亮显示后自动填充推荐值。
5. 推荐完成后，AI 气泡提示「小云已为您推荐 N 个字段」，并展示关闭按钮。

#### 4.4.3 确认按钮规则

- 展示时机：AI 推荐停留在「采购品类」字段且等待用户选择时。
- 禁用状态：用户未选择采购品类时，按钮置灰不可点击。
- 可用状态：用户已选择采购品类时，按钮高亮，点击后继续后续推荐流程。
- 样式：与「智能推荐」按钮保持一致的紫蓝渐变主色。

#### 4.4.4 中断与关闭

- 用户可点击 AI 气泡关闭按钮结束推荐流程（推荐完成后可用）。
- 用户在推荐过程中手动修改字段，该字段的「荐」标签自动移除。

---

## 5. 非功能需求

- 页面需适配暗黑模式。
- AI 小人及气泡位置需根据字段位置动态计算，避免超出可视区域。
- 推荐过程中显示进度条，提示当前推荐进度。
