# 1. 需求背景

## 1.1 问题描述

- 原有附件盖章方式为普通圆形单选，视觉权重低，供应商难以直观理解"电子签章更快"的价值，容易沿用纸质扫描件流程。
- "一键导入"原为区块头部按钮，与附件内容分离，点击后直接弹出推荐列表，缺少引导与匹配过程说明，用户不清楚文件助手做了什么。
- 推荐结果以"附件组 + 推荐文件"的二次确认弹窗呈现，与页面文件组成割裂，用户难以核对最终落入页面的附件，容易出现漏传、错传。
- 导入完成后页面缺少结果反馈与核对引导，用户不清楚导入是否成功、下一步该做什么。

## 1.2 目标用户

- 供应商 / 投标方投标操作人（商务人员、资质管理员）
- 首次参与投标、不熟悉投标附件要求的新供应商

## 1.3 业务目标

- 提升电子签章的选择率，减少纸质流转与快递成本
- 提升一键导入的发现率与确认率
- 让导入结果在页面内可见、可核对、可二次调整，降低因附件缺失导致的无效投标

# 2. 产品定位

## 2.1 本迭代定义

对投标/报价详情页"投标附件"区的体验优化：盖章方式卡片化、一键导入入口前置到附件格式说明下方、导入过程改为"引导浮层 → 文件助手双栏核对 → 确认带入页面"，导入后给出完成反馈与核对建议。

## 2.2 核心价值

- **决策更直观**：两种盖章方式以卡片并列，优势与时效直接可见
- **入口更聚焦**：一键导入独立成行，位于附件格式说明正下方，并带说明浮层
- **过程更透明**：文件助手左侧展示投标文件组成、右侧展示文件库，匹配过程可见
- **结果更可控**：确认带入前可在弹窗内增删调整，确认后一次性写回页面

## 2.3 与迭代前的差异

| 维度 | 迭代前 | 迭代后（本期） |
|------|--------|----------------|
| 盖章方式 | 普通单选，仅名称 | 两张卡片，含推荐角标与时效说明，选中态高亮 |
| 一键导入入口 | 位于"投标附件"区块头部，与内容分离 | 位于附件格式说明下方独立展示，导入后隐藏 |
| 导入过程 | 点击后直接弹出推荐列表弹窗 | 首次展示引导浮层 → 文件助手双栏核对（左文件组成 / 右文件库） |
| 导入结果 | 按附件组逐条确认，与页面结构割裂 | 弹窗内一次调整，点击"确认带入页面"整体写回 |
| 导入反馈 | 无 | 绿色完成提示（约 3 秒）+ 橙色核对建议 |
| 推荐附件标识 | 橙色描边 + 推荐依据 | 已移除，展示样式与普通附件一致 |

# 3. 用户故事

## 3.1 选择附件盖章方式

作为【供应商投标人】，
在【填写投标附件前】场景下，
为了【快速判断哪种盖章方式更适合本次投标】，
需要【以卡片形式直观对比电子签章与纸质扫描件】。

- 验收标准：两张卡片左右平分占满整行；电子签章带"推荐"角标与"最快10分钟完成"说明；整卡可点击，选中态清晰；两种方式各自维护附件，切换互不覆盖。
- 技术实现要点：选中态由 `sealMethod` 状态驱动，`esignGroups` / `scanGroups` 双份数据隔离。

## 3.2 发现并使用一键导入

作为【供应商投标人】，
在【已选择电子签章】场景下，
为了【不逐个分类查找附件】，
需要【在附件格式说明下方直接看到一键导入入口，并理解它的作用】。

- 验收标准：入口位于格式说明正下方、与说明左边缘对齐；按钮右侧带 `Info` 图标，悬停展示"文件助手将根据投标文件组成，推荐匹配的附件并自动填充当前为空的附件项"；点击后先出现引导浮层，再进入文件助手弹窗；导入完成后入口隐藏。
- 技术实现要点：入口展示条件为"电子签章模式 + 未完成导入"；引导浮层通过 `Tour` 指向 `importButtonRef`。

## 3.3 核对并带入导入结果

作为【供应商投标人】，
在【进入文件助手】场景下，
为了【确认每个分类下到底有哪些附件】，
需要【在同一个弹窗里看到文件组成与文件库，并能增删调整】。

- 验收标准：左栏按投标文件组成展示各分类及附件，右栏可搜索、勾选文件库；支持在某分类下"添加"文件；点击"确认带入页面"后整体写回页面并关闭弹窗。
- 技术实现要点：弹窗内使用深拷贝草稿 `draft`，确认时才回写；按文件 ID 去重追加。

## 3.4 核对导入结果

作为【供应商投标人】，
在【完成一键导入】场景下，
为了【确认附件是否齐全再提交投标】，
需要【看到页面内的导入结果与核对建议】。

- 验收标准：导入后页面展示各文件组成及附件；列表下方展示绿色完成提示（约 3 秒）与橙色建议文案；推荐附件不展示推荐标识与推荐依据。
- 技术实现要点：`hasImported` 驱动入口隐藏与建议文案；`importSummary` 3 秒后自动清空。

## 4.2 功能详情

- **卡片化**：保留"附件盖章方式"字段名与必填星号；两张卡片占满整行；电子签章为推荐项，说明"在线签署，最快10分钟完成，无需打印快递"；纸质扫描件说明"需打印、盖章、扫描上传，约1-2天"。
- **入口前置**：一键导入按钮位于附件格式说明下方，仅在电子签章模式且未完成导入时出现。
- **引导浮层**：标题"一键导入，全新升级"，说明匹配逻辑与"推荐结果仅供参考"，提供"不再提示"复选框，主按钮"一键导入"直接进入文件助手。
- **文件助手**：左栏固定 352px 展示"文件组成"，右栏展示"文件库"；导入模式先展示约 900ms 匹配态，再展示匹配结果。
- **导入结果**：点击"确认带入页面"后，弹窗内调整后的文件组成整体写回页面，入口隐藏，展示完成提示与建议文案。
- **样式统一**：推荐附件与普通附件展示一致，不再有 AI 标识与推荐依据。

# 4.3 功能详细说明

## 4.3.1 附件盖章方式卡片化

### 页面概述

将原有普通单选改造为两张并排卡片，强化电子签章的价值感知，降低选择成本。

### 页面布局

```
+--------------------------------------------------------------------+
| ▍投标附件                                     [发起电子签] [?] [^] |
|  *附件盖章方式                                                      |
|  +-------------------------------+  +-----------------------------+ |
|  | (•) 电子签章  [推荐]          |  | ( ) 纸质扫描件              | |
|  | 在线签署，最快10分钟完成，    |  | 需打印、盖章、扫描上传，    | |
|  | 无需打印快递                  |  | 约1-2天                     | |
|  +-------------------------------+  +-----------------------------+ |
|  附件：大小限制：100M  支持格式：.pdf                               |
|        （电子签功能仅支持最多20个100M以内的pdf文件…）               |
|  [一键导入] (i)                                                     |
+--------------------------------------------------------------------+
```

### 功能点说明

| 功能点 | 功能描述 | 操作方式 | 数据来源 |
|--------|----------|----------|----------|
| 字段名 | 保留"附件盖章方式"字段名，前置红色必填星号 | - | - |
| 卡片布局 | 两张卡片左右平分，占满整行 | - | - |
| 选项标题 | 电子签章 / 纸质扫描件，含单选圆点 | - | - |
| 推荐角标 | 电子签章标题右侧橙色"推荐"标签 | - | - |
| 优势说明 | 卡片下方展示该方式的时效与操作成本 | - | - |
| 选中态 | 橙色描边 + 浅橙底色 + 橙色单选点，说明文案变绿 | 点击卡片任意位置 | 本地状态 |
| 未选中态 | 浅灰描边白底、说明文案灰色，悬停描边变浅橙 | 悬停 | 本地状态 |

### 数据字段定义

| 字段名称 | 字段类型 | 显示说明 | 取值范围 |
|----------|----------|----------|----------|
| sealMethod | Enum | 当前盖章方式 | `esign` / `scan` |
| esignDesc | String | 电子签章卡片说明 | 在线签署，最快10分钟完成，无需打印快递 |
| scanDesc | String | 纸质扫描件卡片说明 | 需打印、盖章、扫描上传，约1-2天 |
| recommended | Boolean | 是否展示"推荐"角标 | 电子签章为 true |

### 交互说明

- 整卡点击即可切换，点击单选圆点同样生效。
- 切换后下方附件格式说明、一键导入入口、文件组成列表同步刷新。
- 两种模式各自维护附件集合（`esignGroups` / `scanGroups`），来回切换互不覆盖。
- 卡片高度随文案自适应，两卡等高。

### 异常处理

- 未选择任何方式：默认选中电子签章，不出现空态。
- 文案过长：卡片内换行展示，不截断关键信息。

### 性能要求

- 切换方式后界面刷新 ≤ 200ms

## 4.3.2 一键导入入口与引导

### 页面概述

一键导入入口从投标附件区块头部下移至附件格式说明正下方，独立成行；首次进入时以引导浮层说明能力，导入完成后入口隐藏。

### 页面布局

```
迭代前：投标附件 头部右侧 [一键导入]        ← 与附件内容分离，易忽略
迭代后：
  附件：大小限制：100M  支持格式：.pdf
        （电子签功能仅支持最多20个100M以内的pdf文件…）
  [一键导入] (i)                            ← 独立成行，位于说明正下方
  +--------------------------------------+
  | 文件组成（确认带入后展示）           |
  +--------------------------------------+
```

### 功能点说明

| 功能点 | 功能描述 | 操作方式 | 数据来源 |
|--------|----------|----------|----------|
| 入口展示 | 仅电子签章模式且未完成导入时展示，位于格式说明下方 | 自动展示 | 本地状态 |
| 入口隐藏 | 完成导入后不再展示，避免重复导入 | 自动 | 本地状态 |
| 说明浮层 | 按钮右侧 `Info` 图标，悬停展示作用说明 | 悬停 | 本地状态 |
| 引导浮层 | 切换到电子签章、未导入且未勾选"不再提示"时指向入口 | 自动弹出 | 本地状态 |
| 不再提示 | 勾选后不再自动弹出引导 | 勾选复选框 | 本地状态 |
| 进入文件助手 | 点击引导浮层"一键导入"或页面入口 | 点击按钮 | 推荐结果 |
| 纸质模式降级 | 纸质扫描件模式不展示入口与引导 | 自动 | 本地状态 |

### 数据字段定义

| 字段名称 | 字段类型 | 显示说明 |
|----------|----------|----------|
| hasImported | Boolean | 是否已完成一键导入，驱动入口隐藏与结果展示 |
| isImportGuideOpen | Boolean | 是否展示引导浮层 |
| dontRemindAgain | Boolean | 是否勾选"不再提示" |
| importSummary | String | 导入完成提示文案，3 秒后清空 |
| recommendationMap | Object | 按文件组成维护的推荐附件集合 |

### 交互说明

- 入口位置：附件格式说明正下方，独立一行，与说明左边缘对齐，不缩进。
- 说明浮层：悬停 `Info` 图标展示"文件助手将根据投标文件组成，推荐匹配的附件并自动填充当前为空的附件项"，不遮挡按钮点击。
- 引导浮层指向一键导入按钮（`placement: bottomRight`），遮罩 `rgba(0,0,0,0.45)`，无步骤指示点。
- 点击引导浮层主按钮"一键导入"时关闭引导并直接进入文件助手。
- 仅点击遮罩或关闭按钮退出引导，不改变导入状态。
- 纸质扫描件模式下不展示入口，也不触发引导。

### 异常处理

- 推荐为空：文件助手中不追加任何文件，用户仍可在弹窗内手动添加。
- 重复导入：入口已隐藏，无法再次触发。
- 推荐失败/超时：结束匹配态并提示，允许重新发起。

### 性能要求

- 匹配态展示约 900ms，最长不超过 2s
- 引导浮层层级 `z-index: 100`，不遮挡弹窗

## 4.3.3 文件助手双栏核对与确认带入

### 页面概述

点击一键导入或"添加附件"后打开文件助手弹窗。左侧展示"投标文件组成"各分类及其文件，右侧展示"文件助手已有附件"供筛选、勾选后加入分类，并支持直接上传本地文件，确认后整体写回页面。

### 页面布局

```
+----------------------------------------------------------------------+
| ▍文件助手  [一键导入]                                             ✕  |
| 投标文件组成     共 n 个附件 | 文件助手已有附件  所选文件为未签署文件原件 |
| * 营业执照（高亮）           | 文件名称[____] 文件分类[全部▾] 资质类型[全部▾] |
|   文件名称          操作     | □ 文件名称      大类 文件分类 资质类型 操作 |
|   xxx_二轮报价.pdf  预览 删除 | □ 企业营业执照  文件 投标文件  营业执照 预览 |
| 财务会计信用等级             | □ 财务审计报告  文件 投标文件  财务审计 预览 |
|   文件名称          操作     | □ 技术方案响应书 文件 技术标     —    预览 |
| 技术标 / 商务标 / 其他附件    | [加入本类]                               |
|                             | 上传本地文件  [⤒ 上传文件]                |
+----------------------------------------------------------------------+
|                                        已选择 n 个文件   [取消] [确定] |
+----------------------------------------------------------------------+
```

### 功能点说明

| 功能点 | 功能描述 | 操作方式 | 数据来源 |
|--------|----------|----------|----------|
| 打开方式 | 一键导入进入"导入"模式；添加附件进入"添加"模式并定位分类 | 点击 | 本地状态 |
| 匹配态 | 导入模式下展示约 900ms "正在根据投标文件组成智能匹配附件…" | 自动 | 本地状态 |
| 左侧文件组成 | 按分类展示分类标题与文件表（文件名称 / 操作），当前目标分类高亮，总附件数实时统计 | 点击分类切换目标 | 当前文件组成 |
| 分类内操作 | 每个文件支持"预览""删除"，删除仅影响弹窗内草稿 | 点击文本按钮 | 草稿 |
| 右侧附件表 | 展示文件库文件：勾选框、文件名称、大类、文件分类、资质类型、预览 | 点击行勾选 | 文件库 |
| 筛选条件 | 文件名称模糊搜索、文件分类与资质类型下拉筛选，条件叠加生效 | 输入 / 选择 | 文件库 |
| 加入本类 | 将勾选文件追加到当前高亮分类，加入后清空勾选 | 点击按钮 | 勾选结果 |
| 上传本地文件 | 从本地选择文件（可多选）直接加入当前分类；未指定分类时加入"其他附件" | 点击"上传文件" | 本地文件 |
| 预览 | 打开轻量预览层展示文件名称与预览占位区 | 点击"预览" | 本地状态 |
| 确认带入 | 草稿整体写回页面并关闭弹窗 | 点击 | 草稿 |
| 取消/关闭 | 放弃本次调整，页面保持原状 | 点击 | 本地状态 |

### 数据字段定义

| 字段名称 | 字段类型 | 显示说明 |
|----------|----------|----------|
| mode | Enum | `import`（一键导入）/ `add`（添加附件） |
| groups | Array | 当前盖章方式下的投标文件组成 |
| activeGroupId | String | 添加附件时定位的分类 |
| group.title | String | 文件组成名称 |
| group.subtitle | String | 如"模板下载"，非必填 |
| group.files | Array | 该分类下的附件 |
| file.name | String | 附件名称，单行省略 |
| file.type | Enum | `pdf` / `other`，决定文件图标类型 |
| file.signingStatus | Enum | 签章状态（签署中/签章完成），导入文件初始为空 |
| file.isRecommended | Boolean | 推荐标记，仅用于数据标识，不改变展示样式 |
| kind | String | 文件库大类：文件 / 图片 |
| fileType | String | 文件库分类，参与筛选，如投标文件 / 技术标 / 商务标 |
| qualification | String | 文件库资质类型，无资质时展示" — " |

### 交互说明

- 弹窗打开时深拷贝当前文件组成作为草稿，关闭或取消不写回。
- 导入模式先展示匹配态，匹配完成后按 `recommendationMap` 追加推荐附件，按文件 ID 去重，已有附件保留并排在前。
- 推荐仅覆盖当前为空的文件组成（营业执照、aaa 等已有附件的分类不配置推荐结果）。
- 添加模式不执行匹配，打开即定位到来源分类（`activeGroupId`）；导入模式默认选中第一个分类作为"加入本类"目标。
- 点击左侧任一分类可切换目标分类，高亮同步变化；"加入本类"按钮右侧提示当前目标分类名称。
- 勾选文件仅在点击"加入本类"后进入草稿，不做即时写入。
- 上传本地文件后，文件立即出现在左侧当前分类列表，并计入"已选择"统计。
- 筛选仅过滤右侧附件表，不影响左侧草稿。
- 点击"确认带入页面"后，弹窗内所有增删结果整体写回页面。

### 异常处理

- 文件库为空：右侧展示空状态，仍可通过取消退出。
- 筛选无结果：右侧展示"未找到相关文件"，不改变已勾选项。
- 未选中分类：无法加入本类，按钮置灰。
- 上传空选择：不产生任何改动。
- 推荐与已有附件 ID 重复：跳过该推荐，不产生重复行。

### 性能要求

- 弹窗打开 ≤ 300ms
- 搜索过滤响应 ≤ 200ms
- 确认带入后页面更新 ≤ 300ms

## 4.3.4 导入后文件组成展示与核对建议

### 页面概述

导入确认后，页面以"投标文件组成"结构展示各分类及其附件，并在列表下方给出完成提示与核对建议，引导用户先检查再提交投标。

```

|  | 技术标 / 商务标 / 其他附件                                 | |

|  建议：请先检测投标文件完整性，再提交投标                    |

```

### 功能点说明

| 功能点 | 功能描述 | 操作方式 | 数据来源 |
|--------|----------|----------|----------|
| 结果展示时机 | 导入完成或存在附件时展示文件组成列表 | 自动 | 本地状态 |
| 分类展示 | 按文件组成展示名称、模板下载入口 | - | 数据配置 |
| 附件行 | 展示文件类型图标、名称、编辑与删除入口 | 点击删除 | 当前附件 |
| 签章状态 | 电子签章模式下展示"签章完成"角标 | - | 签章结果 |
| 推荐附件 | 与普通附件一致，不展示推荐标识与依据 | - | 导入结果 |
| 添加附件 | 电子签章模式复用文件助手；纸质模式模拟本地上传 | 点击添加 | 文件助手 |
| 完成提示 | 导入成功展示绿色"已完成一键导入并填充投标文件组成" | 自动展示 | 本地状态 |
| 建议文案 | 导入后在列表下方展示橙色核对建议 | 自动展示 | 本地状态 |
| 底部提示 | 电子签章模式下提示先完成"发起电子签" | 自动展示 | 本地状态 |

### 数据字段定义

| 字段名称 | 字段类型 | 显示说明 |
|----------|----------|----------|
| group.title | String | 文件组成名称 |
| group.subtitle | String | 是否展示"模板下载" |
| file.name | String | 附件名称，单行省略 |
| file.type | Enum | `pdf` / `doc`，决定图标样式 |
| file.signingStatus | Enum | 签章状态标签（签署中/签章完成） |
| adviceText | String | 建议：请先检测投标文件完整性，再提交投标 |
| importSummary | String | 已完成一键导入并填充投标文件组成 |

### 交互说明

- 展示顺序：文件组成按配置顺序排列，附件按已有 → 推荐追加的顺序展示。
- 建议文案位置：文件组成列表下方，仅在完成导入后展示。
- 完成提示为绿色，3 秒后自动消失；建议文案为橙色，持续展示。
- 推荐附件与普通附件交互一致：可删除、可继续追加，不再额外标注来源。
- 删除附件后列表实时更新；分类附件清空后仍保留分类与"添加附件"入口。
- 电子签章模式点击"添加附件"打开文件助手"添加附件"模式；纸质扫描件模式直接追加本地上传占位文件。

### 异常处理

- 分类无附件：仅展示分类标题与"添加附件"按钮。
- 文件名超长：单行截断，不撑高行高。
- 导入后用户删除全部附件：列表保留结构，建议文案仍展示，提示可重新添加。

### 性能要求

- 列表渲染 ≤ 500ms
- 删除/追加附件反馈 ≤ 300ms

# 7. 非功能性需求

## 7.1 性能需求

- 投标附件区展开/收起 ≤ 300ms
- 匹配接口超时 ≤ 10s，超时展示失败提示并允许重试

## 7.2 可用性需求

- 模式切换、导入操作失败时保留已有输入与附件
- 引导浮层可勾选"不再提示"，避免重复打扰
- 弹窗内调整未确认即关闭时，页面数据不被修改

## 7.3 安全需求

- 文件助手仅可访问当前账号权限范围内的文件
- 上传附件需校验格式、大小；电子签章仅支持 pdf，单文件 ≤ 100M，最多 20 个

## 7.4 数据统计需求

- 电子签章选择率（迭代前后对比）
- 一键导入曝光、引导完成、点击、确认带入与放弃事件
- 文件助手内"添加/删除"操作频次，用于评估推荐准确度
- 导入后到提交投标的转化与附件补传情况
