# 检查模板列表与编辑页面规格说明 (check-template-mgmt)

本项目是集采工作台（招标采购 > 一单一检 > 检查模板列表与编辑）管理页面原型。主要用户是具有模板维护权限的局管理员，用于维护检查模板、版本、阶段/分组、检查项、检查标准和填写规则。

## 1. 业务场景与用户需求

一单一检检查模板采用“模板—版本—检查阶段/分组—检查项—检查标准”四层结构：
1. **列表查询与管理 (PG-070)**：
   - 过滤查询：支持按“模板名称”、“适用检查类型”（自查/互查/稽查）、“模板状态”（草稿/已发布/已停用）、“生效时间”进行检索。
   - 核心列表字段：序号、模板名称、适用检查类型、模板状态、阶段/分组数量、检查项总数（分两行显示人工项与系统项数量）、生效时间、更新时间、更新人。
   - 模板状态机：支持“草稿”、“已发布”、“已停用”的状态流转。
   - 版本控制：已发布的版本为只读，若需修改只能通过“基于已发布版本创建新版本草稿”并进行再次发布；历史任务引用已锁定版本，互不追溯。
2. **模板编辑配置 (PG-071)**：
   - **基础信息与适用范围**：维护模板名称、说明，并通过可新增、删除的适用范围表格维护组织、适用检查类型、采购品类、采购类型&组织形式、招标方式&采购方式、合同类型。
   - **检查项列表式配置**：取消原来的左右分栏与左侧阶段树。改为直观的**列表明细形式**，类似于最终执行的预览视图，直接在右侧对全部检查项进行列表展示和管理，每一行对应一个检查项。
   - **检查阶段多级分类选择**：检查项的“检查阶段”不再是自由创建或单级选择，而是采用级联选择（Cascader）的**多级分类选择**，预置好了以下多级结构：
     - **招标/采购阶段**
       - 约发开评定阶段（约标阶段、发标阶段、开标阶段、评标阶段、定标阶段等）
     - **合同阶段**
3. **预览与发布校验**：
   - **模板预览**：按照实际任务执行视图加载表格样式，直观查看“序号、检查阶段、检查项、检查标准、判定结果、检查备注、检查附件”的展示效果。
   - **发布校验**：校验模板是否至少包含一个检查项，且每个系统识别项均已配置具体系统规则；校验通过后生成只读的新发布版本。

## 2. 页面布局与视觉风格

参考 `compliance-personnel-library` 页面的国企稳重深蓝色系，使用 `CentralizedProcurementLayout` 通用布局：
- **菜单导航**：左侧导航栏选中“招标采购” > “一单一检” > “检查模板”。
- **面包屑**：首页 > 招标采购 > 一单一检 > 检查模板
- **页面视图切换**：
  - `list` 列表视图。
  - `form` 模板编辑视图：采用上部基础信息与适用范围配置表格、下部检查项明细表格的专业模板配置布局。
  - `preview` 预览视图：模拟正式检查执行时的只读表格和卡片，确保“所见即所得”。

## 3. 详细交互设计与组件定义

### 3.1 列表页 (List View)
- **查询区**：
  - 模板名称：Input
  - 适用检查类型：Select 多选（自查、互查、稽查）
  - 模板状态：Select（草稿、已发布、已停用）
  - 生效时间：DatePicker.RangePicker
  - 查询/重置按钮
- **工具栏**：
  - 新增模板：Button (Primary, Icon: PlusOutlined)
- **表格列 (Table Columns)**：
  - 序号
  - 模板名称
  - 适用检查类型：展示为 Tag（自查、互查、稽查）
  - 阶段/分组数量
  - 检查项总数：分两行竖向排列显示（人工项：N 项，系统项：M 项）
  - 生效时间
  - 状态：Tag（草稿-灰色，已发布-绿色，已停用-红色）
  - 更新人/更新时间
  - 操作：
    - 草稿状态：编辑、预览、发布、停用、删除
    - 已发布状态：创建新版本（基于此版复制出新草稿）、预览、停用
    - 已停用状态：预览、复制（复制为一个全新草稿）

### 3.2 模板编辑视图 (Form View)
- **页面标题**：仅展示“编辑检查模板”或“新增检查模板”，不展示版本号。
- **顶部标题操作条**：复用 `TopActionBar` 组件，在面包屑下方展示独立白色横向操作条；左侧展示“编辑检查模板”或“新增检查模板”，右侧依次展示“保存草稿”“发布”“取消”。发布为蓝色实心主按钮；操作条高度为 60px，页面向下滚动时固定在主内容区顶部并抵消内容区的 16px 上内边距，内容配置区与该操作条分离展示。
- **卡片一：基础信息**
  - 模板名称 (Input, 必填)
  - 适用范围/说明 (TextArea)
- **卡片二：适用范围配置（可编辑表格）**
  - 组织：TreeSelect 树形展开多选，支持按集团与下属公司层级选择。
  - 适用检查类型：Select 多选（自查、互查、稽查）；模板列表和发布校验使用各行选中类型的并集。
  - 采购品类：Select 多选。
  - 采购类型&组织形式：Select 多选。
  - 招标方式&采购方式：Select 多选。
  - 合同类型：Select 多选，选项为采购合同、框架协议、执行合同。
  - 操作：支持“添加一项”新增适用范围条件；至少保留一条配置。
- **卡片三：检查项明细 (统一表格列表)**
  - 工具栏：新增检查项 (Button)、一键保存、取消。
  - 表格列：
    - 序号：1, 2, 3...
    - 检查阶段：Cascader 级联选择（预置分类：招标/采购阶段 -> 约发开评定阶段（具体包含：约标阶段、发标阶段、开标阶段、评标阶段、定标阶段）；合同阶段）
    - 检查项：人工检查时为 Input；系统识别时切换为“选择系统检查规则”的单选 Select，选择规则后自动回填检查项名称。
    - 检查标准：TextArea (只读预览/快捷输入)
    - 检查方式：Select（人工检查 / 系统识别）
    - 风险等级：Select（高 / 中 / 低）
    - 操作：复制、删除。

### 3.3 模板预览与校验
- **预览视图 (Preview View)**：
  - 顶部面包屑和返回按钮。
  - 顶栏显示当前正在预览的模板及版本信息。
  - 展示实际执行时的列表结构，按照阶段分组把检查项渲染出来，让用户预览实际执行时的交互体验。
- **发布校验 (Publish Validation)**：
  - 点击“发布”时，系统校验至少已配置一项检查项，且系统识别项已选择具体系统规则；未通过时弹窗提示对应检查项。

## 4. 模拟数据定义 (Mock Data)

提供 3 个具有代表性的模板模拟数据：
1. **一局普通合同检查模板**：状态为“已发布”，版本为 `V1.0`。包含“约标阶段”、“发标阶段”等多个阶段，具有系统识别项（如“采购项目关联性检测”，能力标识 `rule_procurement_association`）和人工项。
2. **两阶段采购项目稽查模板**：状态为“草稿”，版本为 `V2.1 (草稿)`。
3. **框架协议专项检查模板**：状态为“已停用”，版本为 `V0.8`。
