# 企业关联-配置页面 迭代-增加配置

## 📋 业务与功能

### 1.1 核心目标

为企业关联检测提供配置入口，支持用户选择待检测企业、配置关联层级与关系类型，最终发起检测任务。

### 1.2 功能清单

- **检测企业配置**：手动添加或批量导入企业，支持企业名称搜索联想与统一社会信用代码回填。
- **关联层级设置**：选择关联路径层数（1-5 层）。
- **关系类型设置**：以表格形式展示企业关系名称、风险等级、所属场景、元数据类型、关联元数据、股权区间；支持「模板选择」下拉切换，提供系统模板与精简模板两套数据；支持按「2-10家」「11-50家」「51-500家」场景 Tab 切换；提供「模板配置」入口按钮，点击后当前页面切换为模板管理视图。
- **模板管理视图**：在当前页面内展示模板列表表格，支持搜索、启用/禁用、删除、分页及返回配置视图。
- **协议确认与检测**：阅读并同意服务协议后，满足条件即可开始检测。

### 1.3 交互要点

- 点击「批量导入企业」按钮，弹出批量导入企业弹窗。
- 弹窗顶部提供 Tab 切换：「手动输入企业名称」和「导入 Excel 文件」。
- 手动输入模式下，提供多行文本框，可换行批量输入企业名称；无内容时「确定提交」按钮禁用。
- 手动输入提交后，弹窗关闭，每行企业名称逐条加入企业列表，并模拟逐行查询。
- 查询模拟规则：仅输入一家时模拟查询成功；输入多家时随机分配成功/失败，并确保至少有一家成功、一家失败。
- 查询成功：统一社会信用代码输入框展示随机代码与绿色对钩，边框高亮。
- 查询失败：企业名称输入框下方展示红色提示「根据企业名称未查询到相关企业」，信用代码框边框变红。
- 查询失败状态下，用户重新输入并选择搜索建议后，该行恢复为查询成功状态并回填社会信用代码。
- 导入 Excel 模式下，支持上传导入文件、下载导入模版、查看已上传文件列表及删除操作。
- 已上传文件为空时，文件列表展示「暂无数据」空状态；「确定提交」按钮禁用。
- 企业名称输入时，满足条件（≥2 字符且不包含“公司”）触发 0.5s 防抖搜索，展示下拉联想列表。
- 关系类型区域提供「模板选择」下拉：默认「系统模板」，可选「精简模板」；切换模板后，表格中「关联元数据」列同步更新为对应模板数据。
- 关系类型区域「模板选择」右侧提供蓝色「模板配置」按钮，点击后当前页面主内容区切换为模板管理视图（保留左侧 AI 工坊侧边栏）。
- 模板管理视图顶部提供「返回配置页」按钮，点击后切回企业关联配置视图。
- 关系类型区域顶部提供场景 Tab 切换：「2-10家」「11-50家」「51-500家」，切换后表格中的「所属场景」列同步更新。
- 系统模板下，「核心管理」与「经营管理」的关联元数据已合并至「董监高」，表格不再单独展示这两行。
- 关系类型表格展示 8 类企业关系：董监高、股东、法人、机构隶属、涉诉关联、联系方式相同、知识产权公有、其他。
- 「开始检测」按钮在企业列表非空且已同意协议时可用。

### 2.2 数据来源

- **数据类型**：企业列表、搜索建议、配置参数
- **数据源**：页面内部状态生成示例数据
- **关键字段**：
  - `id`: 企业项唯一标识
  - `seq`: 序号
  - `name`: 企业名称
  - `creditCode`: 统一社会信用代码

### 2.3 内容示例

- 企业名称搜索示例：北京/上海/深圳等城市 + 关键词 + 科技有限公司 等后缀
- 关系类型表格示例（系统模板）：
  - 董监高：高风险，普通元数据，关联元数据合并了原董监高、核心管理、经营管理内容，包含董事长、董事会秘书、董事、股东监事、联席总裁、高级副总裁、总裁、总经理、总会计师、财务负责人、经营者等
  - 股东：高风险，普通元数据，关联元数据包含股东、投资人、工商股东、新三板股东、十大股东等
  - 法人：高风险，普通元数据，关联元数据为法定代表人
  - 机构隶属：中风险，普通元数据，关联元数据为分支机构
  - 涉诉关联：低风险，普通元数据，关联元数据为「在X份裁判文书中为同一方」
  - 联系方式相同：低风险，普通元数据，关联元数据为相同邮箱、电话号码、地址
  - 知识产权公有：低风险，普通元数据，关联元数据为共同拥有X份软件著作权/专利
  - 其他：低风险，普通元数据，关联元数据为其它、其他
- 关系类型表格示例（精简模板）：
  - 董监高：高风险，普通元数据，关联元数据包含董事、监事、高管、法定代表人、总经理等
  - 股东：高风险，普通元数据，关联元数据包含股东、投资人、工商股东、十大股东等
  - 法人：高风险，普通元数据，关联元数据为法定代表人
  - 机构隶属：中风险，普通元数据，关联元数据为分支机构、子公司
  - 涉诉关联：低风险，普通元数据，关联元数据为「在同一裁判文书中为同一方」
  - 联系方式相同：低风险，普通元数据，关联元数据为相同电话、邮箱
  - 知识产权公有：低风险，普通元数据，关联元数据为共同拥有X份专利
  - 其他：低风险，普通元数据，关联元数据为其它
- 默认关联层级：5层

## 🎨 布局与结构

### 3.1 整体布局

- **布局模式**：双栏（左侧固定侧边栏 + 右侧主内容区）
- **容器宽度**：侧边栏展开 200px / 收起 64px；主内容区流式自适应
- **关键尺寸**：
  - 侧边栏：`w-[200px]` / `w-16`，固定高度
  - 主内容区：左侧预留 `ml-[200px]` / `ml-16`

### 3.2 响应式适配

- 桌面端：完整双栏布局
- 平板/移动端：可折叠侧边栏，主内容区随动

## 🎨 视觉规范

### 4.1 设计规范来源

**设计规范来源**：内置 interface-design

**说明**：采用 Tailwind CSS 原子类实现，主色调为 `#1677FF`，背景色 `#F5F5F5`，文本色 `#262626` / `#595959` / `#8C8C8C`。

### 4.2 自定义设计要点

**自定义色彩**：
- `#1677FF`：主按钮、选中态、链接
- `#FF4D4F`：删除、必填、错误提示
- `#FA8C16`：标签背景
- `#F5F5F5`：页面背景

**自定义尺寸**：
- 步骤条圆点：32px
- 面板标题左侧色块：4px × 16px

### 4.3 组件状态

- **默认态**：输入框、复选框未选中
- **选中态**：复选框选中、菜单项高亮
- **悬停态**：按钮、菜单项背景变化
- **禁用态**：开始检测按钮在条件不满足时禁用
- **错误态**：股东范围输入校验失败时标红
