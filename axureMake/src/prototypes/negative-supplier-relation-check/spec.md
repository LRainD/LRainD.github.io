# 负面分供商清单关联校验

## 📋 业务与功能

### 1.1 核心目标

风控预警中心「分供商」域下的规则页面：**校验分供商是否与负面分供商清单存在关联关系**。页面整页复用组件 [risk-rule-config-page](file:///Users/liurundong/Desktop/云端演示项目/LRainD.github.io/axureMake/src/components/risk-rule-config-page/index.tsx)，本页只提供该规则独有的名称、说明、配置项取值与明细表格列。

### 1.2 功能清单

- **[规则选中]**：左侧规则树默认展开并选中「招投标 > 负面分供商清单关联校验」（P0）
- **[规则启停]**：规则名称右侧开关默认为「开」（P0）
- **[规则配置项]**：适用组织范围 / 下级独立配置 / 预警级别 / 是否去重 / 规则类型，按本规则取值展示（P0）
- **[明细表格]**：前 7 列为组件内置公共列（采购品类、采购类型&组织形式、招标方式&采购方式、预警类型、预警方式、通知方式、通知对象），其后 4 列（是否开启校验、校验阶段、是否校验组织、范围、股权关联阈值配置）由本页通过 `extraColumns` 追加 + 组件追加操作列（P0）
- **[配置提交]**：表格下方「添加一项」与「提交」按钮，由组件提供（P0）

### 1.3 交互要点

- 打开页面：左侧规则树选中本规则，右侧展示本规则配置，开关为「开」
- 通知对象：沿用组件内置公共列（单选下拉），本页不做覆盖
- 是否开启校验：`Switch` 开关，默认「开」
- 校验阶段：多选下拉，默认「报名资审」，可选报名资审 / 定标/成交报告 / 合同签订 / 履约评价
- 是否校验组织、范围：单元格内同一行两组控件，「组织:」下拉（默认中建一局）+「范围:」下拉（默认本级）
- 股权关联阈值配置：`Input` 带「大于」前置标签与 `%` 后缀，默认 30，表示股权占比大于该值即判定为关联
- 点击「添加一项」：表格追加一行空数据行
- 点击「提交」：暂为纯展示，无业务回调

### 2.2 数据来源

- **数据类型**：规则配置（规则名称/说明/配置项）+ 明细表格列定义

## ⚙️ Axure API 说明

### 5.4 配置项列表（configList）

| 配置项名称 | 类型 | 默认值 | 说明 |
|----------|------|-------|------|
| `ruleName` | `string` | `负面分供商清单关联校验` | 规则名称 |
| `ruleDescription` | `string` | `检查分供商是否与负面分供商清单存在关联关系` | 规则说明 |
| `defaultRuleEnabled` | `boolean` | `true` | 规则开关默认状态（开） |
| `config` | `RiskRuleConfigValues` | 见下 | 规则配置项默认值 |
| `commonColumns` | `RiskRuleCommonColumnsConfig` | 不传 | 7 个公共列全部沿用组件内置默认配置 |
| `extraColumns` | `ColumnsType<any>` | 4 列 | 本规则专有列 |
| `treeData` | `RiskRuleTreeGroup[]` | 默认树 + 「招投标」分组追加本规则 | 左侧规则树数据 |
| `defaultSelectedRuleKey` | `string` | `supplier_negative_relation_check` | 默认选中本规则 |
| `tableScrollX` | `number` | `1150` | 表格横向滚动宽度 |

**`config` 取值**：

```typescript
{
  orgScope: 'subordinate',      // 本下级
  subOrgConfig: 'disallow',     // 不允许
  warningLevel: 'medium',       // 中风险
  dedupe: 'no',                 // 不去重
  ruleType: '合规风险'
}
```

### 5.5 数据项列表（dataList）

**数据结构**：

```typescript
// 明细表格行：前 7 列由组件内置公共列渲染，其余列见 extraColumns
{
  category: string[];       // 采购品类（组件内置，多选）
  type: string[];           // 采购类型&组织形式（组件内置，多选）
  method: string[];         // 招标方式&采购方式（组件内置，多选）
  warningType: string;      // 预警类型（组件内置，单选）
  warningMethod: string;    // 预警方式（组件内置，单选）
  notifyMethod: string;     // 通知方式（组件内置，单选）
  notifyTarget: string;     // 通知对象（组件内置，单选）：资审经办 / 采购经理 / 项目经理 / 风控专员
  enabled: boolean;         // 是否开启校验
  checkStage: string;       // 校验阶段：报名资审 / 定标/成交报告 / 合同签订 / 履约评价
  checkOrgScope: {
    org: string;            // 组织：中建一局 / 中建一局一公司 / 测试组织-股份公司
    scope: string;          // 范围：本级 / 本下级
  };
  equityThreshold: string;  // 股权关联阈值配置：股权占比大于该值（%）判定为关联，默认 '30'
}
```
