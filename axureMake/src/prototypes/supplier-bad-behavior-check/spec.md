# 1. 需求背景

## 1.1 问题描述

分供商在投标、签约及履约过程中可能存在围标串标、履约失信、质量安全事故等不良行为。若仅靠人工核查，难以及时发现，容易让存在不良行为的分供商继续参与采购业务。

## 1.2 目标用户

- **集团/局级风控管理员**：统一配置不良行为校验规则，关注规则覆盖的组织与业务环节。
- **下级单位规则配置人员**：按本单位管理要求，逐条明细调整校验范围。
- **招投标业务经办 / 采购经理**：规则生效后被预警，关注提示是否准确。

## 1.3 业务目标

- 在关键业务环节自动校验分供商是否存在不良行为记录。
- 支持按组织范围配置校验口径，兼容不同层级单位的管理要求。
- 复用规则配置页组件，与其他风控规则保持一致的配置体验。

# 2. 产品定位

## 2.1 产品定义

「分供商是否存在不良行为」是风控预警中心规则管理下的业务规则配置页，用于配置校验分供商是否存在不良行为记录的策略。

## 2.2 核心价值

- **降低合规风险**：存在不良行为的分供商在关键节点被预警或拦截。
- **配置灵活**：可指定校验阶段与组织范围，逐行可配。
- **统一配置体验**：复用 `risk-rule-config-page` 组件，与同域其他规则一致。

# 3. 用户故事

## 3.1 规则配置

作为【集团风控管理员】
在【配置分供商是否存在不良行为规则】场景下，
为了【在关键环节识别存在不良行为的分供商】
需要【设置校验阶段与不良行为组织范围】。

**验收标准**

- 明细行可配置「是否开启校验」开关，默认开启。
- 明细行可多选「校验阶段」，至少支持报名-资审、资格审查、定标/成交报告。
- 明细行可配置多组「不良行为组织范围」，支持追加。

## 3.2 分行独立配置

作为【下级单位规则配置人员】
在【调整本单位校验口径】场景下，
为了【不影响其他明细行】
需要【逐行独立配置开关、校验阶段与组织范围】。

**验收标准**

- 各明细行的开关、校验阶段、组织范围互不影响。
- 新增明细行按默认值初始化。

## 4.2 功能详情

### 4.2.1 规则基础信息

- 规则名称：分供商是否存在不良行为。
- 规则说明：校验分供商在报名-资审、资格审查及定标/成交报告环节是否存在不良行为记录。
- 规则开关：默认开启。
- 配置项取值（与参照页面「禁用名录校验」一致）：
  - 适用组织范围：本下级
  - 下级独立配置：允许
  - 预警级别：中高风险
  - 检测场景：风控预警
  - 是否去重：不去重
  - 规则类型：合规风险

### 4.2.2 明细表格

表格共 12 列：7 个组件内置公共列 + 4 个规则专有列 + 1 个操作列。

- **是否开启校验**：开关，默认「开」，标题前置红色星号。
- **不限制品类**：开关，默认「关」，标题无星号，逐行独立；开启后该行校验不再受「采购品类」限制。
- **校验阶段**：多选下拉，默认「资格审查」，选项为报名-资审 / 资格审查 / 定标/成交报告，标题前置红色星号。
- **不良行为组织范围**：单元格内可配置多组「组织 + 范围」，组织为单选组织树，范围为「本级 / 本下级」，支持「添加」追加一组，标题前置红色星号。
- **操作**：编辑 / 删除，由组件提供。

### 4.3.5 交互说明

- 加载逻辑：页面打开即加载规则树并选中本规则，明细表格初始展示 1 条待填写行。
- 开关逻辑：「是否开启校验」可随时切换，同一表格内各行状态互不影响。
- 组织范围逻辑：默认一组「中国建筑股份有限公司 + 本下级」，点击「添加」追加一组空组织与空范围。
- 提交逻辑：点击「提交」当前仅展示，无业务回调。
- 行操作逻辑：编辑/删除由组件内置，原型阶段不接业务接口。

### 4.3.6 异常处理

- 必填项未选择：标题带红色星号，实际提交校验待接入。
- 组织范围为空：允许暂存，提交时需提示（待实现）。
- 提交失败：需提示失败原因并保留已填内容（待接入）。

### 4.3.7 性能要求

- 页面首屏加载时间 ≤ 2 秒。
- 表格操作（开关切换、下拉选择）响应时间 ≤ 0.3 秒。
- 添加行、添加组织范围响应时间 ≤ 0.5 秒。

# 5. 用户旅程

1. 风控管理员进入「风控预警中心 > 规则管理」。
2. 在左侧规则树「分供商」下点击「分供商是否存在不良行为」。
3. 查看规则配置项，确认适用组织范围、预警级别等基础配置。
4. 在明细表格中勾选采购品类、采购类型、招标方式等公共列。
5. 将「是否开启校验」保持为开，选择需要校验的阶段。
6. 配置「不良行为组织范围」，按需添加多组组织与范围。
7. 点击「提交」完成配置（原型阶段为展示态）。

# 6. 测试标准

## 6.1 功能测试标准

| 用例 | 前置条件 | 操作 | 预期结果 |
|------|----------|------|----------|
| 默认状态 | 打开页面 | 查看规则树与明细行 | 默认选中本规则，开关为开，不限制品类为关，校验阶段为资格审查 |
| 开关切换 | 明细行存在 | 关闭「是否开启校验」 | 开关显示「关」，仅该行变化 |
| 不限制品类 | 明细行存在 | 打开「不限制品类」 | 开关显示「开」，仅该行变化，采购品类不参与该行校验 |
| 校验阶段 | 明细行存在 | 多选校验阶段 | 下拉保留已选阶段 |
| 组织范围 | 默认一组 | 点击「添加」 | 新增一组组织 + 范围输入 |
| 添加明细 | 表格有 1 行 | 点击「添加一项」 | 追加一行，控件取默认值 |
| 多行独立 | 第 1 行开、第 2 行关 | 分别查看 | 两行按各自配置展示 |

## 6.2 性能测试标准

- 页面首屏加载 ≤ 2 秒。
- 开关、下拉操作响应 ≤ 0.3 秒。
- 表格横向滚动流畅，无明显卡顿。

## 6.3 用户体验测试标准

- 列顺序符合配置阅读顺序：是否开启校验 → 校验阶段 → 组织范围。
- 必填列标识清晰，不易漏填。

# 7. 非功能性需求

## 7.1 性能需求

- 单规则明细行数量在 50 行以内时，表格操作保持流畅。
- 组织树展开、下拉渲染无明显延迟。

## 7.2 可用性需求

- 开关、下拉、按钮具备清晰的默认、悬停、聚焦、禁用状态。
- 必填项与说明文案表述一致，避免歧义。

## 7.3 安全需求

- 规则配置仅授权管理员可修改。
- 配置变更需记录操作日志（组件已提供「操作日志」Tab）。
