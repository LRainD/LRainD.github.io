# 企业关联关系配置 - 规格文档

## 📋 业务与功能

### 1.1 核心目标

企业关联关系配置单页面用于直接管理平台内唯一的企业关系检测规则。用户无需进入模板列表，打开页面即可对企业关系在不同企业数量场景下的检测规则进行配置。

### 1.2 功能清单

- **企业关联关系配置表格**：以表格形式展示所有企业关系。
- **每个企业关系横向展示三个企业数量场景**（2-10家、11-50家、51-500家）的配置。
- **每个场景下可独立配置**：元数据类型、关联元数据。
- **支持新增企业关系**、删除关系。
- **本页面为详情查看态**：所有操作入口置灰禁用，仅可浏览配置内容。

### 1.3 交互要点

- 页面打开时直接加载默认企业关系数据。
- 每个企业关系占据合并后的三行，分别对应 2-10家、11-50家、51-500家三个所属场景。
- "分类名称"、"企业关系名称"、"风险等级"、"hover说明"、"操作"五列跨三行合并显示，其余列为每个场景单独一行。
- "分类名称"使用下拉选择，选项为：人员关系、机构隶属、其他。
- "风险等级"使用下拉选择，选项为：高风险、普通风险。
- "hover说明"使用文本输入框，用于填写当前企业关系的悬浮说明文案。
- 修改任意场景下的元数据类型或关联元数据时，仅更新当前场景的配置，不影响其他场景。
- 点击"新增企业关系" → 在表格末尾新增一条空配置的企业关系。
- 点击"删除" → 移除当前企业关系。
- 点击右上角"提交"按钮 → 模拟保存，弹出"保存成功"提示。
- **详情查看态**：
  - 本页面固定为「查看」模式，不提供编辑入口。
  - "新增企业关系"、"提交"按钮置灰禁用；表格内"分类名称"、"企业关系名称"、"风险等级"、"hover说明"、"元数据类型"、"关联元数据"等表单控件全部禁用；"删除"操作显示为灰色不可点击文本。
- **左侧菜单**：本页面属于「配置管理」下的二级菜单「企业关联关系配置」。左侧菜单中「配置管理」分组默认展开，子项「企业关联关系配置」高亮选中。
- **顶部机构栏**：本页面隐藏平台下拉、机构编码与上级组织信息栏。

## 📊 内容规划

### 2.1 信息架构

```
企业关联关系配置页面
└── 企业关联关系配置区域
    ├── 新增企业关系按钮
    └── 企业关联关系配置表格
        ├── 分类名称（跨三行合并）
        ├── 企业关系名称（跨三行合并）
        ├── 风险等级（跨三行合并）
        ├── hover说明（跨三行合并）
        ├── 所属场景
        ├── 元数据类型
        ├── 关联元数据
        └── 操作（跨三行合并）
```

### 2.2 数据来源

- **数据类型**：配置数据。
- **数据源**：当前使用本地示例数据（DEFAULT_RELATIONS）。
- **关键字段**：
  - `EnterpriseRelation.id`：关系唯一标识。
  - `EnterpriseRelation.categoryName`：分类名称，可选值：人员关系、机构隶属、其他。
  - `EnterpriseRelation.name`：企业关系名称。
  - `EnterpriseRelation.riskLevel`：风险等级，可选值：高风险、普通风险。
  - `EnterpriseRelation.hoverDesc`：hover说明，文本输入。
  - `EnterpriseRelation.configs`：按场景划分的配置对象，键为 `2-10`、`11-50`、`51-500`。
  - `SceneConfig.metaType`：元数据类型。
  - `SceneConfig.relatedMeta`：关联元数据数组。

### 2.3 内容示例

- 默认企业关系：
  - 人员关系：董监高、法定代表人、股东
  - 机构隶属：分支机构
  - 其他：相同电话号码、相同邮箱、相同地址、涉诉关联、知识产权公有
- 默认关联元数据示例：董事长、董事、独立董事、股东、法定代表人、分支机构、有相同的电话号码、有相同的邮箱、有相同的地址、在X份裁判文书中为同一方、共同拥有X份软件著作权、共同拥有X份专利等。

## 🎨 布局与结构

### 3.1 整体布局

- **布局模式**：单栏布局。
- **容器宽度**：流式，跟随运营后台布局组件自适应。
- **关键尺寸**：
- 企业关联关系配置表格最小宽度：840px。
- 表格纵向最大高度：520px，支持纵向滚动。
- 分类名称列宽度：120px，企业关系名称列宽度：160px，风险等级列宽度：120px，hover说明列宽度：160px，操作列宽度：90px。
- 所属场景、元数据类型、关联元数据按常规列宽自适应。

### 3.2 响应式适配

- 桌面端（≥1000px）：完整展示企业关联关系配置表格。
- 较小屏幕：表格通过横向滚动查看完整内容。

## 🎨 视觉规范

### 4.1 设计规范来源

**设计规范来源**：内置 interface-design

### 4.2 自定义设计要点

**自定义色彩**：
- 操作链接色：`#1890ff`
- 删除操作色：`#f5222d`

**自定义尺寸**：
- 场景配置标签字号：12px
- 表格单元格字号：13px

### 4.3 组件状态

- **默认态**：表单控件显示当前配置值。
- **悬停态**：操作链接悬停时颜色变浅。
- **聚焦态**：Input、Select 聚焦时显示 Ant Design 默认聚焦样式。
- **编辑态**：用户修改任一场景配置时，该单元格即时响应并更新状态（本页面当前仅作查看态展示）。
- **查看态**：页面整体进入只读模式，所有按钮与表单控件禁用，操作列删除入口置灰，仅用于展示配置内容。
