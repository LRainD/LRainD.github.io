# 1. 需求背景

## 1.1 问题描述

「禁用名录校验」规则当前只检查明细行已勾选采购品类下的禁用分供商。若某分供商在 A 品类被禁用，但该明细行只勾选了 B 品类，系统不会预警，存在合规漏检风险。

部分单位要求：只要分供商在禁用名录中，不论走什么采购品类，都应拦截。因此需要在明细配置中提供一个可选的「不区分品类校验」开关。

## 1.2 目标用户

- **集团/局级风控管理员**：统一配置禁用名录校验规则，关注规则能否覆盖全部采购品类。
- **下级单位规则配置人员**：按本单位管理要求，逐条明细调整校验范围。
- **招投标业务经办 / 采购经理**：规则生效后被预警或拦截，关注提示是否准确。

## 1.3 业务目标

- 支持「按品类校验」与「不区分品类校验」两种模式，覆盖不同管理口径。
- 新开关默认关闭，存量规则升级后行为不变，避免误伤。
- 开关按明细行独立配置，不影响同一规则下的其他明细行。

# 2. 产品定位

## 2.1 产品定义

「禁用名录校验」是风控预警中心规则管理下的业务规则配置页，用于配置在招投标场景中校验分供商是否命中禁用名录的策略。

## 2.2 核心价值

- **降低合规风险**：命中禁用名录的分供商在关键业务节点被预警或拦截。
- **配置灵活**：按品类精细校验，或全品类统一拦截，逐行可配。
- **存量兼容**：新增开关默认关闭，已有规则无需调整。
- **统一配置体验**：复用规则配置页组件，与同域其他规则保持一致。

## 2.3 产品差异化

相较于「负面分供商清单校验」等同类规则页，本规则新增「不区分品类校验」能力，在同一页面内同时支持「品类维度」与「全品类维度」两种校验口径，无需拆分两套规则。

# 3. 用户故事

## 3.1 规则配置

作为【集团风控管理员】
在【配置禁用名录校验规则】场景下，
为了【让禁用分供商在所有采购品类下都被拦截】
需要【在明细行打开「不区分品类校验」开关】。

**验收标准**

- 明细行存在「不区分品类校验」开关，位于「禁用名录是否开启校验」之后、「禁用名录组织范围」之前。
- 开关默认关闭，可切换为开启，逐行独立。
- 开启后该行校验不再受「采购品类」限制。

**技术实现要点**

- 通过 `extraColumns` 在公共列后追加该开关列。
- 行数据字段 `ignoreCategory: boolean`，默认 `false`。

## 3.2 存量规则兼容

作为【下级单位规则配置人员】
在【升级后查看已有规则】场景下，
为了【避免规则行为突然变化】
需要【新开关默认关闭且存量配置保持原有效果】。

**验收标准**

- 开关初始为关。
- 关闭状态下，校验逻辑与升级前一致（仅匹配勾选品类）。

## 3.3 按品类校验

作为【采购业务经办】
在【规则未开启不区分品类校验】场景下，
为了【只在关注的品类上被校验】
需要【系统仅在该行勾选的采购品类内查询禁用名录】。

**验收标准**

- 分供商在未勾选品类被禁用时不预警。
- 分供商在已勾选品类被禁用时按预警类型给出预警/拦截。

## 4.2 功能详情

### 4.2.1 规则基础信息

- 规则名称：禁用名录校验。
- 规则说明：空。
- 规则开关：默认开启。
- 配置项取值：
  - 适用组织范围：本下级
  - 下级独立配置：允许
  - 预警级别：中高风险
  - 检测场景：风控预警
  - 是否去重：不去重
  - 规则类型：合规风险

### 4.2.2 明细表格

表格共 11 列：7 个组件内置公共列 + 3 个规则专有列 + 1 个操作列。

- **禁用名录是否开启校验**：开关，默认「开」，标题前置红色星号。
- **不区分品类校验**：开关，默认「关」，标题无星号，逐行独立。
- **禁用名录组织范围**：单元格内可配置多组「组织 + 范围」，组织为单选组织树，范围为「本级 / 本下级」，支持「添加」追加一组。
- **操作**：编辑 / 删除，由组件提供。

### 4.2.3 「不区分品类校验」校验逻辑

| 开关状态 | 校验范围 | 命中条件 |
|----------|----------|----------|
| 关（默认） | 该行勾选的采购品类 | 分供商在命中品类下存在禁用记录 |
| 开 | 全部品类 | 分供商在任意品类下存在禁用记录 |

- 开关只影响所在明细行，不影响其他行与规则级配置。
- 开启后「采购品类」仍保留可勾选、可修改，但不参与该行校验。
- 开关与「禁用名录是否开启校验」的关系：后者关闭时不执行校验，前者不生效。

- 开关逻辑：「不区分品类校验」可随时切换，同一表格内各行状态互不影响。
- 校验逻辑：开关关闭时按 `category` 匹配禁用记录；开启时忽略 `category`，任意品类存在禁用记录即命中。

- 组织范围为空：允许暂存，提交时需提示（待实现）。
- 开关开启但采购品类仍为空：不阻断保存，因为该行品类已不参与校验。
- 提交失败：需提示失败原因并保留已填内容（待接入）。

##### 性能要求

- 页面首屏加载时间 ≤ 2 秒。
- 表格操作（开关切换、下拉选择）响应时间 ≤ 0.3 秒。
- 添加行、添加组织范围响应时间 ≤ 0.5 秒。

# 5. 用户旅程

## 5.1 配置「不区分品类校验」的旅程

1. 风控管理员进入「风控预警中心 > 规则管理」。
2. 在左侧规则树「招投标」下点击「禁用名录校验」。
3. 查看规则配置项，确认适用组织范围、预警级别等基础配置。
4. 在明细表格中勾选采购品类、采购类型、招标方式等公共列。
5. 将「禁用名录是否开启校验」保持为开。
6. 在需要全品类拦截的明细行，将「不区分品类校验」切换为开。
7. 配置「禁用名录组织范围」，按需添加多组组织与范围。
8. 点击「提交」完成配置（原型阶段为展示态）。

## 5.2 校验生效旅程（业务侧）

1. 业务人员在招投标场景发起采购业务。
2. 系统读取规则明细，判断该行「禁用名录是否开启校验」。
3. 若开启，再判断「不区分品类校验」：
   - 关：仅在该行勾选的采购品类下查询禁用名录。
   - 开：在全部品类下查询该分供商是否存在禁用记录。
4. 命中后按「预警类型」「预警方式」输出预警或拦截，并按「通知方式」「通知对象」通知相关人员。

# 6. 测试标准

## 6.1 功能测试标准

| 用例 | 前置条件 | 操作 | 预期结果 |
|------|----------|------|----------|
| 默认状态 | 打开页面 | 查看明细行开关 | 「禁用名录是否开启校验」为开，「不区分品类校验」为关 |
| 开关切换 | 明细行存在 | 打开「不区分品类校验」 | 开关显示「开」，仅该行变化 |

| 开启态校验 | 开关为开，仅勾选物资 | 分供商在专业分包被禁用 | 命中并预警 |
| 多行独立 | 第 1 行开、第 2 行关 | 分别触发校验 | 两行按各自开关状态执行 |
| 组织范围 | 默认一组 | 点击「添加」 | 新增一组组织 + 范围输入 |
| 添加明细 | 表格有 1 行 | 点击「添加一项」 | 追加一行，开关取默认值 |

## 6.2 性能测试标准

- 页面首屏加载 ≤ 2 秒。
- 开关、下拉操作响应 ≤ 0.3 秒。
- 表格横向滚动流畅，无明显卡顿。

## 6.3 用户体验测试标准

- 开关位置符合配置阅读顺序：校验开关 → 不区分品类 → 组织范围。
- 开启「不区分品类校验」后，用户能理解采购品类不再生效。
- 必填列标识清晰，不易漏填。

## 6.4 线上监控指标

- 规则命中次数与命中率。
- 开启「不区分品类校验」的规则/明细行数量。
- 因开启该开关新增的预警量。

# 7. 非功能性需求

## 7.1 性能需求

- 单规则明细行数量在 50 行以内时，表格操作保持流畅。
- 组织树展开、下拉渲染无明显延迟。

## 7.2 可用性需求

- 开关、下拉、按钮具备清晰的默认、悬停、聚焦、禁用状态。
- 必填项与说明文案表述一致，避免歧义。

## 7.3 安全需求

- 规则配置仅授权管理员可修改。
- 配置变更需记录操作日志（组件已提供「操作日志」Tab）。

## 7.4 数据统计需求

- 统计各规则「不区分品类校验」的开启比例。
- 统计开关开启前后预警量变化，用于评估规则合理性。

# 9. 附录

## 9.1 关键术语表

| 术语 | 定义 |
|------|------|
| 禁用名录 | 被禁止参与采购业务的分供商名单，按品类记录禁用关系 |
| 不区分品类校验 | 开启后忽略采购品类，只要分供商在禁用名录中即命中 |
| 明细行 | 规则下的一条校验策略，包含品类、方式、通知、组织范围等配置 |
