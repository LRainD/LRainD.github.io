# 应用字段配置 PRD

## 1. 文档信息

- **文档名称**：应用字段配置需求文档
- **适用页面**：应用字段配置
- **目标读者**：前端研发、后端研发、测试、产品
- **文档状态**：评审稿

---

## 2. 背景与目标

### 2.1 背景

合同模板系统需要为每个应用单独维护其可使用的系统标准字段。运营管理员在「应用字段配置」页面内先查看已接入应用列表，再切换到字段配置视图，为指定应用配置在创建范本时支持选用的字段，字段值将从应用内直接读取。

### 2.2 目标

- 提供已接入应用的列表查看能力。
- 支持新增应用到系统字段管理范围。
- 提供应用字段列表的查看能力。
- 支持新增字段并配置字段属性。
- 支持为字段设置富文本说明。
- 支持为字段设置文本标签，便于分类识别。
- 支持配置字段适用的业务类型范围。
- 支持提交保存字段配置。

---

## 3. 术语定义

| 术语 | 说明 |
|------|------|
| 应用编码 | 应用在系统中的唯一业务编码 |
| 应用标识 | 应用在系统中的唯一标识 |
| 范本内展示名称 | 字段在合同范本中展示给用户的名称 |
| 应用字段名称 | 应用代码内定义的字段标识名称 |
| 字段类型 | 字段或表单，决定字段在范本中的使用方式 |
| 显示类型 | 可编辑输入框或标准替换标识，决定字段的展示形态 |
| 标准替换标识 | 系统预定义的标准占位符 |
| 字段说明 | 对字段业务含义的富文本说明 |
| 字段标签 | 对字段的简短分类标识，非必填，最多 20 个字符，在列表中以蓝色小 Tag 展示 |
| 适用业务类型 | 字段可被使用的业务分类范围，数据来源为「业务类型管理」菜单中维护的分类数据 |

## 5. 功能需求

### 5.1 应用列表视图

#### 5.1.1 功能描述

「应用字段配置」页面的默认视图，以表格形式展示已接入系统字段管理的应用列表，支持查看应用基本信息、新增应用，并作为切换到字段配置视图的入口。

#### 5.1.2 列表字段

| 字段 | 说明 |
|------|------|
| 应用名称 | 应用的中文名称 |
| 应用编码 | 应用的业务编码 |
| 最近更新时间 | 应用字段配置最后一次更新时间 |
| 最近更新人 | 应用字段配置最后一次更新人，展示姓名 |
| 操作 | 包含「编辑」入口，点击后切换到字段配置视图 |

#### 5.1.3 新增应用

- 入口：应用列表视图标题栏「新增应用」按钮。
- 点击后弹出新增应用弹窗。
- 弹窗字段：

| 字段 | 必填 | 规则 |
|------|------|------|
| 应用名称 | 是 | 必填，为空时提示「请输入应用名称」，最大长度 50 个字符 |
| 应用编码 | 是 | 必填，为空时提示「请输入应用编码」 ，最大长度 50 个字符 |

- 弹窗底部包含「确认」「取消」按钮，右上角包含关闭按钮。
- 点击「确认」后校验表单，校验通过后在列表顶部新增一条记录。
- 点击「取消」或关闭弹窗时，重置表单内容。

#### 5.1.4 进入字段配置视图

- 入口：应用列表操作列「编辑」按钮。
- 点击后页面切换至字段配置视图，并携带当前应用信息：应用名称、应用编码、应用标识。

### 5.2 应用字段配置

#### 5.2.1 页面入口

用户从应用列表视图点击某一行「编辑」按钮进入字段配置视图。页面需携带当前应用信息：应用名称、应用编码、应用标识。进入页面后，页面头部展示当前应用名称。

#### 5.2.2 页面布局

页面整体布局如下：

- 左侧边栏：运营后台菜单（当前选中「系统字段」）。
- 主体卡片区域：
  - 页面头部：左侧展示当前应用名称与配置说明；右侧为「返回」按钮。
  - Tab 切换：字段配置 / 适用配置。
  - 表格区域：根据当前 Tab 展示不同字段。
  - 底部操作区：字段配置 Tab 展示「提交」按钮。

#### 5.2.3 字段配置

##### 功能描述

以表格形式展示当前应用下已配置的系统字段，支持新增字段、设置字段说明、删除字段和提交保存。

##### 列表字段

| 字段 | 说明 |
|------|------|
| 范本内展示名称 | 字段在范本中展示的名称，新增行可编辑，已有行置灰 |
| 应用字段名称（应用代码内定义字段名称） | 应用代码内定义的字段名称，新增行可编辑，已有行置灰 |
| 字段类型 | 字段或表单，新增行可编辑，已有行置灰 |
| 显示类型 | 可编辑输入框或标准替换标识，新增行可编辑，已有行置灰 |
| 字段说明 | 已设置显示「查看字段说明」按钮；未设置显示「—」 |
| 字段标签 | 已设置以蓝色小 Tag 展示标签文本；未设置显示「—」 |
| 操作 | 包含「设置字段说明」「设置字段标签」「删除」三个入口 |

##### 行状态规则

- 已有数据行（非新增行）为置灰状态，所有字段不可编辑。
- 点击表格底部「添加一行」，在表格末尾新增一条可编辑行。
- 新增行的所有字段可输入/选择。
- 点击「提交」后，所有新增行变为已保存状态，字段置灰锁定。
- 提交成功后，页面顶部弹出「保存成功」提示。

##### 字段类型与显示类型联动

- 字段类型为「字段」时，显示类型可选：可编辑输入框、标准替换标识。
- 字段类型为「表单」时，显示类型固定为「标准替换标识」，且下拉选项仅保留该选项。
- 当字段类型从「字段」切换为「表单」时，若当前显示类型为「可编辑输入框」，系统自动修正为「标准替换标识」。

##### 新增字段

- 入口：表格底部「添加一行」按钮。
- 新增行字段：

| 字段 | 必填 | 规则 |
|------|------|------|
| 范本内展示名称 | 是 | 必填，为空时提示「请输入范本内展示名称」 |
| 应用字段名称 | 是 | 必填，为空时提示「请输入应用字段名称」 |
| 字段类型 | 是 | 必填，默认值为「字段」；可选枚举：字段、表单 |
| 显示类型 | 是 | 必填，默认值为「可编辑输入框」；可选枚举：可编辑输入框、标准替换标识；当字段类型为「表单」时，显示类型固定为「标准替换标识」且不可切换 |

- 提交规则详见 [5.2.3.6 提交保存](#5236-提交保存)。

##### 设置字段说明

- 入口：字段配置表格操作列「设置字段说明」按钮。
- 点击后弹出富文本编辑器弹窗，使用前端通用富文本编辑器。
- 弹窗底部左侧展示红色「删除」按钮，右侧包含「取消」「保存」按钮。
- 当字段说明为空时，「删除」按钮禁用。
- 点击「删除」后，在按钮附近弹出二次确认气泡，标题为「确认删除」，内容为「是否确认删除该字段说明？」，底部包含「确认」「取消」按钮。
- 点击「确认」后，将该字段的字段说明置空，关闭弹窗，页面顶部弹出「删除成功」提示；点击「取消」或点击弹窗外部区域，关闭确认气泡，不执行删除。
- 点击「保存」后，该行的「字段说明」列变为「查看字段说明」按钮。
- 保存成功后，页面顶部弹出「保存成功」提示。

##### 查看字段说明

- 入口：字段配置表格「字段说明」列的「查看字段说明」按钮。
- 点击后弹出只读弹窗，以富文本渲染形式展示字段说明内容。
- 弹窗右上角可关闭，点击遮罩或关闭按钮均可关闭弹窗。

##### 设置字段标签

- 入口：字段配置表格操作列「设置字段标签」按钮。
- 点击后弹出文本输入弹窗。
- 弹窗字段：

| 字段 | 必填 | 规则 |
|------|------|------|
| 字段标签 | 否 | 非必填，最多输入 20 个字符，超出时提示「字段标签最多输入 20 个字符」 |

- 弹窗底部包含「取消」「保存」按钮，右上角包含关闭按钮。
- 点击「保存」后，该行的「字段标签」列更新为已输入文本，并以蓝色小 Tag 展示。
- 清空输入框并保存后，视为未设置，该行的「字段标签」列显示「—」。
- 保存成功后，页面顶部弹出「保存成功」提示。
- 点击「取消」或关闭弹窗时，不保存修改内容。

##### 删除字段

- 入口：字段配置表格操作列「删除」按钮。
- 前置校验：
  - 删除前判断该字段是否已被模板使用。
  - 若已被模板使用，点击「删除」后直接弹出错误提示弹窗，标题为「无法删除」，内容为「该字段已被模板使用，无法删除」，底部仅包含「知道了」按钮；关闭弹窗后不执行删除。
  - 若未被模板使用，进入二次确认流程。
- 交互规则：
  - 点击「删除」并通过前置校验后，在按钮附近弹出聊天框气泡样式的二次确认弹窗。
  - 弹窗标题为「确认删除」，内容为「删除后无法恢复，是否确认删除？」。
  - 弹窗底部包含「取消」「确认」按钮。
  - 点击「确认」后，从表格中移除该行数据，并调用后端接口删除。
  - 点击「取消」或点击弹窗外部区域，关闭弹窗，不执行删除。

##### 提交保存

- 入口：字段配置 Tab 底部「提交」按钮。
- 提交规则：
  - 点击后校验所有新增行必填字段。
  - 校验通过后，所有新增行变为已保存状态，字段置灰锁定。
  - 提交成功后，页面顶部弹出「保存成功」提示。
  - 提交失败时保留表单状态并提示错误信息。

#### 5.2.4 适用业务类型配置

##### 功能描述

配置每个字段适用的业务类型范围。切换到「适用配置」Tab 后，表格仅保留「范本内展示名称」「适用业务类型」「操作」三列。

##### 列表字段

| 字段 | 说明 |
|------|------|
| 范本内展示名称 | 字段在范本中展示的名称 |
| 适用业务类型 | 已设置时以灰色小 Tag 展示完整层级路径；未设置时显示「—」 |
| 操作 | 包含「设置适用类型」入口 |

##### 设置适用业务类型

- 入口：适用配置表格操作列「设置适用类型」按钮。
- 点击后弹出业务类型级联多选弹窗。
- 弹窗内展示业务类型树，支持三级结构；树形数据来源于「业务类型管理」菜单中维护的分类数据。
- 选择规则：
  - 勾选父级时，只选中父级本身，不自动勾选其子级。
  - 当某个父级下的所有直接子级都被勾选时，该父级自动被勾选。
  - 取消勾选某个子级时，若其父级已被自动勾选，则父级同步取消勾选。
  - 上述规则逐级向上生效，支持三级结构。
- 已选项在弹窗内以灰色小 Tag 展示完整层级路径，用「/」分隔，例如「招标应用/公开招标/劳务分包」。
- 弹窗底部包含「取消」「保存」按钮。
- 点击「保存」后，表格「适用业务类型」列更新为已选类型。
- 保存成功后，页面顶部弹出「保存成功」提示。

## 6. 异常处理

| 场景 | 处理方式 |
|------|----------|
| 新增应用必填字段为空 | 表单项自身展示错误提示，阻止确认 |
| 新增字段必填字段为空 | 表单项自身展示错误提示，阻止提交 |
| 字段类型为「表单」时切换显示类型 | 系统自动修正为「标准替换标识」 |
| 字段标签超过 20 个字符 | 表单项自身展示错误提示，阻止保存 |
| 删除已有字段 | 若字段已被模板使用，弹出错误提示弹窗并禁止删除；否则弹出气泡二次确认弹窗，点击「确认」后从列表移除 |

## 8. 非功能需求

### 8.1 历史数据迁移

页面上线前，需将历史已配置数据迁移至新系统，确保业务连续性：

- **系统字段迁移**：
  - 将原有系统中各应用已配置的系统字段数据（字段名称、字段类型、显示类型）完整迁移至「应用字段配置」页面。
  - 迁移后字段在列表中展示为已保存状态，不可直接编辑，仅支持设置字段说明、字段标签、适用业务类型及删除（受删除校验规则约束）。
  - 若历史字段存在字段说明或标签信息，迁移后应在对应列正常展示。

- **适用业务类型初始化**：
  - 将历史字段已绑定的适用业务类型数据，按「业务类型管理」中维护的分类树结构进行映射与初始化。
  - 若历史业务类型在当前分类树中已不存在，则标记为待处理或按产品侧确认的规则进行兼容，确保列表中展示完整可识别的业务类型路径。
  - 初始化完成后，运营管理员可在「适用配置」Tab 中查看并调整各字段的适用业务类型范围。

- **迁移校验**：
  - 迁移过程需记录日志，便于排查异常数据。
  - 迁移完成后需进行数据完整性校验，确保系统字段总数、适用业务类型绑定关系与历史数据一致。
