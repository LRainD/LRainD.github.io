# 派发任务 (PG-020/PG-021) 规格文档

## 1. 页面目标
统一承载自查、互查、稽查的待派发和待发起数据，以及检查项模板与人员选择、批量派发、派发调整和批次结果。

## 2. 页面布局
- **顶部导航**：使用 `CentralizedProcurementLayout` 通用布局。
- **面包屑**：首页 / 招标采购 / 一单一检 / 派发任务。
- **核心内容区**：
    - **顶部页签 (Tabs)**：自查、互查、稽查、批次/派发记录；自查、互查、稽查页签内提供“全部、待派发、已派发”二级页签，便于快捷查询任务状态。
    - **搜索过滤区 (Card)**：提供招标/采购编号、招标/采购名称、合同编号、合同名称、合同所属组织、当前状态的筛选，状态选项根据 activeTab 动态匹配。筛选项按四列栅格排列，标签与输入框/下拉框在同一行，标签保持不换行，控件自适应占满剩余宽度；筛选卡片及控件默认使用 `#d9d9d9` 细边框，控件悬停边框使用 `#4096ff`。
    - **列表展示区 (Card)**：展示待处理单据，支持批量操作。
    - **人工指派详情页**：从单条或批量人工指派入口进入，替代右侧抽屉，在同一页面完整展示所选合同、检查项模板与可选合规人员。

## 3. 核心功能说明

### 3.1 自查页签
- **视图**：待派发、已派发/记录。
- **核心逻辑**：
    - 展示“自查待派发”任务。
    - 人工指定或系统均衡派发。
    - 校验合规专员资格（启用状态、组织匹配）。

### 3.2 互查页签
- **视图**：待发起、待派发、已派发/记录。
- **核心逻辑**：
    - **待发起**：满足互查准入条件的合同，支持批量发起。
    - **抽取规则**：按比例、按数量或人工勾选。
    - **派发逻辑**：系统均衡或人工指定，执行跨单位回避校验。

### 3.3 稽查页签
- **视图**：待发起、待派发、已派发/记录。
- **核心逻辑**：
    - **待发起**：满足稽查准入条件的合同。
    - **双重回避**：专家账号所属组织不得与合同所属单位相同，且不得是该合同原互查人员。

### 3.4 批次/派发记录
- 展示各类检查批次的规则、抽取结果、成功/失败明细。

### 4.2 自查页签状态

自查页签通过状态名称包含“自查”筛选任务，共支持 9 个状态：

- **待派发/待处理**：自查待派发、自查待处理。
- **检查中**：自查中。
- **异常及回退**：自查回退审批中、自查已收回。
- **处置及复核**：自查待处置、自查待复核、自查复核不通过。
- **申诉**：自查结论申诉中。

当前列表完整展示 9 个自查状态的示例数据。自查待派发支持“人工指派”，其余未办结的自查状态支持“调整派发”。

### 4.3 互查页签状态

互查页签通过状态名称包含“互查”或状态为“待互查”筛选任务，共支持 9 个状态：

- **待发起**：待互查，满足互查准入条件，等待发起。
- **待派发/待处理**：互查待派发、互查待处理。
- **检查中**：互查中。
- **异常及回退**：互查回退审批中。
- **处置及复核**：互查待处置、互查待复核、互查复核不通过。
- **申诉**：互查结论申诉中。

当前列表完整展示 9 个互查状态的示例数据。待互查支持单条或批量“发起并派发”，互查待派发支持“人工指派”，其余已派发状态支持“调整派发”。

### 4.4 稽查页签状态

稽查页签通过状态名称包含“稽查”、状态为“待稽查”或状态为“检查已完成”筛选任务，共支持 10 个状态：

- **待发起**：待稽查，满足稽查准入条件，等待发起。
- **待派发/待处理**：稽查待派发、稽查待处理。
- **检查中**：稽查中。
- **异常及回退**：稽查回退审批中。
- **处置及复核**：稽查待处置、稽查待复核、稽查复核不通过。
- **申诉**：稽查结论申诉中。
- **完成**：检查已完成。

当前列表完整展示 10 个稽查状态的示例数据。待稽查支持单条或批量“发起并派发”，稽查待派发支持“人工指派”，其余未办结的稽查状态支持“调整派发”；检查已完成仅供查看，不可勾选或派发。

### 4.5 批次/派发记录页签状态

批次/派发记录页签展示批次状态，不展示合同任务状态。当前 Mock 数据包含 2 条记录，状态均为“全部成功”，检查类型覆盖自查和互查；当前未提供稽查批次示例。

- **全部成功**：批次内全部任务派发成功，当前 Mock 数据使用此状态。
- **非全部成功**：批次存在失败任务时使用警告样式，当前未配置具体失败示例或失败明细入口。

当前页面未实现批次创建中、抽取中、部分成功、全部失败、已取消等更细分状态，也未将合同任务状态筛选条件应用于批次记录列表。

## 5. 列表字段定义
| 字段名 | 说明 |
| --- | --- |
| 序号 | 自动生成的行号 |
| 招标/采购编号 | 招标项目的流水编号（如 cscec202608310000004851） |

| 合同编号 | 合同唯一标识 |
| 合同名称 | 合同全称 |
| 招采经办人 | 招标采购经办人，按“姓名（账号）”展示，例如“张三（zhangsan）” |
| 合同经办人 | 合同经办人，按“姓名（账号）”展示，例如“张三（zhangsan）” |
| 当前状态/阶段 | 任务目前在业务流程中所处的状态及前序最新记录 |
| 评审完成时间 | 招标项目的最终评审/定标时间 |
| 合同所属组织 | 合同所属组织单位 |

| 派发模式 | 自动派发、人工指定 |
| 操作 | 待互查、待稽查显示“发起并派发”；各类待派发任务显示“人工指派”；已派发未办结任务显示“调整派发”；检查已完成仅显示短横线，固定在表格右侧 |

### 5.1 派发状态二级页签
- **全部**：展示当前检查类型全部相关合同及任务状态；互查“待互查”和稽查“待稽查”候选合同仅在此视图出现。
- **待派发**：仅展示自查待派发、互查待派发或稽查待派发任务。
- **已派发**：展示已流转至待处理、检查中、处置、复核、申诉或已完成的任务；不新增“已派发”主状态，未办结任务可通过“调整派发”重新选择办理人。
- **切换规则**：切换一级或二级页签后，清空已勾选任务与当前状态下拉条件，避免跨任务类型或跨状态误操作。

## 6. 人工指派详情页
- **顶部操作区**：提供返回派发任务、取消、确认指派并流转；确认前必须选择一名办理人。
- **所选合同单据模块**：展示本次待派发的合同列表，并在单选时补充项目名称、原任务模板、合同经办人。
- **检查项模板模块**：必须选择一个检查项模板；点击“选择检查项模板”打开弹窗，弹窗仅展示“检查模板”页面中状态为“已发布”且适用于当前检查类型（自查、互查或稽查）的模板，支持按模板名称检索、单选和分页。确认选择后仅回显模板名称，并展示该模板全部启用检查项的明细表。
- **检查项明细字段**：展示序号、检查阶段、检查项、检查标准、检查方式、风险等级和必检标识；不展示版本号、生效时间、模板说明及检查项数量等非执行字段。
- **可选合规人员模块**：基于当前检查类型展示合规专员、合规专家或稽查专家，展示姓名、账号、人员类型、所属组织、资质所属组织、待办任务、执行中和临期超时等基本信息。
- **人员选择与分页**：人员表格仅允许单选，默认每页 5 人，支持切换每页数量并展示总人数。
- **筛选边界**：候选人员已按当前检查类型、组织资质与回避规则筛选；推荐人员以标签突出显示。

## 7. 交互细节
- **批量操作**：仅允许选择待发起或待派发任务；待发起与待派发不可混合，跨组织批量发起并派发或调整派发禁止提交。
- **模板校验**：确认指派前必须选择模板；未选择时提示“请选择检查项模板”。
- **模板选择**：弹窗内选择仅作为待确认结果，点击“确定选择”后才更新当前指派任务引用的模板；取消弹窗时保留原有选择。
- **回避校验**：在派发确认前实时执行，不符合条件的列出原因。
- **状态流转**：当前原型在派发确认后仅提示“任务状态已流转至相应办理状态”，关闭操作面板并清除勾选，不持久化更新任务状态、办理人或批次记录；产品目标状态为待派发/待发起进入对应的待处理状态。
- **页面切换**：进入人工指派后隐藏派发列表，返回或取消后回到原列表并清空模板与人员选择。
