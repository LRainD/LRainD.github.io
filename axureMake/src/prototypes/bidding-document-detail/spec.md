- 文档编号：PRD-Bidding-Document-Detail
- 负责人：[@liurundong]
- 版本：v1.0
- 状态：进行中

## 1. 摘要

投标报价详情页用于供应商查看招标信息并填报投标报价。本期迭代在"投标附件"模块接入"附件盖章方式"选项（电子签章 / 纸质扫描件），接入文件助手组件，实现与报名信息弹窗一致的附件管理交互逻辑，提高代码复用性和业务统一性。

> 关联范围：投标报价详情页、调价详情页、报名信息弹窗页（三处同步实现一致的附件管理交互逻辑）

## 2. 功能规格

### 2.1 投标附件

#### 2.1.1 附件盖章方式（必填）
- 单选字段，选项：
  - **电子签章**：使用电子签章上传，需进行电子签章后再提交
  - **纸质扫描件**：直接上传，传统附件上传方式
- 默认选中：**电子签章**
- 选择后展开附件字段

#### 2.1.2 附件上传
- 附件（必填）

**选择"电子签章"时（仅可使用电子签功能）：**
- 大小限制：100M
- 支持格式：.pdf
- 最多支持 20 个文件发起签章
- 添加方式：仅可通过"文件助手"组件选择文件，**不支持本地上传**
- 说明文字：大小限制：100M　支持格式：.pdf
- 提示文字：电子签功能仅支持最多20个100M以内的pdf文件，若不满足需求，请选择纸质扫描件方式上传附件报名

**选择"纸质扫描件"时：**
- 大小限制：500M
- 支持格式：.jpeg、.jpg、.gif、.png、.doc、.doc_、.docx、.xls、.xls_、.xlsx、.txt、.pdf、.rar、.zip、.7z、.tar、.jar、.dwg、.dws、.dwt、.dxf、.csv
- 添加方式：触发本地上传
- 说明文字：大小限制：500M　支持格式：.jpeg、.jpg、.gif、.png、.doc、.doc_、.docx、.xl...
- 隐藏签章相关按钮与标签

### 2.2 操作按钮（联动规则）

按钮根据**附件盖章方式**的选择进行联动：

| 附件盖章方式 | 操作按钮 |
|-------------|---------|
| 纸质扫描件 | 无（隐藏"发起电子签"按钮及签章状态标签） |
| 电子签章 | 显示"发起电子签"按钮 |

### 2.3 电子签章流程

#### 2.3.1 确认提示弹窗
点击"发起电子签"按钮后，弹出提示弹窗：
- 弹窗标题：提示（带橙色感叹号图标）
- 说明文字：以下附件将发起电子签章，签章完成后自动提交投标，最多支持20个文件发起签章
- 文件列表：显示当前所有附件，全部默认勾选，不可取消勾选
- 已选数量提示：已选X条（最多20条）
- 操作按钮：取消、确定

#### 2.3.2 签署状态标记
点击确定后，关闭提示弹窗，在对应附件左上角显示签署状态标签：
- **签署中**：橙色背景（#f5a623），白色文字，圆角，位于附件卡片左上角（-top-2 left-2）
- **签章成功**：绿色背景（#52c41a），白色文字，位于附件卡片左上角

#### 2.3.3 跳转电子签落地页
- 确认发起之后，跳转电子签落地页
- 新增传递场景字段，报名、投标、调价作区分，落地页文案不同

### 2.4 附件独立存储与切换
- **独立存储**：电子签章与纸质扫描件的附件列表相互独立，切换方式时保留已选内容
- **切换逻辑**：切换盖章方式 → 清空当前视图中的附件 → 切换回原方式 → 原附件重新显示

### 2.5 签章闭环
- 选择文件 → 点击发起签章 → 卡片状态更新 → 提交业务数据

## 3. 交互要点

- **动态获取**：电子签章模式下点击"添加附件"统一调用"文件助手"组件；纸质扫描件模式触发本地上传。
- **独立附件逻辑**：切换盖章方式 → 清空当前视图中的附件 → 切换回原方式 → 原附件重新显示。
- **签章闭环**：选择文件 → 点击发起签章 → 卡片状态更新 → 提交业务数据。
