# 投标文件组成智能推荐 - 规格文档 (PRD)

## 📋 业务概述
针对供应商投标过程中附件上传繁琐的问题，引入“智能推荐”能力。系统调用文件助手，根据投标文件组成匹配附件并返回推荐结果，降低操作成本，提升投标效率。

## 🎯 功能清单
- **智能填充附件**：支持基于投标文件组成智能匹配并自动填充附件。

## 🔍 详细功能说明

### 3.1 一键引用 (入口)
- **展示条件**：
  - 仅在“开启解决方案”且当前场景为“文件组成”，且选择为“电子签章”模式时，该按钮才可见。
- **视觉样式**：
  - **背景色**：`#ff9900` (Primary)
  - **文字颜色**：白色
  - **图标**：右侧带 `Info` 图标
  - **Hover 效果**：背景色加深至 `#e68a00`
- **交互逻辑**：
  - 点击按钮后，页面调用文件助手接口，并触发 Loading 状态；接口响应前不可重复点击。
  - 请求参数为当前投标文件组成。
  - 文件助手根据传入的文件组成返回推荐附件列表。
  - **弹窗确认**：接口返回后，弹出“文件助手的推荐附件”弹窗，展示推荐列表。
- **填充规则**：
  - **增量填充**：仅对当前文件列表为“空”的附件组进行推荐。
  - **追加原则**：若用户已手动上传或已存在文件，推荐结果将追加到已有文件列表中。
  - **模式隔离**：电子签章模式与纸质扫描件模式下的推荐结果相互独立，切换模式后需重新触发或保留各自状态。

### 3.2 推荐反馈与交互
- **状态联动**：
  - 用户在弹窗中点击“一键引用”后，选中的文件将直接填充到对应的附件组中。
  - 页面不再展示“推荐填充了 xxx”的提示文案。
