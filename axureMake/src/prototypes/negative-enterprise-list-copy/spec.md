# 负面企业清单产品需求说明

## 文档说明

| 项目 | 内容 |
|---|---|
| 产品模块 | 风控预警中心 / 负面企业清单 |
| 使用端 | 采方端 |
| 文档用途 | 产品、研发、测试共同评审及验收依据 |
| 需求状态 | 待评审 |
| 本期范围 | 查询、查看、新增、编辑、移出、附件查看、批量导入、对外查询接口 |

本文档描述用户要完成的业务任务、页面规则和验收口径，不约束具体实现方式。当前页面为交互原型，原型中的示例数据、上传过程和下载提示仅用于演示业务流程；正式上线时应以真实业务数据和实际处理结果为准。

## 1. 需求背景

采购业务在供应商寻源、资格预审、评标和履约过程中，需要及时识别存在失信、重大税收违法、履约不良或其他重大风险的企业。当前风险企业信息如果分散维护，容易出现信息不统一、查询困难和风险拦截不及时等问题。

负面企业清单用于统一记录和维护高风险企业，为后续采购环节的风险识别和准入管控提供可信依据。

## 2. 产品目标

- 建立统一的负面企业清单，集中沉淀企业风险信息和管控依据。
- 支持管理人员快速查询、查看、新增、编辑和移出负面企业。
- 支持通过批量导入提升集中维护效率。
- 保留列入组织、列入人、更新人及更新时间，便于追溯维护责任。
- 为采购相关环节提供风险企业识别基础，但本期不包含采购流程中的自动拦截能力。

## 3. 用户与使用场景

### 3.1 目标用户

- 风控管理人员：维护负面企业及其管控信息。
- 采购管理人员：查询并查看企业是否已被列入负面清单。
- 业务审核人员：核对企业被列入的原因、有效期和附件依据。

### 3.2 典型场景

1. 风控人员收到处罚、失信或履约不良信息后，将相关企业加入负面清单。
2. 管理人员根据企业名称、信用代码、列入组织或日期等条件查询记录。
3. 企业风险情况或管控期限发生变化时，管理人员更新清单信息。
4. 企业满足移出条件后，管理人员确认并将其移出负面清单。
5. 需要一次维护多家企业时，管理人员下载模板并批量导入。

## 4. 范围与优先级

| 功能 | 优先级 | 本期说明 |
|---|---|---|
| 清单查询 | P0 | 支持多条件组合查询和重置 |
| 清单列表 | P0 | 展示企业、管控、有效期和维护信息 |
| 新增负面企业 | P0 | 单条新增并进行必填和重复校验 |
| 编辑负面企业 | P0 | 修改可维护的管控信息 |
| 移出清单 | P0 | 二次确认后移出 |
| 查看详情及附件 | P1 | 只读查看完整信息和附件 |
| 批量导入 | P1 | 下载模板、上传校验、确认导入和失败反馈 |
| 对外查询接口 | P0 | 面向分供商团队，按分供商编号批量查询是否为负面清单分供商 |

### 4.1 本期不包含

- 采购寻源、资格预审、评标等环节的自动命中和拦截。
- 企业风险信息的自动采集、自动判断或自动列入。
- 负面企业审批流程、解除审批流程及操作撤回。
- 历史版本对比、操作日志查询和清单数据导出。

## 5. 业务定义与统一口径

### 5.1 负面企业

因失信、违法、履约不良或其他风险情形，需要在指定期限内受到采购业务管控的企业。

### 5.2 录入来源

- 人工录入：由管理人员在本页面新增。
- 外部数据同步：由其他业务来源同步进入清单。
- 本期页面新增的数据，录入来源固定为“人工录入”，用户不可修改。

### 5.3 列入日期与有效期

- 列入日期：企业进入负面清单的日期。人工新增时取新增当天，后续不可修改。
- 生效日期：该条负面管控开始生效的日期。
- 结束日期：该条负面管控结束的日期。
- 长期：无法确定结束日期或需持续管控时使用。选择“长期”后不再填写具体结束日期，页面统一展示“长期”。

### 5.4 管控情形与管控类别

| 管控情形 | 对应管控类别 | 填写规则 |
|---|---|---|
| 第2种管控情形 | 云筑网总部禁用分供商 | 自动带出，不可修改 |
| 第3种管控情形 | 评价不合格分供商 | 自动带出，不可修改 |
| 第4种管控情形 | 合作不良 | 自动带出，不可修改 |
| 第5种管控情形 | 涉诉涉裁风险分供商 | 自动带出，不可修改 |
| 第6种管控情形 | 过程履约评价不良分供商 | 自动带出，不可修改 |
| 第7种管控情形 | 报名关联行为分供商 | 自动带出，不可修改 |
| 第8种管控情形 | 结算失信分供商 | 自动带出，不可修改 |
| 第9种管控情形 | 人力专项排查分供商 | 自动带出，不可修改 |
| 第10种管控情形 | 纪巡审认定违规分供商 | 自动带出，不可修改 |
| 其他管控情形 | 用户填写 | 必填，最多100个字符 |

### 5.5 企业信息与查询

- 企业名称与统一社会信用代码共同标识一家企业，二者其一即可查询到对应的企业信息。
- 新增时无需同时填写两项：填写企业名称或统一社会信用代码其中一项后查询，系统带出另一项，并保证两项信息一致。
- 查询不到对应企业时，提示用户核对企业名称或统一社会信用代码后重新查询，不自动带出企业信息。
- 手工修改其中一项后，另一项不再保留，如需带出关联信息需重新查询。

### 5.6 中建安装特有字段

- 「管控情形」「管控类别」「涉及人员」「涉及人员联系方式」均为中建安装集团有限公司特有字段。
- 上述字段仅在中建安装及其下属组织的清单中展示、填写和导入；其他组织使用负面企业清单时，不展示、不填写、不校验这些字段。
- 涉及人员、涉及人员联系方式为选填字段，用于记录风险事项相关的责任人（联系人）及其联系方式；未填写时列表展示“-”。

## 6. 功能需求

### 6.1 页面进入与默认展示

- 页面名称为“负面企业清单”，归属“风控预警中心”。
- 进入页面后默认展示全部可见记录和记录总数。
- 列表默认提供分页，支持切换每页条数和跳转页码。
- 原型使用6条示例数据；正式环境中的记录数量以实际数据为准。

### 6.2 清单查询

#### 查询条件

| 查询项 | 查询方式 | 匹配规则 |
|---|---|---|
| 企业关键字 | 文本输入 | 支持按企业名称或统一社会信用代码模糊匹配 |
| 统一社会信用代码 | 文本输入 | 支持按信用代码模糊匹配 |
| 列入组织 | 单选 | 精确匹配 |
| 管控情形 | 单选 | 精确匹配 |
| 列入日期 | 日期范围 | 查询起止日期均包含在内 |
| 生效日期 | 日期范围 | 查询起止日期均包含在内 |
| 结束日期 | 日期范围 | 查询起止日期均包含在内；“长期”记录不纳入结果 |
| 更新时间 | 日期时间范围 | 精确到秒，查询起止时间均包含在内 |
| 列入人 | 文本输入 | 支持模糊匹配 |
| 更新人 | 文本输入 | 支持模糊匹配 |

#### 查询规则

- 未填写任何条件时点击“查询”，展示全部记录。
- 同时填写多个条件时，各条件共同生效，结果需同时满足所有条件。
- 点击“查询”后刷新列表和记录总数。
- 点击“重置”后清空全部查询条件，并恢复全部记录。
- 没有符合条件的数据时，展示空结果，不保留上一次查询结果。

### 6.3 清单列表

#### 展示字段

| 字段 | 展示规则 |
|---|---|
| 序号 | 按当前列表顺序展示 |
| 企业名称 | 展示企业全称，不增加图标或简称 |
| 统一社会信用代码 | 完整展示 |
| 录入来源 | 展示“人工录入”或“外部数据同步” |
| 列入组织 | 展示负责列入该企业的组织 |
| 管控情形 | 展示选定的管控情形 |
| 管控类别 | 展示系统带出或用户填写的类别；无内容时展示“-” |
| 列入日期 | 按年-月-日展示 |
| 生效日期 | 按年-月-日展示 |
| 结束日期 | 有明确日期时按年-月-日展示，长期有效时展示“长期” |
| 涉及人员 | 展示录入的涉及人员；无内容时展示“-”（中建安装特有字段） |
| 涉及人员联系方式 | 展示录入的涉及人员联系方式；无内容时展示“-”（中建安装特有字段） |
| 附件 | 有附件时展示“查看附件”，无附件时展示“-” |
| 列入人 | 展示首次列入人员 |
| 更新时间 | 展示最近一次更新日期和时间 |
| 更新人 | 展示最近一次更新人员 |

#### 列表操作

- 每条记录提供“查看”“编辑”“移除”操作。
- 点击“查看”进入只读详情，任何字段均不可修改。
- 点击“编辑”进入编辑页面并带出当前记录内容。
- 点击“移除”必须先进行二次确认，避免误操作。
- 列表区域展示当前查询结果总数。
- 序号列前提供行复选框，表头复选框支持一键全选/取消全选。
- 工具栏实时展示“共选中 X 条数据”，未选中任何记录时“批量删除”按钮置灰不可点击。
- 点击“批量删除”必须先进行二次确认，确认后删除已选记录并清空选中状态，取消则不做任何变更。

### 6.4 新增负面企业

#### 新增入口与默认值

- 点击“新增企业”打开新增页面。
- 录入来源固定为“人工录入”，不可修改。
- 列入日期默认取新增当天，不可修改。
- 列入组织默认选中“中建五洲工程装备有限公司”，用户可修改。

#### 企业信息查询

- 企业名称和统一社会信用代码输入框右侧均提供查询图标，点击后按当前填写内容查询企业信息。
- 两个输入框均填写时，点击哪个输入框的查询图标，就以该输入框的内容作为查询条件。
- 对应输入框为空时点击查询图标，提示“请先输入企业名称或统一社会信用代码”，不发起查询。
- 查询到企业时，自动带出企业名称和统一社会信用代码，两项信息以查询结果为准。
- 查询不到企业时，提示“未查询到该企业信息，请核对企业名称或统一社会信用代码”，不修改已填写内容。
- 手动修改企业名称或统一社会信用代码其中一项时，另一项自动清空，避免出现两项信息不一致；需要关联信息时重新点击查询图标。

#### 新增字段规则

| 字段 | 是否必填 | 录入及校验规则 |
|---|---|---|
| 企业名称 | 是 | 填写企业全称，最多100个字符；可通过右侧查询图标按名称查询并带出信用代码 |
| 统一社会信用代码 | 否 | 18位数字或大写字母；填写时校验格式，同一信用代码已存在时不允许重复新增；可通过右侧查询图标按信用代码查询并带出企业名称 |
| 录入来源 | 是 | 固定为“人工录入” |
| 列入组织 | 是 | 从可选组织中选择 |
| 管控情形 | 是 | 从第2种至第10种管控情形及“其他管控情形”中选择 |
| 管控类别 | 条件必填 | 按第5.4节规则自动带出或填写 |
| 列入日期 | 是 | 自动取新增当天 |
| 生效日期 | 是 | 选择具体日期；须早于或等于结束日期 |
| 结束日期 | 是 | 选择具体日期（不得早于生效日期），或选择“长期” |
| 列入原因 | 是 | 说明列入依据或风险事实，最多2000个字符 |
| 涉及人员 | 否 | 中建安装特有字段；文本框录入涉及人员姓名，最多2000个字符 |
| 涉及人员联系方式 | 否 | 中建安装特有字段；文本框录入涉及人员联系方式，最多2000个字符 |
| 备注 | 否 | 补充说明，最多2000个字符 |
| 附件 | 否 | 支持一次添加多个附件，最多20个；附件格式及单个、总大小限制按研发项目规范执行 |

#### 提交结果

- 必填项缺失或格式不符合要求时，不允许保存，并在对应字段处提示原因。
- 结束日期早于生效日期时，不允许保存，并提示“结束日期不得早于生效日期”。
- 填写了统一社会信用代码且该代码已存在时，不允许保存，并提示“该统一社会信用代码已存在负面清单中，请勿重复添加”。
- 保存成功后关闭新增页面，新记录展示在列表首行，并更新列表总数。
- 新增成功后，列入人和更新人均记录为当前操作人，更新时间记录为当前时间。
- 点击“取消”时不保存本次填写内容。

### 6.5 编辑负面企业

- 点击“编辑”后带出该企业当前的完整信息。
- 企业名称、统一社会信用代码、录入来源和列入日期不可修改。
- 列入组织、管控情形、管控类别、生效日期、结束日期、列入原因、涉及人员、涉及人员联系方式、备注和附件可以修改。
- 管控情形发生变化后，管控类别按第5.4节重新确定，不能保留与新情形不一致的原类别。
- 提交时执行与新增一致的必填和格式校验。
- 提交成功后在原位置更新该条记录，同时将更新人和更新时间更新为本次操作信息。
- 提交时结束日期不得早于生效日期。
- 外部数据同步来源的记录与人工录入记录采用相同的编辑和移出规则，允许人工编辑和移出（本期暂不会有外部数据同步记录）。
- 点击“取消”时不保存本次修改。

### 6.6 查看详情与附件

- 查看详情时展示新增页面中的全部业务信息，所有字段只读。
- 有附件时展示附件名称列表，用户可点击附件执行下载。
- 无附件时明确展示无附件，不显示无效下载入口。
- 从列表点击“查看附件”时，直接打开该企业的附件列表。

### 6.7 移出清单

- 点击“移除”后提示用户确认是否将该企业移出负面企业清单。
- 用户取消时不做任何变更。
- 用户确认后移出该记录，刷新列表和记录总数，并提示“已移出负面企业清单”。
- 移出仅代表该企业不再出现在当前负面企业清单中；本期移出不要求填写移出原因，也不提供移出历史记录查询。

### 6.8 批量导入

#### 导入入口

- 点击“导入”打开批量导入页面。
- 页面首先提供“导入模板”下拉选择和“下载导入模板”入口，用户先选择模板类型（中建安装、通用）再下载对应模板，并提示用户按模板要求填写后上传。
- 页面明确提示：“请注意！导入不会校验重复数据，请谨慎操作，避免重复导入过多数据。”

#### 导入模板

- 模板分为“中建安装”和“通用”两类，下载前先在下拉框中选择模板类型，默认为“中建安装”。
- “中建安装”模板包含字段：序号、列入组织、管控情形、管控类别、企业名称、统一社会信用代码、列入原因、涉及人员、涉及人员联系方式、生效时间、结束时间、备注。
- “通用”模板不包含中建安装特有字段（管控情形、管控类别、涉及人员、涉及人员联系方式），其余字段与中建安装模板一致。

| 模板字段 | 是否必填 | 填写要求 |
|---|---|---|
| 列入组织 | 是 | 填写有效组织名称 |
| 管控情形 | 是 | 中建安装模板特有字段，填写规定的管控情形 |
| 管控类别 | 否 | 中建安装模板特有字段，与管控情形保持一致 |
| 企业名称 | 是 | 填写企业全称 |
| 统一社会信用代码 | 否 | 有信用代码时填写 |
| 列入原因 | 是 | 填写风险事实或列入依据 |
| 涉及人员 | 否 | 中建安装模板特有字段，填写相关人员姓名 |
| 涉及人员联系方式 | 否 | 中建安装模板特有字段，填写相关联系方式 |
| 生效时间 | 是 | 按年-月-日填写，须早于或等于结束时间 |
| 结束时间 | 是 | 按年-月-日填写，或填写“长期” |
| 备注 | 否 | 填写补充说明 |

- 模板提供3条示例数据和填写说明，示例数据仅用于说明填写方式。
- 点击“确认下载”后，按所选模板类型下载对应文件：“负面企业清单导入模板（中建安装）.xlsx”或“负面企业清单导入模板（通用）.xlsx”。
- 用户不得修改模板表头，正式导入前应删除示例数据。

#### 上传与校验

- 每次仅上传1个文件，文件大小不超过10MB。
- 上传后进入“文件上传解析中”状态，处理期间避免重复提交。
- 校验通过时展示通过条数，并提供“确认导入”操作。
- 上传文件不是规定的导入模板（文件表头或字段与模板不一致）时，不提供“下载失败原因”入口，仅在导入时通过轻提示（toast）告知“导入模板不正确，请下载标准导入模板后重新上传”，并返回上传状态以便重新上传。
- 数据校验失败（模板正确但数据不符合要求）时展示失败提示和“下载失败原因”入口，同时允许重新上传。
- 失败原因文件名称为“负面企业清单导入失败原因.xlsx”，仅用于模板正确但数据校验失败的场景。

#### 确认导入

- 点击“确认导入”时再次提示用户确认。
- 用户确认后执行导入，成功时提示“导入成功”并关闭导入页面。
- 用户取消确认时保留当前校验结果，可继续确认导入或关闭。
- 原型中的上传、成功、失败、下载和导入结果均为流程演示；正式功能应以实际文件解析和数据处理结果反馈。

## 7. 页面状态与异常处理

| 场景 | 业务要求 |
|---|---|
| 首次进入 | 展示全部可见记录 |
| 查询无结果 | 展示空结果，并保留当前查询条件以便调整 |
| 表单校验失败 | 保留已填写内容，明确标识错误字段及原因 |
| 新增信用代码重复 | 阻止保存并提示重复原因 |
| 结束日期早于生效日期 | 阻止保存并提示结束日期不得早于生效日期 |
| 导入处理中 | 展示处理中状态，避免用户重复发起导入 |
| 导入模板不符 | 仅轻提示模板不正确并返回上传状态，不提供失败原因下载 |
| 导入校验失败 | 展示失败原因下载入口，并允许重新上传 |
| 附件为空 | 展示“-”或“无附件”，不提供下载入口 |
| 移出取消 | 数据不发生变化 |
| 操作成功 | 给出明确成功提示，并同步刷新受影响的数据 |

## 8. 权限与数据范围

本模块在采方端新增 2 个功能权限点：“查看”和“编辑”。权限点目录分别为“集采工作台-风控预警-棱镜识别-查看”和“集采工作台-风控预警-棱镜识别-编辑”，并分别绑定授权组织及数据范围。

### 8.1 权限点定义

| 权限点目录 | 权限点 | 权限类型 | 覆盖的页面能力 |
|---|---|---|---|
| 集采工作台-风控预警-棱镜识别-查看 | 查看 | 查看类权限 | 进入页面、查询列表、查看详情、查看及下载附件、下载导入模板，以及导出、下载等读取类操作 |
| 集采工作台-风控预警-棱镜识别-编辑 | 编辑 | 操作类权限 | 新增、编辑、移出、批量删除、批量导入及其他会新增、修改或删除数据的操作 |

### 8.2 组织数据范围

- “查看”和“编辑”权限均须关联授权组织，权限仅对授权组织范围内的数据生效。
- 每个授权组织支持“本级”和“本下级”两种数据范围。
- “本级”仅包含被授权组织本身的数据。
- “本下级”包含被授权组织本身及其全部下级组织的数据。
- 查看数据范围按“查看”权限对应的授权组织及范围计算；用户只能查询、查看、下载或导出该范围内的数据。
- 编辑数据范围按“编辑”权限对应的授权组织及范围计算；用户只能新增、编辑、移出、批量删除或导入该范围内的数据。
- 同一用户被授予多个组织权限时，最终数据范围取各授权组织及其配置范围的并集。
- 权限范围仅按组织维度控制，无需考虑品类维度。

### 8.3 页面与按钮控制

- 无“查看”权限时，不展示本页面菜单入口，用户也不可通过页面地址直接访问。
- 查看详情、查询、附件查看与下载、模板下载，以及导出等读取类按钮或入口，统一根据“查看”权限控制。
- 新增、编辑、移出、批量删除、批量导入等操作类按钮或入口，统一根据“编辑”权限控制。
- 用户有“查看”权限但无“编辑”权限时，页面以只读方式展示，不展示或禁用所有操作类按钮。
- 对于处于查看范围内、但不处于编辑范围内的数据，仅允许查询和查看，不展示或禁用该条数据的编辑、移出等操作。
- 新增时“列入组织”仅可选择编辑权限覆盖的组织；批量导入时，仅允许导入编辑权限覆盖组织的数据。
- 批量选择包含无编辑权限的数据时，不允许执行批量删除等操作，并提示存在超出编辑权限范围的数据。
- 前端按钮控制仅用于交互展示，后端接口必须按对应权限点、授权组织和数据范围再次校验，防止越权访问或越权操作。

#### 权限示例

假设组织层级为：“中建安装”下设“中建五洲”和“中建电力”，“中建五洲”下设“华东分公司”。

| 授权场景 | 可查看的数据 | 可编辑的数据 | 页面表现 |
|---|---|---|---|
| 仅拥有“中建五洲-本级”的查看权限，无编辑权限 | 仅中建五洲列入的数据 | 无 | 可进入页面并查询、查看、下载或导出中建五洲的数据；不展示新增、编辑、移出、批量删除和批量导入按钮 |
| 拥有“中建五洲-本下级”的查看权限，以及“中建五洲-本级”的编辑权限 | 中建五洲及华东分公司的数据 | 仅中建五洲的数据 | 中建五洲的数据可编辑、移出；华东分公司的数据仅可查看，不展示或禁用编辑、移出操作 |
| 拥有“中建五洲-本下级”的查看和编辑权限 | 中建五洲及华东分公司的数据 | 中建五洲及华东分公司的数据 | 可查看并操作两级组织的数据；新增时“列入组织”可选择中建五洲或华东分公司，导入文件也只能包含这两个组织的数据 |
| 拥有“中建五洲-本级”和“中建电力-本级”的查看、编辑权限 | 中建五洲与中建电力的数据 | 中建五洲与中建电力的数据 | 两个授权组织的数据范围取并集，但不包含华东分公司的数据 |

例如，用户能查看中建五洲及华东分公司的数据，但只能编辑中建五洲本级数据。当列表同时选中一条中建五洲数据和一条华东分公司数据时，不允许执行批量删除，并提示“所选数据中包含无编辑权限的数据，请重新选择”。

### 8.4 其他约束

- 列入人、更新人和更新时间由系统记录，不允许用户自行填写或修改。
- 附件查看和下载遵循与负面企业记录一致的数据权限。
- 当前原型重点演示业务流程，权限中心配置、菜单可见性、按钮权限及接口鉴权由正式系统建设时统一接入。

## 9. 数据及展示口径

- 日期统一展示为“年-月-日”，更新时间展示到秒。
- 企业名称使用企业全称，统一社会信用代码按原值完整展示。
- 列表中的记录总数应与当前查询结果一致。
- 新增记录展示在列表首行；编辑记录在原位置更新；移出记录不再出现在列表中。
- “长期”是结束日期的一种业务状态，不等同于空值。
- 本页面与导入模板统一使用“企业名称”指代清单维护对象，不再使用“分供商名称”。
- 对外查询接口（第11节）的入参使用“分供商编号”，口径与供应商主数据保持一致，由用户中心映射到清单企业。

## 10. 验收标准

### 10.1 查询与列表

- 输入任一查询条件后，结果均按该条件正确筛选。
- 同时输入多个条件后，结果同时满足全部条件。
- 日期范围包含起止日期，结束日期查询不返回“长期”记录。
- 更新时间可按具体日期和时间范围筛选。
- 重置后全部条件被清空，列表恢复全部记录。
- 列表字段、记录总数、分页和每条记录操作均正常展示。
- 行复选框与表头一键全选均可用，选中数量与“共选中 X 条数据”展示一致。
- 点击“批量删除”先弹出二次确认；确认后已选记录被删除且选中状态清空，取消则不删除任何数据。
- 未选中任何记录时“批量删除”按钮不可点击。

### 10.2 新增与编辑

- 新增页面的录入来源、列入日期和默认组织符合要求。
- 仅填写企业名称或统一社会信用代码其中一项时，可通过输入框右侧查询图标查询企业并自动带出另一项。
- 企业名称未填写时保存被阻止；统一社会信用代码未填写不影响保存。
- 查询不到企业时给出提示，且不自动带出或清空已填写内容。
- 修改企业名称或统一社会信用代码其中一项后，另一项被自动清空。
- 所有必填项、长度限制和信用代码格式校验均生效。
- 使用已存在的信用代码新增时被阻止，并展示指定提示语。
- 管控情形与管控类别的联动结果符合第5.4节。
- 结束日期早于生效日期时保存被阻止并给出提示。
- 选择“长期”后无需填写具体结束日期，保存后列表显示“长期”。
- 附件一次最多添加 20 个，超过数量时不允许继续添加并给出提示。
- 新增成功后记录出现在首行；编辑成功后原记录内容、更新人和更新时间发生更新。
- 编辑时企业名称、信用代码、录入来源和列入日期不可修改。
- 涉及人员、涉及人员联系方式为非必填，未填写时可正常保存，列表中对应字段展示“-”。

### 10.3 查看、附件与移出

- 查看详情时全部字段只读且内容与列表记录一致。
- 有附件时可打开附件列表，无附件时不提供无效入口。
- 移出前必须二次确认；取消后记录保留，确认后记录移除并给出成功提示。

### 10.4 批量导入

- 可选择“中建安装”或“通用”模板类型，并查看、下载对应名称的导入模板，通用模板不包含中建安装特有字段。
- 上传后能够展示处理中、校验成功和校验失败状态。
- 导入模板中列入组织、管控情形、企业名称、列入原因、生效时间、结束时间为必填项，缺失时校验失败并可下载失败原因。
- 生效时间晚于结束时间时校验失败并可下载失败原因。
- 确认导入前出现二次确认提示，确认后给出导入成功反馈。
- 上传非规定模板时仅出现模板不正确提示，且不提供失败原因下载入口。
- 校验失败时可下载指定名称的失败原因文件，并可重新上传。

### 10.5 对外查询接口

- 按分供商编号列表批量查询时，只有能映射到清单企业的编号才可能命中。
- 范围为本级时只命中传入组织列入的记录；本下级包含其所有下级组织；本下级+本上级同时包含下级和上级组织。
- 未生效、已过期的记录不计为命中，结束日期为“长期”的记录计为命中。
- 命中时返回的管控情形、管控类别、列入组织、生效日期、结束日期与清单记录一致。
- 已被移出清单的企业不再命中。
- 分供商编号列表为空时返回空结果，不返回全量数据。
- 调用方无权访问的组织数据不返回。

### 10.6 权限与数据范围

- 权限中心可配置“集采工作台-风控预警-棱镜识别-查看”和“集采工作台-风控预警-棱镜识别-编辑”两个权限点，并可分别配置授权组织及“本级”或“本下级”范围。
- 配置“本级”后，只能查看或编辑该组织本级数据；配置“本下级”后，可以查看或编辑该组织及其全部下级组织数据。
- 同一用户配置多个授权组织后，数据范围按各组织授权范围的并集计算。
- 权限判断仅依据组织及组织范围，不校验品类。
- 无“查看”权限时不展示菜单入口，且直接访问页面地址时拒绝访问。
- 仅有“查看”权限时，可查询和查看授权范围内数据，并可使用附件下载、模板下载、导出等读取类功能，但不可执行新增、编辑、移出、批量删除或批量导入。
- 具有“编辑”权限时，仅可对编辑权限组织范围内的数据执行新增、编辑、移出、批量删除和批量导入。
- 数据在查看范围内但不在编辑范围内时，该数据保持只读，操作类按钮不展示或不可用。
- 新增可选组织和导入数据组织均不得超出编辑权限覆盖范围；越权数据由后端拒绝处理。
- 前端隐藏或禁用按钮后，通过接口直接发起的越权查看、下载、导出或编辑请求仍会被后端拒绝。

## 11. 对外查询接口需求（提供给分供商团队）

本节描述负面企业清单对外提供的能力，供分供商团队在准入、建档、报价、投标等自有环节中判断某分供商是否已被列入负面清单。本节只定义业务能力和口径，具体接口路径、HTTP 方法、请求及响应 JSON 结构、字段命名、鉴权方式、错误码、限流和版本管理由研发确定。

### 11.1 接口目标

- 由分供商团队按分供商编号批量发起查询，判断这些分供商当前是否属于负面清单分供商。
- 对命中的分供商返回管控情形、管控类别、有效期和列入组织等信息，便于调用方展示拦截或提示原因。
- 本接口只提供查询结果，不执行拦截动作，也不接收拦截结果反馈；是否拦截、如何提示由调用方自行决定。

### 11.2 请求参数

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| 分供商编号列表 | 数组 | 是 | 待查询的分供商编号集合，编号口径为供应商主数据编号，不是统一社会信用代码；单次调用数量上限及是否需要分页由研发确定；空列表直接返回空结果，不按全量查询 |
| 组织 | 字符串 | 是 | 发起查询的调用方所属组织，用于限定数据范围；统一使用组织编码 |
| 范围 | 枚举 | 是 | 组织覆盖范围，取值为：本级、本下级、本下级+本上级 |

### 11.3 范围口径

「组织 + 范围」共同决定本次查询可覆盖的负面清单记录，匹配字段为清单中的“列入组织”。

| 范围取值 | 含义 | 覆盖的列入组织 |
|---|---|---|
| 本级 | 仅本级组织 | 传入组织 |
| 本下级 | 本级组织及其所有下级组织 | 传入组织 + 所有下级组织 |
| 本下级+本上级 | 本级组织、所有下级组织及上级组织 | 传入组织 + 所有下级组织 + 上级组织 |

- 组织层级关系以主数据组织树为准。
- 「本下级+本上级」的上级范围按组织树层级逐级向上追溯，直至股份级，不受跨公司、跨层级限制。
- 范围只决定组织覆盖，不改变有效期过滤规则和命中判断规则。
- 同一分供商在覆盖范围内存在多条有效记录时全部返回，不做合并。

### 11.4 命中规则与返回内容

同时满足以下条件才算命中：

1. 该分供商编号可通过用户中心查询映射到清单中的企业（按统一社会信用代码建立对应关系）。
2. 该企业记录处于当前有效期内：生效日期 ≤ 查询当天 ≤ 结束日期，或结束日期为“长期”；未生效、已过期的记录不算命中。
3. 该企业记录的“列入组织”落在本次「组织 + 范围」覆盖范围内。

命中后返回内容：

| 返回字段 | 说明 |
|---|---|
| 分供商编号 | 入参中的分供商编号原样返回 |
| 企业名称 | 清单中的企业全称 |
| 统一社会信用代码 | 清单中的信用代码 |
| 管控情形 | 该条记录的管控情形 |
| 管控类别 | 该条记录的管控类别 |
| 列入组织 | 该条记录的列入组织 |
| 列入日期 | 该条记录的列入日期 |
| 生效日期 | 该条记录的生效日期 |
| 结束日期 | 有明确日期时返回具体日期，长期有效时返回“长期”标识 |
| 列入原因 | 该条记录的列入原因 |

- 同时返回命中条数。
- 未命中的分供商编号、供应商主数据中不存在的无效编号，是否返回由研发确定（默认只返回命中结果）。
- 附件名称及下载地址默认不通过本接口返回，如需提供由调用方另行确认。

### 11.5 异常与边界

| 场景 | 业务要求 |
|---|---|
| 分供商编号列表为空 | 不做查询，直接返回空结果 |
| 编号在供应商主数据中不存在或已删除 | 按未命中处理，不报错；|
| 传入组织不存在 | 返回组织不存在提示，不返回数据 |
| 单次编号数量超过上限 | 拒绝本次请求并提示上限 |
| 企业已被移出负面清单 | 不再命中 |
| 有效期内无匹配记录 | 返回空结果 |

### 11.6 接口约束

- 本接口为只读查询，不产生数据变更，重复调用结果一致（幂等）。
- 必须做调用方鉴权和数据权限控制：调用方只能查询到其组织及范围覆盖的记录，规则与第8节的清单数据权限一致。
- 接口返回清单数据和管控信息，不代替调用方的准入或拦截判断，也不回写调用方的处理结果。
- 返回字段按原值返回，统一社会信用代码、列入原因等字段不做脱敏；本期不维护调用方白名单。

## 12. 评审结论与待确认事项

以下事项已由产品给出结论，作为研发和测试依据；其中 Q2 仍需业务确认。

| 编号 | 事项 | 结论 |
|---|---|---|
| Q1 | 生效日期、结束日期与列入日期的先后关系 | 结束日期不得早于生效日期；不限制列入日期与生效、结束日期的先后 |
| Q2 | 批量导入为什么不校验重复数据 | 待业务确认重复风险是否可接受（本期按不校验执行） |
| Q3 | 新增时信用代码必填，但导入时非必填是否合理 | 统一为信用代码非必填：新增时企业名称必填、统一社会信用代码非必填；导入模板一致 |
| Q4 | 移出时是否必须填写移出原因，是否保留历史记录 | 本期不需要：移出时无需填写移出原因，也不提供移出历史记录 |
| Q5 | 附件允许的格式、数量、单个及总大小 | 格式及单个、总大小按研发项目规范执行；数量暂定每个企业最多 20 个 |
| Q6 | 批量导入中生效时间、结束时间和列入原因是否应必填 | 三者均为必填 |
| Q7 | “企业”与“分供商”的业务术语是否统一 | 统一使用“企业名称”，导入模板不再使用“分供商名称” |
| Q8 | 采方端的数据范围和查看、编辑权限如何控制 | 新增“集采工作台-风控预警-棱镜识别-查看”和“集采工作台-风控预警-棱镜识别-编辑”2个权限点；两个权限点分别按授权组织配置“本级”或“本下级”范围，不考虑品类；查看、导出、下载等读取类能力使用查看权限，新增、编辑、移出、批量删除、批量导入等操作类能力使用编辑权限 |
| Q9 | 外部数据同步记录是否允许人工编辑和移出 | 允许，与人工录入记录规则一致；本期暂不会有外部数据同步 |
| Q10 | 请求参数中的“分供商编号”与清单企业标识如何对应 | 通过用户中心查询，按统一社会信用代码映射到清单企业 |
| Q11 | 组织入参使用组织编码还是组织名称 | 统一使用组织编码 |
| Q12 | 单次查询的分供商编号数量上限，是否需要分页 | 由研发确定 |
| Q13 | 未命中的编号、主数据中不存在的无效编号是否需要返回 | 由研发确定（默认只返回命中结果）。原型中按未命中处理，不报错 |
| Q14 | 返回的统一社会信用代码、列入原因等敏感字段是否脱敏，调用方白名单如何维护 | 不做脱敏；本期不维护调用方白名单 |
| Q15 | 「本下级+本上级」中向上追溯的层级范围（是否跨公司、跨层级） | 按组织树层级逐级向上追溯至股份级，不受跨公司、跨层级限制 |
| Q16 | 「管控情形」「管控类别」「涉及人员」「涉及人员联系方式」的适用范围 | 均为中建安装特有字段，仅中建安装及其下属组织展示和填写，其他组织不展示；导入模板相应分为“中建安装”和“通用”两类 |
