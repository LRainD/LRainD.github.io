# 负面企业清单

## 📋 业务与功能

### 1.1 核心目标
> 简要说明该组件/原型的核心定位、解决的问题、用户价值

为集采平台的风控预警中心提供**负面企业清单（黑名单）维护能力**。将失信被执行人、重大税收违法、履约不良等高风险企业统一沉淀为可维护的清单，供采购寻源、资格预审、评标等环节实时命中校验，从源头拦截高风险供应商。

### 1.2 功能清单
> 列出所有功能模块及其优先级

- **[清单查询]**：按企业关键字、统一社会信用代码、列入组织、管控情形、列入日期、生效日期、结束日期、更新时间（精确到时分秒）、列入人、更新人筛选负面企业（P0）
- **[清单列表]**：以表格展示企业名称、信用代码、录入来源、列入组织、管控情形、管控类别、列入日期、生效日期、结束日期、附件、列入人、更新时间、更新人（P0）
- **[新增负面企业]**：通过弹窗录入企业名称、信用代码、录入来源、列入组织、管控情形、管控类别、列入日期、生效日期、结束日期、附件、列入原因、备注（P0）
- **[批量导入]**：下载导入模板并上传文件，支持演示上传处理中、导入成功预览与导入失败原因下载分支（P1）
- **[编辑负面企业]**：通过弹窗修改录入来源、列入组织、列入日期、生效日期、结束日期、附件、列入原因、备注等信息（P0）
- **[查看负面企业]**：通过弹窗只读查看清单明细（包含录入来源、列入组织、生效日期、结束日期、附件）（P1）
- **[移出清单]**：二次确认后将该企业移出负面清单（P0）

### 1.3 交互要点
> 关键的交互触发点、反馈机制、状态变化

- 点击「查询」：读取查询表单值 → 过滤列表数据并刷新统计条数
- 点击「重置」：清空查询表单 → 恢复全量列表
- 查询区筛选条件：企业关键字、统一社会信用代码（关键字）、列入组织（下拉）、管控情形（下拉）、列入日期/生效日期/结束日期（日期范围选择器）、更新时间（带时分秒的范围选择器）、列入人（关键字）、更新人（关键字）
- 结束日期筛选时，结束日期为「长期」的记录不计入；更新时间按 `YYYY-MM-DD HH:mm:ss` 范围匹配
- 点击「新增企业」：打开新增弹窗，「录入来源」置灰不可编辑，固定为「人工录入」
- 点击「新增企业」：「列入日期」置灰不可编辑，固定取新增当天日期
- 「管控情形」为必选下拉框，选项为第1种至第10种管控情形，以及「其他管控情形」
- 选择第2种至第10种管控情形时，系统自动带出对应的「管控类别」且不可编辑
- 选择「其他管控情形」时，「管控类别」切换为必填文本输入框
- 选择「第1种管控情形」时，「管控类别」暂不赋值，映射关系待确认
- 「生效日期」「结束日期」为日期选择器（`YYYY-MM-DD`），新增/编辑时均必填
- 「结束日期」勾选「长期」复选框后，结束日期选择器置灰清空，表示长期有效；列表与模板中「结束日期」展示为「长期」
- 「附件」支持上传多个文件，编辑时回显已上传文件，查看时仅展示附件列表
- 新增、编辑、查看表单中「附件」位于「备注」下方
- 列表有附件时展示蓝色「查看附件」按钮，点击后弹窗展示附件列表；无附件时展示「-」
- 提交新增时若统一社会信用代码重复：拦截并提示「该统一社会信用代码已存在负面清单中，请勿重复添加」
- 点击「编辑」：打开编辑弹窗并回填记录，企业名称与信用代码不可修改
- 点击「导入」：打开导入弹窗，「下载导入模板」按钮位于上传文件框上方
- 导入提示不再说明文件格式及单次导入数量，明确提示「3、请注意！导入不会校验重复数据，请谨慎操作，避免重复导入过多数据。」
- 点击上传文件框：不打开系统文件选择器，直接进入上传解析 Loading 演示状态
- Loading 状态下展示「成功」「失败」两个小按钮，用于模拟导入结果分支
- 成功分支：展示「校验成功」及校验通过数量，蓝底「预览」按钮使用白色文字，点击后打开导入数据表格
- 校验成功后弹窗右下角在「关闭」右侧展示「确认导入」按钮；点击后进行二次确认，提示「建议点击预览查看后确认导入。」
- 二次确认后完成导入，提示「导入成功」并关闭导入弹窗
- 导入数据预览列为：序号、列入组织、管控情形、管控类别、分供商名称、统一社会信用代码（非必填）、列入原因、涉及人员、涉及人员联系方式、生效时间、结束时间、备注
- 导入数据预览顶部提供「分供商名称」筛选条件，支持查询和重置
- 失败分支：展示「导入失败」和「下载失败原因」按钮，同时重新展示上传文件框以支持再次上传
- 点击「下载失败原因」：提示下载「负面企业清单导入失败原因.xlsx」
- 点击「下载导入模板」：打开模板预览弹窗，以 Excel 表格样式展示模板表头与 3 条示例数据，并附填写说明
- 模板预览弹窗点击「确认下载」：提示「模板下载中：负面企业清单导入模板.xlsx」并关闭弹窗
- 点击「查看」：打开只读详情弹窗，所有字段只读
- 点击「移除」：Popconfirm 二次确认，确认后从列表移除并提示「已移出负面企业清单」
- 列表「企业名称」列仅展示企业全称文本，不带任何前置图标
- 点击「查看」/「编辑」：回填时「列入日期」「生效日期」「结束日期」以 dayjs 对象写入 DatePicker，提交时统一格式化为 `YYYY-MM-DD`
- 提交成功后：新增插入列表首行，编辑就地更新，并同步刷新更新时间与更新人

## 📊 内容规划

### 2.1 信息架构
> 模块划分、信息层级、内容组织方式

```
负面企业清单
├── 面包屑（风控预警中心 > 负面企业清单）
├── 查询区（企业关键字 + 统一社会信用代码 + 列入组织 + 管控情形 + 三个日期范围 + 更新时间 + 列入人/更新人 + 查询、重置）
├── 清单表格区
│   ├── 工具栏（标题 + 共 N 条 + 导入 + 新增企业）
│   └── 数据表格（14 列）
├── 新增 / 编辑 / 查看弹窗
├── 附件列表弹窗
├── 导入弹窗（下载模板 + 上传 / Loading / 成功 / 失败状态）
├── 导入数据预览弹窗
└── 导入模板预览弹窗（Excel 仿真样式）
```

### 2.2 数据来源
> 数据源优先级：用户提供数据 > 项目数据表 > 生成示例数据

- **数据类型**：列表（6 条示例数据）
- **数据源**：生成示例数据（本次为字段推测版本，待用户确认后调整）
- **关键字段**：
  - `enterpriseName`: 企业名称（企业全称）
  - `creditCode`: 统一社会信用代码（18 位数字或大写字母）
  - `source`: 录入来源（外部数据同步/人工录入）
  - `organization`: 列入组织（中建安装下级组织：中建五洲工程装备有限公司、南京华建检测技术有限公司，以及华北、国际工程、南方、上海、西安分公司）
  - `controlSituation`: 管控情形（第1种至第10种管控情形，或其他管控情形）
  - `controlCategory`: 管控类别（第2种至第10种由管控情形自动映射；其他管控情形时由用户输入）
  - `includeDate`: 列入日期
  - `effectiveTime`: 生效日期（`YYYY-MM-DD`）
  - `endTime`: 结束日期（`YYYY-MM-DD`）；勾选「长期」时为空
  - `isLongTerm`: 是否长期有效（true 时结束时间展示为「长期」）
  - `attachments`: 附件文件名列表
  - `reason`: 列入原因
  - `remark`: 备注
  - `creator` / `updater`: 列入人 / 更新人
  - `createTime` / `updateTime`: 创建时间 / 更新时间

### 2.3 内容示例
> （可选）重要的示例内容、文案语气、术语规范

- 录入来源取值：外部数据同步、人工录入
- 列表模拟数据中的列入组织均使用中建安装下级组织，新增表单默认选中「中建五洲工程装备有限公司」
- 结束日期支持「长期」：勾选后无需填写具体日期，展示为「长期」
- 管控情形与管控类别映射：
  - 第1种管控情形 → 待确认
  - 第2种管控情形 → 云筑网总部禁用分供商
  - 第3种管控情形 → 评价不合格分供商
  - 第4种管控情形 → 合作不良
  - 第5种管控情形 → 涉诉涉裁风险分供商
  - 第6种管控情形 → 过程履约评价不良分供商
  - 第7种管控情形 → 报名关联行为分供商
  - 第8种管控情形 → 结算失信分供商
  - 第9种管控情形 → 人力专项排查分供商
  - 第10种管控情形 → 纪巡审认定违规分供商
  - 其他管控情形 → 用户通过文本输入框填写管控类别

## 🎨 布局与结构

### 3.1 整体布局
> 布局模式（单栏/双栏/网格/自由）、模块尺寸、比例约束

- **布局模式**：运营后台顶部导航 + 左侧菜单（复用 `OperationAdminLayout`）+ 右侧单栏内容流
- **容器宽度**：流式，内容区自适应
- **关键尺寸**：
  - 查询区：白色卡片 `filter-card`，标题「查询条件」带蓝色竖条，`Row/Col` 三列网格（每项 `span=8`）排列，标签与控件同行、控件自适应撑满，「查询/重置」按钮靠右
  - 表格区：`Card` 承载工具栏与 `Table`，横向滚动 `x: 2420`
  - 新增 / 编辑 / 查看弹窗：宽度 680px，纵向表单
  - 附件列表弹窗：宽度 520px，附件以蓝色下载按钮纵向排列
  - 导入弹窗：宽度 560px，下载模板按钮位于上传框上方，结果状态居中展示
  - 导入数据预览弹窗：宽度 1200px，表格支持横向滚动

### 3.2 响应式适配
> （如适用）断点、适配策略

- **桌面端（≥1200px）**：查询条件按每行 3 项网格排布，表格横向滚动展示全部列
- **平板端（768-1199px）**：查询条件网格自动换行，操作列固定右侧
- **移动端（<768px）**：查询项标签与控件纵向堆叠，工具栏纵向堆叠

| 事件名称 | Payload 类型 | 触发时机 | 说明 |
