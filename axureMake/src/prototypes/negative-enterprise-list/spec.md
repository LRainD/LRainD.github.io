# 负面企业清单

## 📋 业务与功能

### 1.1 核心目标
> 简要说明该组件/原型的核心定位、解决的问题、用户价值

为集采平台的风控预警中心提供**负面企业清单（黑名单）维护能力**。将失信被执行人、重大税收违法、履约不良等高风险企业统一沉淀为可维护的清单，供采购寻源、资格预审、评标等环节实时命中校验，从源头拦截高风险供应商。

### 1.2 功能清单
> 列出所有功能模块及其优先级

- **[清单查询]**：按企业关键字（企业名称/统一社会信用代码）、列入组织筛选负面企业（P0）
- **[清单列表]**：以表格展示企业名称、信用代码、列入来源、列入组织、列入日期、更新时间、更新人（P0）
- **[新增负面企业]**：弹窗录入企业名称、信用代码（18 位校验）、列入来源、列入组织、列入日期、列入原因、备注（P0）
- **[批量导入]**：下载导入模板并上传 Excel/CSV 文件批量导入负面企业（包含列入组织列）（P1）
- **[编辑负面企业]**：修改列入来源、列入组织、列入日期、列入原因、备注等信息（P0）
- **[查看负面企业]**：只读查看清单明细（包含列入组织）（P1）
- **[移出清单]**：二次确认后将该企业移出负面清单（P0）

### 1.3 交互要点
> 关键的交互触发点、反馈机制、状态变化

- 点击「查询」：读取查询表单值 → 过滤列表数据并刷新统计条数
- 点击「重置」：清空查询表单 → 恢复全量列表
- 点击「新增企业」：打开新增弹窗，默认列入来源为「人工录入」
- 提交新增时若统一社会信用代码重复：拦截并提示「该统一社会信用代码已存在负面清单中，请勿重复添加」
- 点击「编辑」：打开弹窗并回填记录，企业名称与信用代码不可修改
- 点击「导入」：打开导入弹窗，支持下载模板与上传文件
- 点击「下载导入模板」：打开模板预览弹窗，以 Excel 表格样式展示模板表头（A~F 列）与 3 条示例数据，并附填写说明
- 模板预览弹窗点击「确认下载」：提示「模板下载中：负面企业清单导入模板.xlsx」并关闭弹窗
- 导入弹窗未选择文件时点击「确认导入」：提示「请先选择需要导入的文件」
- 导入弹窗选择文件后点击「确认导入」：提示「导入任务已提交，系统正在解析校验，请稍后刷新列表查看结果」
- 点击「查看」：弹窗内所有字段只读，仅保留「关闭」按钮
- 点击「移除」：Popconfirm 二次确认，确认后从列表移除并提示「已移出负面企业清单」
- 列表「企业名称」列仅展示企业全称文本，不带任何前置图标
- 点击「查看」/「编辑」：弹窗回填时「列入日期」以 dayjs 对象写入 DatePicker，提交时格式化为 `YYYY-MM-DD` 字符串，避免日期组件因值类型不匹配而崩溃
- 提交成功后：新增插入列表首行，编辑就地更新，并同步刷新更新时间与更新人

### 2.2 数据来源
> 数据源优先级：用户提供数据 > 项目数据表 > 生成示例数据

- **数据类型**：列表（6 条示例数据）
- **数据源**：生成示例数据（本次为字段推测版本，待用户确认后调整）
- **关键字段**：
  - `enterpriseName`: 企业名称（企业全称）
  - `creditCode`: 统一社会信用代码（18 位数字或大写字母）
  - `source`: 列入来源（外部数据同步/人工录入/系统检测）
  - `organization`: 列入组织（中国建筑下级工程局：中建一局/中建二局/中建三局/中建四局/中建八局）
  - `includeDate`: 列入日期
  - `reason`: 列入原因
  - `remark`: 备注
  - `creator` / `updater`: 创建人 / 更新人
  - `createTime` / `updateTime`: 创建时间 / 更新时间

## 🎨 布局与结构

### 3.1 整体布局
> 布局模式（单栏/双栏/网格/自由）、模块尺寸、比例约束

- **布局模式**：顶部导航 + 左侧菜单（复用 `CentralizedProcurementLayout`）+ 右侧单栏内容流
- **容器宽度**：流式，内容区自适应
- **关键尺寸**：
  - 查询区：`Card size="small"`，表单项行内排列，「查询/重置」靠右
  - 表格区：`Card` 承载工具栏与 `Table`，横向滚动 `x: 1250`
  - 弹窗：宽度 620px，纵向表单

### 3.2 响应式适配
> （如适用）断点、适配策略

- **桌面端（≥1200px）**：查询表单项单行排布，表格横向滚动展示全部列
- **平板端（768-1199px）**：查询表单项自动换行，操作列固定右侧
- **移动端（<768px）**：查询表单项整行占宽，工具栏纵向堆叠

## ⚙️ Axure API 说明
> 如果不使用 Axure API，可删除此部分

### 5.1 事件列表（eventList）
> 组件对外暴露的事件

| 事件名称 | Payload 类型 | 触发时机 | 说明 |
|---------|-------------|---------|------|
| `onEnterpriseAdd` | `string` | 新增企业成功后 | payload 为新增记录 JSON 字符串 |
| `onEnterpriseEdit` | `string` | 编辑企业成功后 | payload 为编辑后记录 JSON 字符串 |
| `onEnterpriseRemove` | `string` | 移出清单成功后 | payload 为 `{ id }` JSON 字符串 |

### 5.2 动作列表（actionList）
> 组件可被调用的动作

| 动作名称 | Params 类型 | 参数说明 | 功能描述 |
|---------|------------|---------|---------|
| `refreshList` | `string` | 无 | 刷新清单列表 |
| `openAddModal` | `string` | 无 | 打开新增弹窗 |
| `openEditModal` | `string` | `{ id }` | 打开指定记录的编辑弹窗 |
| `openImportModal` | `string` | 无 | 打开批量导入弹窗 |

### 5.3 变量列表（varList）
> 组件内部状态变量

| 变量名称 | 类型 | 默认值 | 说明 |
|---------|-----|-------|------|
| `data_source` | `object` | 6 条示例数据 | 负面企业清单数据 |
| `is_modal_open` | `boolean` | `false` | 弹窗开关状态 |
| `modal_type` | `string` | `'add'` | 弹窗类型：add/edit/view |
| `editing_record` | `object` | `null` | 当前编辑/查看的记录 |

**命名规范**：使用 snake_case（小写字母、数字、下划线）
