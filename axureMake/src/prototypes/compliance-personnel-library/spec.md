# 合规人员库页面规格说明 (compliance-personnel-library)

本项目是集采工作台（招标采购下的一级菜单）中的合规人员库管理页面原型。主要用户是合规人员库管理员，用于在授权的资格所属组织范围内维护合规专员、合规专家和稽查专家资格。

## 1. 业务场景与用户需求

合规人员库是系统进行一单一检自查、跨单位互查及局级稽查的核心人员数据源：
1. **多组织多资格规则**：同一账号（用户）可以同时拥有合规专员、合规专家、稽查专家等多条人员资格，且每条资格可以归属于不同的组织（如：人事属于一局，但作为合规专家资格属于局级）。
2. **多维查询**：支持按“人事所属组织”、“资格所属组织”、“人员类型”、“资格状态”等维度进行检索。
3. **资格维护**：
   - **新增/编辑**：支持选择系统内人员，并为其配置具体的人员类型、资格所属组织与状态。
   - **启/停用**：独立控制每条资格的生效状态，禁用状态的资格将不会接收新分配的检查任务。
   - **批量导入/导出**：提供符合集采平台规范的导入和导出模板与操作。

## 2. 页面布局与视觉风格

根据 `检查详情页.png` 风格（深蓝色系国企偏稳重风格，左侧深色菜单，顶部面包屑，主体部分卡片式布局，精致的表格和表单控制）：
- **布局结构**：
  - **通用布局**：使用 `CentralizedProcurementLayout` 组件，包含标准的顶部导航栏和左侧侧边栏。
20→  - **左侧导航**：深蓝色（`#3a7fc3`）侧边栏，当前选中“招标采购”下的“一单一检”下的“合规人员库”。
21→  - **顶部通栏**：提供组织切换、搜索、语言选择、快捷链接及用户信息。
22→  - **面包屑**：首页 > 招标采购 > 一单一检 > 合规人员库。
  - **主内容区**：
    - 列表页：查询卡片（折叠与展开） + 数据卡片（包含工具栏和 Table 表格）。
    - 表单页（新增/编辑）：卡片式表单布局，内容区最大宽度 800px 并左对齐展示，清晰划分“基本信息”与“资格配置”分块；保存与取消按钮与表单左侧对齐。
    - 导入弹窗：支持模板下载、文件拖拽上传、导入进度和错误校验回显。
  - **间距规范**：内容区保留 24px 水平与底部留白；面包屑与查询区间距为 20px，查询卡片与数据卡片间距为 16px。查询条件采用 24 栅格四列布局，条件项之间保持 16px 水平与垂直间距，标签与控件之间保持 8px 间距；当末行仅有一个筛选项时，查询与重置按钮占用其余栅格并靠右排列；工具栏按钮组内间距为 12px，工具栏与表格间距为 24px。
  - **背景与卡片**：主内容区及页面容器统一使用 `#f0f2f5` 灰色背景并铺满可滚动区域；查询区、数据区和表单区保持白色卡片背景、浅灰边框与圆角。

- **配色与主题**：
  - 主色：深蓝色 `#1890ff` / `#002140`
  - 辅助色：成功绿 `#52c41a`，警告黄 `#faad14`，错误红 `#f5222d`
  - 标签配色：合规专员（蓝色 Tag）、合规专家（紫/青色 Tag）、稽查专家（橙色 Tag）。
  - 查询条件标签使用 `rgba(0, 0, 0, 0.65)` 灰色，控件在栅格列内自适应填充。

## 3. 详细交互设计与组件定义

### 3.1 列表页 (List View)
- **查询区**：
  - 人员姓名：Input 文本输入。
  - 账号/手机号：Input 文本输入。
  - 人事所属组织：TreeSelect（中建一局、二局等结构）。
  - 资格所属组织：TreeSelect。
  - 人员类型：Select 多选（合规专员、合规专家、稽查专家）。
  - 资格状态：Select（全部、有效、失效、已停用）。
  - 操作按钮：“查询”主按钮，“重置”次按钮，“展开/收起”高级查询。
- **工具栏**：
  - 左侧：批量操作按钮组（“批量启用”、“批量停用”）。
  - 右侧：操作按钮组（“新增人员资格”主按钮、“批量导入”次按钮、“导出”次按钮）。
- **表格列定义**：
  - 复选框 (Checkbox)：支持批量操作。
  - 序号：自增编号。
  - 姓名：纯文本单行显示姓名和工号，如：`张合规 (zhanghegui)`，不展示头像图标。
  - 人事所属组织：显示用户的组织关系。
  - 人员类型：Tag 区分，支持单人展示多行（每条资格是一条独立记录）。
  - 资格所属组织：显示该项资格的归属组织。
  - 状态：Switch 切换（启用/停用）。
  - 更新人/更新时间：操作痕迹。
  - 操作列：编辑（链接）、详情（链接）、删除（二次确认）。

### 3.2 新增/编辑表单 (Form View)
- **卡片一：人员基本信息**：
  - 选择系统用户：Select 带搜索，可模糊检索已有账号（模拟从统一用户中心同步）。
  - 人事所属组织：只读展示；选择系统用户后，根据该账号的组织信息即时自动带出。
  - 联系电话/邮箱：只读展示。
- **卡片二：资格所属配置**：
  - 资格所属组织：TreeSelect（必填）。
  - 人员类型：Checkbox.Group 组（必填，可多选）。
  - 备注说明：TextArea。
- **表单操作**：
  - “保存”：执行校验，重复性校验（同一用户在同一组织下同类型的资格不能重复配置），反馈保存成功并返回。
  - “取消”：返回列表。

### 3.3 批量导入弹窗 (Import Modal)
- 模板下载：提供“人员资格批量导入模板.xlsx”下载超链接。
- 上传区域：支持拖拽或选择文件上传。
- 校验规则：
  - 所属组织必须存在于组织树。
  - 人员类型必须属于规定类型。
  - 异常反馈：上传后若有错，展示“校验失败”列表，清晰标明“行号”、“错误字段”和“错误原因”（如：第3行：工号 zhanghegui 在中建一局已存在合规专员资格，不能重复导入）。

## 4. 模拟数据定义 (Mock Data)

模拟 8-10 位具有代表性的用户资格记录，包含：
1. 跨组织资格：如“王合规”，人事属于中建一局，但同时在一局拥有“合规专员”资格，在局级（中国建筑）拥有“合规专家”资格。
2. 停用状态：状态为 Switch = false。
