# 我的任务页面规格文档 (Spec)

## 1. 页面概述
“我的任务”是集采工作台的核心办理入口，统一承载了检查执行、不合规处置、整改复核和申诉处理任务。

## 2. 页面布局
- **整体框架**：使用 `CentralizedProcurementLayout` 通用布局。
- **顶部区域**：面包屑导航（首页 / 招标采购 / 一单一检 / 我的任务）。
- **页签切换**：顶部设置“自查任务”、“互查任务”、“稽查任务”三个页签。
- **搜索筛选区**（页签维度隔离）：
  - 筛选条件现在位于每个页签的内容区域内，不同页签拥有独立的搜索状态和筛选结果。
  - 任务搜索：模糊搜索任务编号。
  - 任务状态：严格使用 PRD 第9.1节状态总表中的29个可保存状态，包括自查、互查、稽查各阶段状态及跨阶段的待互查、待稽查、检查已完成。
  - **招标/采购编号**：支持输入检索。
  - **招标/采购名称**：支持输入检索。
  - **合同名称**：支持输入检索。
  - **合同编号**：支持输入检索。
  - 更新时间：起止日期范围选择（已汉化，支持中文占位符和本地化显示）。
- **列表展示区**：使用 Ant Design Table 展示任务列表，设置横向滚动条 `scroll={{ x: 1800 }}` 以保证大量列宽度展示完整，支持操作列固定在右侧。
- **分页区**：底部展示分页控件。

## 3. 核心功能点
- **页签隔离**：不同页签（自查/互查/稽查）的筛选条件和搜索状态完全隔离，切换页签时保留各自的搜索输入。
- **国际化支持**：日期选择器（RangePicker）已配置为中文环境。
- **身份隔离**：根据当前登录用户的业务身份展示对应的页签和任务。
- **任务列表字段**：
  - **序号**：`render: (text, record, index) => index + 1`，自增列。
  - 任务编号
  - 任务类型（自查/互查/稽查）
  - **招标/采购编号**：例如 `cscec202608310000004851`（样式契合业务场景）。
  - **招标/采购名称**：对应招标项目名称。
  - **合同名称**：原合同信息拆分。
  - **合同编号**：原合同信息拆分。
  - **评审完成时间**：例如 `2026-08-31 15:00:00`。
  - 当前状态：使用 PRD 状态总表的完整状态名称，例如自查待处置、互查待复核、稽查复核不通过。
  - 待本人处理事项
  - 问题统计（不合规项数量）
  - 剩余时限（倒计时显示，超时标识红色高亮）
  - **操作**：支持固定在右侧（`fixed: 'right'`），状态驱动展示检查、整改、复核或查看。
- **操作逻辑**：
  - 自查、互查、稽查的待处理和进行中状态展示“检查”，进入检查执行模式。
  - 待处置、复核不通过状态展示“整改”，供合同经办人处理不合规检查项。
  - 待复核状态展示“复核”，供原检查人逐项复核整改材料。
  - 其他状态展示“查看”，以只读方式查看任务记录。
  - 点击操作进入 `/prototypes/task-execution`，使用 `taskId` 和 `mode` 参数打开对应任务及办理模式。

## 4. 视觉风格
- 遵循集采工作台统一视觉规范。
- 超时任务使用红色文字或图标预警。
- 状态标签使用不同颜色的 Tag 区分。
- 表格支持横向水平滚动以适配宽字段展示（如招标采购编号、评审完成时间、合同编号等）。

## 5. 模拟数据 (Mock Data)
- 更新 mock 结构，提供丰富的真实性数据，包括：
  - `bidNo`: 招标/采购编号
  - `bidName`: 招标/采购名称
  - `contractName`: 合同名称
  - `contractNo`: 合同编号
  - `reviewCompleteTime`: 评审完成时间
  - 其它固有字段（任务编号、任务类型、当前状态、待处理项、问题统计等）。
- 示例状态覆盖自查待处置、自查待处理、自查中、自查申诉中、互查待复核、互查待处置、互查待处理、稽查复核不通过、稽查待处理和检查已完成。
