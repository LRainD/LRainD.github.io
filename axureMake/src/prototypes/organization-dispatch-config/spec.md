# 组织业务配置页面规格说明 (organization-dispatch-config)

本项目是集采工作台（招标采购下的一级菜单）中的组织业务配置页面原型。主要用户是单位供应链负责人，用于集中配置和维护各组织的自查派发模式、超时自动收回时限等组织级业务参数。

## 1. 业务场景与用户需求

根据 PRD 要求，每个组织需要独立维护其自查任务的派发逻辑与时限规则，且未来会扩展更多配置项：
1. **配置维度**：按组织进行配置。支持在列表中查看所有已配置的组织，并支持新增、编辑和删除配置。
2. **配置项内容**：
   - **自查派发模式**：
     - **自动派发**：系统根据合同所属组织，自动从该组织的合规专员库中，按待办量均衡派发任务。
     - **人工指定**：系统生成“待派发”任务，由单位供应链负责人手动指定具体的合规专员。
   - **超时自动收回**：
     - **启用状态**：是否开启超时自动收回。
     - **收回时限**：开启后可配置具体时限（如：72小时、48小时等）。
3. **生效规则**：配置变更仅影响后续新生成的任务，不追溯历史任务。未配置时默认为“人工指定”且不自动收回。
4. **权限控制**：仅具备“维护组织业务配置”权限的用户可进行修改保存。

## 2. 页面布局与视觉风格

遵循集采工作台统一视觉规范，采用简洁实用的列表+弹窗设计：
- **布局结构**：
  - **通用布局**：使用 `CentralizedProcurementLayout` 组件。
  - **左侧导航**：选中“招标采购” > “一单一检” > “组织派发配置”。
  - **面包屑**：首页 > 招标采购 > 一单一检 > 组织派发配置。
- **主内容区**：
  - **查询卡片**：支持按组织名称、派发模式、收回状态进行过滤。
  - **工具栏**：提供“新增配置”按钮。
  - **数据表格**：展示已配置的组织列表，包含组织名称、派发模式、超时收回状态、收回时限、更新人、更新时间等列，并提供“编辑”、“删除”操作。
  - **配置弹窗**：点击“新增配置”或“编辑”时弹出，包含组织选择（TreeSelect）、派发模式选择（Radio）、超时收回开关（Switch）及收回时限输入（InputNumber）。

## 3. 详细交互设计与组件定义

### 3.1 列表查询与展示
- **查询表单**：
  - 组织名称：Input 文本输入。
  - 派发模式：Select（全部、自动派发、人工指定）。
  - 超时收回：Select（全部、已启用、已禁用）。
  - 操作按钮：“查询”与“重置”。
- **表格列定义**：
  - 序号、组织名称、自查派发模式（Tag 区分）、超时自动收回（Switch/Tag 区分）、收回时限（小时）、更新人、更新时间、操作（编辑、删除）。

### 3.2 新增/编辑弹窗 (Modal Form)
- **组织选择**：TreeSelect（必填，编辑时只读）。
- **自查派发模式**：Radio.Group（[自动派发]、[人工指定]）。
- **超时自动收回**：Switch 开关。
- **收回时限**：InputNumber（当超时自动收回开启时显示且必填，单位：小时）。
- **保存校验**：
  - 组织不能重复配置。
  - 开启超时收回时，收回时限必须大于 0。
  - 保存时提示：“配置变更仅对新生成的任务生效，是否确认保存？”

## 4. 模拟数据定义 (Mock Data)

- **组织树数据**：包含中建一局、二局、三局、四局及其下属子公司的层级结构。
- **列表数据**：
  - 中建一局：自动派发，开启超时收回（72小时）。
  - 一局一公司：人工指定，关闭超时收回。
  - 一局二公司：自动派发，开启超时收回（48小时）。
  - 中建四局：自动派发，关闭超时收回。
