# 组织业务配置页面规格说明 (organization-dispatch-config)

本项目是集采工作台（招标采购下的一级菜单）中的组织业务配置页面原型。主要用户是单位供应链负责人，用于集中配置和维护各组织的自查、互查派发模式、超时自动收回规则及自查、互查、稽查的可申诉时间。

## 1. 业务场景与用户需求

每个组织需要独立维护自查和互查任务的派发逻辑、自动派发模板、超时自动收回规则及不同检查类型的可申诉时间，且未来会扩展更多配置项：
1. **配置维度**：按组织进行配置。支持在列表中查看所有已配置的组织，并支持新增、编辑和删除配置。
2. **配置项内容**：
   - **自查派发模式**：
     - **自动派发**：系统根据合同所属组织，自动从该组织的合规专员库中，按待办量均衡派发任务。
     - **人工指定**：系统生成“待派发”任务，由单位供应链负责人手动指定具体的合规专员。
     - **自动派发模板**：当模式为自动派发时，必须选择一条已发布且适用于自查的检查模板及版本。
   - **互查派发模式**：
     - **自动派发**：系统从符合跨单位回避规则的合规专家中，按待办量均衡派发任务。
     - **人工指定**：系统生成“待派发”任务，由具备互查派发权限的人员手动指定合规专家。
     - **自动派发模板**：当模式为自动派发时，必须选择一条已发布且适用于互查的检查模板及版本。
   - **超时自动收回**：
     - 自查与互查分别维护启用状态和收回时限，开启后可配置具体时限（如：72小时、48小时等）。
   - **可申诉时间**：
     - 自查、互查、稽查分别维护可申诉时限，单位为小时，时限必须大于 0。
     - 检查结论生成后，可在对应时限内提交申诉；超出时限后不再受理。
3. **生效规则**：配置变更仅影响后续新生成的自查、互查、稽查任务，不追溯历史任务。未配置时默认“人工指定”且不自动收回；新增配置时默认自查 48 小时、互查 72 小时、稽查 120 小时可申诉。
4. **权限控制**：仅具备“维护组织业务配置”权限的用户可进行修改保存。

## 2. 页面布局与视觉风格

遵循集采工作台统一视觉规范，采用简洁实用的列表+弹窗设计：
- **布局结构**：
  - **通用布局**：使用 `CentralizedProcurementLayout` 组件。
  - **左侧导航**：选中“招标采购” > “一单一检” > “组织业务配置”。
  - **面包屑**：首页 > 招标采购 > 一单一检 > 组织业务配置。
- **主内容区**：
  - **内容容器**：内容区最大宽度为 1440px 并居中显示，左右保留 24px 间距；面包屑独立置于内容容器上方。
  - **查询卡片**：采用与合规人员库一致的白色卡片和左侧蓝色标题标识。筛选项按 4 列网格排列，组织名称、自查派发、互查派发各占一列，查询与重置按钮靠右对齐；窄屏时按网格自动换行。
  - **工具栏**：表格卡片内提供右对齐的“新增配置”按钮，并与表格保留 24px 间距。
  - **数据表格**：展示已配置的组织列表，包含组织名称、自查派发模式、互查派发模式、自动派发模板、自查与互查超时收回状态及各自时限、自查、互查、稽查可申诉时间、更新人、更新时间等列，并提供“编辑”、“删除”操作。
  - **配置弹窗**：点击“新增配置”或“编辑”时弹出，按自查、互查分别配置派发模式、自动派发模板、超时收回开关与收回时限；同时配置自查、互查、稽查的可申诉时间。

## 3. 详细交互设计与组件定义

### 3.1 列表查询与展示
- **查询表单**：
  - 组织名称：Input 文本输入。
  - 自查派发：Select（全部、自动派发、人工指定）。
  - 互查派发：Select（全部、自动派发、人工指定）。
  - 操作按钮：“查询”与“重置”。
- **表格列定义**：
  - 序号、组织名称、自查派发模式（Tag 区分）、互查派发模式（Tag 区分）、自动派发模板（自查与互查分别展示）、超时自动收回（自查与互查分别展示开关状态和时限）、可申诉时间（自查、互查、稽查分别展示）、更新人、更新时间、操作（编辑、删除）。

### 3.2 新增/编辑弹窗 (Modal Form)
- **组织选择**：TreeSelect（必填，编辑时只读）。
- **自查配置**：Radio.Group（[自动派发]、[人工指定]）；选择自动派发时显示必填模板 Select，仅提供检查模板管理页中“已发布且适用于自查”的模板版本；另配置超时自动收回 Switch 和收回时限 InputNumber（开启时显示且必填，单位：小时）。
- **互查配置**：Radio.Group（[自动派发]、[人工指定]）；选择自动派发时显示必填模板 Select，仅提供检查模板管理页中“已发布且适用于互查”的模板版本；另配置超时自动收回 Switch 和收回时限 InputNumber（开启时显示且必填，单位：小时）。
- **可申诉时间配置**：自查、互查、稽查分别使用必填 InputNumber 配置，单位为小时，最小值为 1。
- **保存校验**：
  - 组织不能重复配置。
  - 自动派发时必须选择对应检查类型的已发布模板；人工指定时不保存模板配置。
  - 自查或互查开启超时收回时，对应收回时限必须大于 0。
  - 自查、互查、稽查的可申诉时间均必须大于 0。
  - 保存时提示：“配置变更仅对新生成的自查、互查、稽查任务生效，是否确认保存？”

## 4. 模拟数据定义 (Mock Data)

- **组织树数据**：包含中建一局、二局、三局、四局及其下属子公司的层级结构。
- **列表数据**：
  - 中建一局：自查自动派发并使用“一局普通合同检查模板（V1.0）”，开启收回（72小时）；互查人工指定并关闭收回；自查、互查、稽查可申诉时间分别为 48、72、120 小时。
  - 一局一公司：自查人工指定并关闭收回；互查自动派发并使用“跨单位互查检查模板（V1.2）”，开启收回（48小时）；自查、互查、稽查可申诉时间分别为 48、72、120 小时。
  - 一局二公司：自查自动派发并使用“采购合同专项检查模板（V2.0）”，开启收回（48小时）；互查自动派发并使用“跨单位互查检查模板（V1.2）”，开启收回（72小时）；自查、互查、稽查可申诉时间分别为 24、48、72 小时。
  - 中建四局：自查自动派发并使用“一局普通合同检查模板（V1.0）”；互查人工指定，均关闭超时收回；自查、互查、稽查可申诉时间分别为 48、72、120 小时。
