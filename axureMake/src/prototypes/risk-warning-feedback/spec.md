# 预警核查运营列表迭代 PRD

## 1. 迭代目标
在运营后台的风控预警中心新增预警核查列表，帮助运营人员集中查看用户针对风控预警提交的问题说明，并查看同一条预警的全部历史反馈。

## 2. 新增页面
- 菜单位置：风控预警中心 > 预警核查
- 页面提供查询区和反馈列表。
- 查询区支持按“是否满意”和“是否反馈”筛选。
- 页面权限：查看、编辑：目前不设权限码，放阿波罗配置。例如：查看列表：wanggnang 编辑列表：wanggang、lufang 则表示只有 wanggnang 可查看列表，wanggang、lufang 可编辑列表。

## 3. 列表迭代内容

### 3.1 序号
- 在列表最左侧新增固定“序号”列，按当前列表顺序从 1 开始展示。

### 3.2 是否满意
- 在列表新增“是否满意”列，展示用户对该条预警提交的唯一满意度评价。
- 取值包括：满意、不满意、未评价。
- 一条预警只能提交一次满意度评价；后续重复提交问题反馈不会覆盖该评价。

### 3.3 操作
- 在列表新增“操作”列，反馈数量列。
- 存在反馈记录时，展示“查看问题反馈”按钮。
- 没有反馈记录时，按钮不可点击。
- 操作列展示“解除风险”按钮；点击后以气泡确认框二次确认，确认后提示“解除成功”并将该预警状态更新为“已解除”。预警解除状态为“已解除”时，该按钮置灰且不可点击。

### 3.4 与业务预警页面不同的列，取自预警监控页：当前数据、预警解除状态与审查依据
- 列表新增“当前数据”列，展示命中预警时用于判定的核心业务数据。
- 列表新增“预警解除状态”列，取值为“已解除”或“未解除”，分别使用成功和警告标签展示。
- 列表新增“审查依据”列，每行提供“查看依据”操作。
- 点击“查看依据”后打开居中弹窗，展示思考过程，目前仅支持大模型规则。

### 3.4 筛选条件
- 组织机构：下拉选择全部、发展公司西南分公司，支持“包含下级”复选框。
- 业务域：下拉选择云筑集采。
- 业务编号：输入框。
- 业务名称：输入框。
- 业务类型：下拉选择。
- 业务环节：下拉选择。
- 经办人：输入框。
- 预警级别：下拉选择。
- 检测场景：展示“合规自查”“合规自查、风控预警”或“风控预警”。
- 预警类型：下拉选择。
- 预警规则：下拉选择。
- 预警时间：日期范围选择器。
- 是否满意：下拉选择“是”或“否”；“是”筛选满意度评价为“满意”的数据，“否”筛选满意度评价为“不满意”的数据。
- 是否反馈：下拉选择“是”或“否”；“是”筛选反馈次数大于 0 的数据，“否”筛选反馈次数为 0 的数据。
- 包含已废标/已废除数据：复选框。
- 支持折叠/展开功能。

## 4. 查看问题反馈

### 4.1 打开方式
- 点击“查看问题反馈”按钮后，从页面右侧打开“问题反馈记录”详情面板。
- 面板顶部展示该条预警对应的业务编号、业务名称和预警规则，便于确认当前查看对象。

### 4.2 多次反馈展示
- 同一条预警允许用户多次提交反馈。
- 详情面板需展示该预警的全部反馈记录，并按反馈时间从新到旧排列。
- 面板中显示反馈总数。

### 4.3 单条反馈内容
每条记录展示以下内容：
- 反馈序号和反馈时间。
- 问题类型。
- 问题说明。
- 用户上传的附件；未上传时显示“无”。

## 5. 验收标准
1. 左侧“风控预警中心”菜单下可以进入“问题反馈”页面。
2. 页面顶部、左侧菜单栏与运营后台现有页面保持一致。
3. 列表最左侧固定展示按当前顺序递增的“序号”字段，并在“预警类型”左侧展示“检测场景”字段，同时展示“当前数据”“预警解除状态”“审查依据”“是否满意”“反馈次数”和“操作”字段。
4. 每条预警的满意度只能保存一条，重复反馈不会改变已记录的满意度。
5. 点击“查看问题反馈”可查看对应预警的反馈详情。
6. 一条预警有多次反馈时，详情面板能够完整展示全部记录，且最新记录排在最前。
7. 无反馈记录的预警不可进入反馈详情。
8. 筛选条件栏支持三列网格布局，支持折叠/展开，样式与截图高度一致。
9. 点击“查看依据”可打开审查依据弹窗；分供商维度依据支持展开和收起。 
10. 操作列展示“解除风险”按钮，点击时显示二次确认气泡；确认后提示解除成功、更新解除状态，已解除预警的按钮为禁用状态。
11. “是否满意”支持按满意度评价为是或否筛选；“是否反馈”支持按反馈次数大于 0 或等于 0 筛选。
