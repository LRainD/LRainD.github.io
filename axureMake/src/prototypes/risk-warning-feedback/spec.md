# 问题反馈运营列表迭代 PRD

## 1. 迭代目标
在运营后台的风控预警中心新增问题反馈列表，帮助运营人员集中查看用户针对风控预警提交的问题说明，并查看同一条预警的全部历史反馈。

## 2. 新增页面
- 菜单位置：风控预警中心 > 业务预警
- 页面提供查询区和反馈列表。
- 查询区支持按“是否满意”和“是否反馈”筛选。

## 3. 列表迭代内容

### 3.1 是否满意
- 在列表新增“是否满意”列，展示用户对该条预警提交的唯一满意度评价。
- 取值包括：满意、不满意、未评价。
- 一条预警只能提交一次满意度评价；后续重复提交问题反馈不会覆盖该评价。

### 3.2 操作
- 在列表新增“操作”列，反馈数量列。
- 存在反馈记录时，展示“查看问题反馈”按钮。
- 没有反馈记录时，按钮不可点击。

### 3.3 筛选条件
- 是否满意：下拉选择满意、不满意、未评价。
- 是否反馈：下拉选择是、否。
- 选择“是”时，仅展示已有问题反馈记录的预警；选择“否”时，仅展示未提交问题反馈的预警。

## 4. 查看问题反馈

### 4.1 打开方式
- 点击“查看问题反馈”按钮后，从页面右侧打开“问题反馈记录”详情面板。
- 面板顶部展示该条预警对应的业务编号、业务名称和预警规则，便于确认当前查看对象。

### 4.2 多次反馈展示
- 同一条预警允许用户多次提交反馈。
- 详情面板需展示该预警的全部反馈记录，并按反馈时间从新到旧排列。
- 面板中显示反馈总数。

### 4.3 单条反馈内容
每条记录展示以下内容：
- 反馈序号和反馈时间。
- 问题类型。
- 问题说明。
- 用户上传的附件；未上传时显示“无”。

## 5. 验收标准
1. 左侧“风控预警中心”菜单下可以进入“问题反馈”页面。
2. 页面顶部、左侧菜单栏与运营后台现有页面保持一致。
3. 列表展示截图中的业务预警基础数据，并新增“是否满意”“反馈次数”和“操作”字段。
4. 每条预警的满意度只能保存一条，重复反馈不会改变已记录的满意度。
5. 点击“查看问题反馈”可查看对应预警的反馈详情。
6. 一条预警有多次反馈时，详情面板能够完整展示全部记录，且最新记录排在最前。
7. 无反馈记录的预警不可进入反馈详情。
