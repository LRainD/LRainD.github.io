# 招标基础信息页面规格说明 (Spec)

## 业务与功能
- **定位**：企业级集采工作台的招标基础信息详情页。
- **核心目标**：展示招标项目的关键信息、截标倒计时以及关联的问题线索，辅助用户快速掌握项目全貌与风险情况。
- **功能清单**：
  1. 全局导航：左侧边栏菜单与顶部导航条。
  2. 招标信息卡：展示招标编号、组织机构、招标方式、项目、品类、经办人等关键字段。
  3. 截标倒计时：以天/时/分/秒形式展示距离截标截止的剩余时间。
  4. 问题线索表格：使用 Ant Design `Table` 组件展示企业核实处置情况，支持合并表头。

## 内容规划
- **信息架构**：
  - 左侧边栏 (Sidebar)：一级功能导航，当前位于「招标采购 > 非招标采购」路径下。
  - 顶部导航 (Header)：系统 Logo、全局搜索、语言切换、快捷入口、用户中心。
  - 主内容区 (Main Content)：
    - 面包屑导航
    - 标题栏（含类型标签与返回按钮）
    - 招标信息卡
    - 截标倒计时
    - 问题线索表格

## 问题线索表格

### 列定义
| 层级 | 列名 | 字段 | 说明 |
|------|------|------|------|
| 一级 | 序号 | - | 渲染为当前行索引 + 1 |
| 一级 | 问题分类 | `category` | 问题所属类别 |
| 一级 | 主要问题线索 | `clue` | 问题线索描述，列宽 260px，文本自动换行 |
| 一级（合并） | 企业核实处置情况 | - | 下方包含 6 个子列 |
| 二级 | 是否属实 | `verified` | 核实结论 |
| 二级 | 问题线索核查情况 | `investigation` | 核查过程与结果说明 |
| 二级 | 是否完成整改 | `rectified` | 整改完成状态 |
| 二级 | 整改进展情况 | `progress` | 当前整改进度描述 |
| 二级 | 追责人次 | `accountabilityCount` | 追责人员数量，为 0 时显示为 `-` |
| 二级 | 问题移送情况 | `transfer` | 线索移送去向 |

## 布局与结构
- **整体布局**：左侧固定侧边栏（展开 256px / 收起 64px），右侧为主操作区；主操作区上方为固定 Header（56px），下方为可滚动内容区。
- **模块划分**：
  - 招标信息卡采用四列网格布局展示字段。
  - 问题线索使用整宽表格，开启边框与紧凑尺寸，合并表头展示企业核实处置情况。

## 视觉规范
- **主题风格**：典型的 ToB 管理系统风格。
- **色彩规范**：
  - 侧边栏背景：品牌蓝色（`#007add`）
  - 主色调：蓝色（`#007add`）
  - 主内容区背景：浅灰（`#f5f7fa`）
  - 模块背景：纯白
  - 文本颜色：标题深灰（`#333333`），次要文本灰（`#666666`）
- **字体与图标**：无衬线字体，Lucide 图标库；表格使用 Ant Design 组件。
