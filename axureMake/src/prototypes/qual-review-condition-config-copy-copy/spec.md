# 资格审查条件豁免场景配置 — 页面规格（当前版本）

> 本页由旧版「资格审查条件豁免配置」拷贝而来，2026-10-30 完成第一轮列精简，后续按需迭代。

## 一、页面定位

在「解决方案 > 运营解决方案配置」下，按「采购品类 + 采购类型 + 招标方式」配置供应商需要满足的资格审查条件，并限定每条资审条件适用的二级品类。

左侧为解决方案组成树，右侧为「方案配置 / 配置下发 / 功能说明 / 操作日志」四个 Tab，当前仅「方案配置」有内容。

## 二、主表格（条件配置行）

只保留 4 列：

| 列 | 交互 | 说明 |
| --- | --- | --- |
| 采购品类 | 多选 | 物资、设备、劳务分包、专业分包、专业服务、租赁 |
| 采购类型&组织形式 | 多选 | 招标采购、区域联采、战略采购、集中采购、分散采购、电子商城采购 |
| 招标方式&采购方式 | 多选 | 公开招标、邀请招标、询比采购、竞价采购、谈判采购 |
| 操作 | 按钮 | 「添加资格审查条件」（在该行下新增一条子表行）、「删除」（删除该配置行） |

列宽按 20% / 27% / 28% / 25% 固定分配（`tableLayout="fixed"`），避免多选标签把列挤窄。

已移除列：强制使用、AI智能推荐资审条件、是否只使用AI智能推荐资审条件、资格后审是否开启资审、资格后审是否开启符合性审查、是否启用文件检测。

## 三、子表格（资格审查条件项）
每条配置行下方挂一个子表，共 5 列：

| 列 | 交互 | 说明 |
| --- | --- | --- |
| 资格审查条件项 | 树形下拉 | 选「自定义」时名称为空且审查方式为人工；选风控/文件检测类节点时自动带出名称与分类 |
| 资格审查条件名称 | 只读 | 由「资格审查条件项」带出，不允许手工修改；未带出时显示「-」 |
| 区域 | 区域树多选 | 见第五节 |
| 适用合作品类（必填） | 三级品类多选树 | 列名前带红色星号，见第四节 |
| 审查依据列展示 | 文本输入 | 默认为空白文本框，由用户手工填写，见第六节 |

已移除列：资格审查强度、资格审查条件分类、审查方式、映射编码、是否强制使用、操作（子表行的删除入口随之移除，如需恢复再加）。

## 四、适用合作品类（三级品类树）

原列名为「不适用二级品类」，语义由「排除」改为「适用」，列名改为「适用合作品类」，且为必填项（列名前带红色星号）。

### 数据层级

品类按「一级品类 → 二级品类 → 三级品类」组织，共 6 个一级品类：

| 一级品类 | 二级品类（示例） | 三级品类（示例） |
| --- | --- | --- |
| 物资 | 钢材、水泥及制品、混凝土、砂石骨料、管材、电线电缆、砌体材料 | 钢材下：螺纹钢、盘螺、线材、圆钢、型钢、钢板 |
| 设备 | 机械设备、电气设备、仪器仪表、电梯、暖通设备 | 机械设备下：起重机械、土方机械、混凝土机械、运输车辆 |
| 劳务分包 | 主体结构劳务、土建劳务、安装劳务、装饰劳务、其他类 | 主体结构劳务下：钢筋劳务、模板劳务、混凝土劳务 |
| 专业分包 | 地基基础工程专业承包、钢结构工程、幕墙工程、机电安装工程、消防设施工程、建筑装饰装修工程 | 幕墙工程下：玻璃幕墙、石材幕墙、金属幕墙 |
| 专业服务 | 勘察设计、工程监理、检测检验、造价咨询、招标代理 | 检测检验下：材料检测、结构检测、无损检测 |
| 租赁 | 设备租赁、周转材料租赁 | 设备租赁下：塔吊租赁、施工电梯租赁、泵车租赁 |

三级清单为演示口径，最终以业务品类主数据为准。

### 交互规则

1. 点击单元格展开三级品类树面板，逐级下钻；支持输入关键字搜索定位。
2. 多选、可跨一级品类选择；勾选一级/二级节点会联动勾选其下全部子节点。
3. 展示采用 `SHOW_PARENT` 策略：某个二级品类下全部三级品类都勾选时，单元格只显示该二级品类名称（如「钢材」）；只勾部分三级时，显示所勾的三级名称。
4. 单元格最多显示 2 个标签，超出折叠为「+N …」；支持一键清除。
5. 不选表示该资审条件对全部品类均适用。
6. 新增一条资审条件时该列为空。

## 五、区域

| 上海市 | 市辖区 | 黄浦区、徐汇区、浦东新区、闵行区 |
| 广东省 | 广州市、深圳市、佛山市、东莞市 | 天河区、福田区、南山区、禅城区… |
| 江苏省 | 南京市、苏州市、无锡市 | 玄武区、姑苏区、梁溪区… |
| 浙江省 | 杭州市、宁波市、温州市 | 上城区、西湖区、鄞州区… |
| 四川省 | 成都市、绵阳市、宜宾市 | 锦江区、涪城区、翠屏区… |

区域清单为演示口径，最终以业务区域主数据（行政区划）为准。

### 交互规则

1. 点击单元格展开区域树，默认只展开「全国」，按需逐级下钻；支持关键字搜索。
2. 多选、可跨省选择；勾选某一级节点会联动勾选其下全部下级节点。
3. 展示采用 `SHOW_PARENT` 策略：某节点下全部下级都勾选时只显示该节点名称（如勾「广东省」→ 显示「广东省」）。
4. 单元格最多显示 2 个标签，超出折叠；支持一键清除。
5. 不选表示该条件在全国范围均适用。

## 六、审查依据列展示

位于子表最后一列（列名即「审查依据列展示」），语义为：当该资审项原本不通过、后被改为通过时，展示在审查依据列的文案。

- 单元格是可编辑文本框，默认空白（placeholder「请输入」），不随「资格审查条件项」自动带出内容。
- 切换条件项不会清空、也不会覆盖已填写的内容。
- 种子行与新增行该字段均为空字符串。
- 表头带问号，悬停说明上述语义与填写方式。

## 七、状态与数据

页面数据全部为组件内 `useState`，刷新即恢复种子数据（一条配置行 + 一条「自定义」条件项）。暂未接本地持久化。
