# 资格审查条件配置 —「不适用二级品类」功能说明（PRD）

## 一、需求背景

资格审查条件通常按采购品类配置，但同一资审条件并非对所有二级品类都适用。例如「具备某项专业资质」对物资类采购无意义，若不做区分，会导致不适用的品类也被要求满足该条件，影响供应商报名与资审效率。

因此需要在资审条件行上明确「该条件不适用于哪些二级品类」，让配置人员在维护资审方案时一次性表达清楚适用范围。

## 二、需求目标

1. 支持对每一条资格审查条件单独设置不适用的二级品类。
2. 品类选择覆盖五大一级品类及其下属二级品类，避免逐条手工选择。
3. 配置结果直观可见，便于复核与调整。

## 三、功能说明

在「资格审查条件项」列表中，每条资审条件新增一列「不适用二级品类」，位置在「是否强制使用」之后、「操作」之前。

- 该列用于选择本条资审条件不适用于哪些二级品类。
- 不做选择时，表示该条件对全部二级品类均适用。
- 选择后，所选二级品类在本条资审条件中视为不适用，即不要求该品类下的供应商满足该条件。
- 每条资审条件独立配置，互不影响。

## 四、品类选择范围

品类按「一级品类 - 二级品类」两级组织，一级品类为五大类：

| 一级品类 | 二级品类 |
| --- | --- |
| 物资 | 钢材、水泥及制品、混凝土、砂石骨料、管材、电线电缆、砌体材料 |
| 设备 | 机械设备、电气设备、仪器仪表、电梯、暖通设备 |
| 劳务分包 | 主体结构劳务、土建劳务、安装劳务、装饰劳务、其他类 |
| 专业分包 | 地基基础工程专业承包、钢结构工程、幕墙工程、机电安装工程、消防设施工程、建筑装饰装修工程 |
| 专业服务 | 勘察设计、工程监理、检测检验、造价咨询、招标代理 |

说明：以上二级品类为当前示例口径，最终以业务品类主数据为准。

## 五、交互规则

1. 点击该列单元格展开品类选择面板，面板按「一级品类 - 二级品类」层级展示。
2. 支持同时选择多个二级品类，可跨一级品类选择。
3. 勾选某个一级品类时，其下全部二级品类一并选中；取消勾选则一并取消。
4. 已选项以标签形式展示在单元格内；超出列宽时收起显示，选择较多时不影响表格阅读。
5. 支持一键清除已选品类，恢复为「全部品类均适用」。
6. 新增一条资审条件时，该列默认为空。
7. 该列仅用于表达适用范围，不改变「是否强制使用」等其他列的配置结果。

## 六、使用场景示例

某条资审条件为「具备安全生产许可证」：

- 在「不适用二级品类」中选择「物资 / 钢材」「物资 / 水泥及制品」。
- 则表示钢材、水泥及制品类采购不强制要求供应商满足该条件，其他二级品类仍按原规则执行。

## 七、待确认事项

1. 五大一级品类及其二级品类的正式清单与口径。
2. 当主表格已限定「采购品类」时，「不适用二级品类」是否需要只展示该行已选品类下的二级品类。
3. 已选品类与主表格采购品类冲突时（例如主表格只选了物资，却选择了设备下的二级品类）是否需要提示或限制。
