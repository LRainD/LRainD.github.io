# 业务类型管理 PRD

## 1. 文档信息

- **文档名称**：业务类型管理需求文档
- **适用页面**：业务类型管理
- **目标读者**：前端研发、后端研发、测试、产品
- **文档状态**：评审稿

---

## 2. 背景与目标

### 2.1 背景

合同模板系统需要一套可维护的业务分类体系，用于对模板进行归类。运营管理员通过「业务类型管理」页面对分类进行增删改查，保证模板归属清晰、检索高效。

### 2.2 目标

- 提供业务分类的树形列表查看能力。
- 支持按分类名称快速搜索定位。
- 支持新增、编辑、删除业务分类。
- 支持维护父子层级关系，分类层级可无限扩展。

---

## 3. 术语定义

| 术语 | 说明 |
|------|------|
| 业务类型 / 分类 | 合同模板的归属分类，存在父子层级，层级可无限扩展 |
| 父级分类 | 作为其他分类上级的分类 |
| 子分类 | 挂在某个分类下的下级分类 |
| 一级分类 | 没有父级的顶层分类 |
| 分类编码 | 分类的业务编码，必填 |
| 关联模板数 | 当前分类已关联的合同模板数量 |

---

## 4. 功能范围

本页面包含以下功能模块：

1. 业务类型列表（含搜索、展开/收起）
2. 新增业务类型
3. 编辑业务类型
4. 删除业务类型

---

## 5. 功能需求

### 5.1 业务类型列表

#### 5.1.1 功能描述

以树形表格展示业务分类数据，支持查看分类的层级关系、编码、关联模板数、更新时间、更新人，并支持按分类名称搜索、节点展开/收起。

#### 5.1.2 列表字段

| 字段 | 说明 | 示例 |
|------|------|------|
| 分类名称 | 分类的中文名称，有子分类时左侧显示展开/收起图标 | 136合同中心应用 |
| 分类编码 | 分类的业务编码，必填 | CONTRACT_CENTER |
| 关联模板/个 | 当前分类关联的模板数量 | 45 |
| 最近更新时间 | 分类最后一次更新时间 | 2026-07-10 15:07:17 |
| 最近更新人 | 分类最后一次更新人，展示头像及姓名 | 幂律专属测试 |
| 操作 | 行内操作入口，包含删除、新增、编辑三个按钮；分别对应下文的删除业务类型、新增业务类型、编辑业务类型功能 | - |

#### 5.1.3 层级展示规则

- 数据为树形结构，支持无限层级扩展。
- 系统可配置默认展开的节点，用于高亮展示重点分类。
- 有子分类的节点在分类名称列显示展开/收起图标；无子分类的节点不显示图标。
- 展开图标状态：
  - 收起态：显示右向箭头
  - 展开态：显示下向箭头
- 点击展开图标切换当前节点的展开/收起状态，不影响其他节点。
- 子分类下仍可继续新增下级分类，层级无上限。

#### 5.1.4 搜索过滤

用户可在搜索框输入分类名称关键字，实时过滤列表数据。

- 搜索框占位文案：`输入分类名称搜索`。
- 输入完成后按回车键触发搜索，不输入时不触发过滤。
- 过滤逻辑：
  - 去除输入内容首尾空格。
  - 命中节点时，展示该节点及其父级路径，路径上的节点自动展开。
- 清空搜索框后，列表恢复展示全部数据。

边界情况：

- 输入纯空格：视为空搜索，展示全部数据。
- 无匹配结果：表格展示空状态。

#### 5.1.5 展开/收起

用户可单独展开或收起有子分类的节点，也可一键收起所有节点。

- 单节点展开/收起：
  - 点击分类名称列的展开/收起图标切换当前节点状态。
  - 点击图标时不触发行内其他操作。
  - 切换逻辑：若当前节点已展开，则收起；否则展开。
- 全部收起：
  - 点击标题栏「全部收起」按钮，所有节点收起。

默认状态：

- 页面初始化时，默认收起所有节点。

#### 5.1.6 数据为空

- 搜索无结果时，表格展示空状态提示。
- 列表数据为空时，表格展示空状态提示。

### 5.2 新增业务类型

#### 5.2.1 功能描述

用户可新增一级分类，也可在任意已有分类下新增下级分类。分类层级可无限延伸，例如在一级分类下新增二级分类，在二级分类下新增三级分类，以此类推。

父级分类支持多选：选择多个父级分类时，系统会在每一个选中的父级分类下，各新增一个分类名称和分类编码完全相同的分类，实现相同分类的批量挂载。若父级分类为空，则新增为一级分类。

#### 5.2.2 入口

新增业务类型提供两个入口，差异如下：

| 入口 | 位置 | 父级分类默认值 | 新增结果 |
|------|------|---------------|---------|
| 标题栏「新增分类」按钮 | 页面右上角标题栏 | 空 | 新增为一级分类 |
| 表格行内「新增」按钮 | 每条数据的操作列 | 当前行分类 | 新增为当前分类的下级分类 |

- 标题栏「新增分类」按钮：父级分类为空，新增后作为一级分类展示。
- 表格行内「新增」操作：以当前行作为父级分类新增其下级分类。

#### 5.2.3 表单字段

| 字段 | 必填 | 规则 |
|------|------|------|
| 分类名称 | 是 | 必填，为空时提示「请输入分类名称」；长度不超过 50 个字符 |
| 分类编码 | 是 | 必填，为空时提示「请输入分类编码」；长度不超过 50 个字符 |
| 父级分类 | 否 | 多选；选择多个父级时，在每个父级下各新增一个同名同编码的分类；未选择父级时，新增为一级分类 |

#### 5.2.4 父级分类回填规则

- 从标题栏「新增分类」进入：父级分类字段为空。
- 从行内「新增」进入：
  - 自动回填当前行为父级。
  - 用户可在此基础上继续选择或取消其他父级；若取消全部已选父级，则新增分类为一级分类。

#### 5.2.5 父级分类选择器规则

- 选项数据为系统中已有的全部分类，覆盖所有层级。
- 新增模式下父级分类支持多选，每个父级分类必须独立勾选，父子节点之间不做级联联动；勾选父级时不会自动勾选其所有子分类，勾选子分类时也不会自动勾选其父级。
- 用户可选择任意已有分类作为父级，包括深层级分类。
- 选择多个父级时，提交后会在每个父级下各创建一个分类名称和分类编码相同的分类。
- 支持清空已选父级；清空后新增为一级分类。

#### 5.2.6 提交规则

- 点击「确定」按钮触发表单校验。
- 校验分类名称和分类编码长度，超过限制时给出提示并阻止提交。
- 校验通过后，先校验同一父级分类下是否已存在相同分类名称或分类编码：
  - 若存在，提示具体重复信息并阻止提交。
  - 若不存在，继续提交。
- 提交数据：
  - 若父级分类为空，新增一个一级分类。
  - 若父级分类为单选，在指定父级下新增一个子分类。
  - 若父级分类为多选，在每个选中的父级下各新增一个分类名称和分类编码相同的子分类；每个父级下均需单独校验重复。
- 提交成功后关闭编辑视图并刷新列表。
- 提交失败时保留表单状态并提示错误信息。

#### 5.2.7 异常处理

- 分类名称为空：提示「请输入分类名称」，阻止提交。
- 分类名称超过 50 个字符：提示「分类名称不能超过 50 个字符」，阻止提交。
- 分类编码为空：提示「请输入分类编码」，阻止提交。
- 分类编码超过 50 个字符：提示「分类编码不能超过 50 个字符」，阻止提交。
- 同一父级分类下已存在相同分类名称：提示「父级分类「XXX」下已存在相同分类名称，请修改」，文案中需列出所有存在重复的父级分类名称；若存在多个重复父级，全部点名展示，阻止提交。
- 同一父级分类下已存在相同分类编码：提示「父级分类「XXX」下已存在相同分类编码，请修改」，文案中需列出所有存在重复的父级分类名称；若存在多个重复父级，全部点名展示，阻止提交。

### 5.3 编辑业务类型

#### 5.3.1 功能描述

用户可修改已有分类的名称、编码及所属父级分类。

#### 5.3.2 入口

- 表格行内「编辑」操作。

#### 5.3.3 表单字段

| 字段 | 必填 | 规则 |
|------|------|------|
| 分类名称 | 是 | 必填，为空时提示「请输入分类名称」；长度不超过 50 个字符 |
| 分类编码 | 是 | 必填，为空时提示「请输入分类编码」；长度不超过 50 个字符 |
| 父级分类 | 否 | 单选，仅可选择一个父级分类 |

#### 5.3.4 数据回填规则

- 分类名称：回填当前分类名称。
- 分类编码：回填当前分类编码。
- 父级分类：
  - 若当前分类存在父级，回填其直属父级。
  - 若当前分类为顶层分类，父级字段为空。

#### 5.3.5 父级分类选择器规则

- 编辑模式下父级分类为单选，不支持多选。
- 选项数据来源与新增模式一致。
- 用户可将一级分类的父级清空，表示保持为一级分类。

#### 5.3.6 提交规则

- 点击「确定」按钮触发表单校验。
- 校验分类名称和分类编码长度，超过限制时给出提示并阻止提交。
- 校验通过后，先校验变更后的父级分类下是否已存在相同分类名称或分类编码（除当前分类自身外）：
  - 若存在，提示具体重复信息并阻止提交。
  - 若不存在，继续提交。
- 提交成功后关闭编辑视图并刷新列表。
- 提交失败时保留表单状态并提示错误信息。

#### 5.3.7 异常处理

- 分类名称为空：提示「请输入分类名称」，阻止提交。
- 分类名称超过 50 个字符：提示「分类名称不能超过 50 个字符」，阻止提交。
- 分类编码为空：提示「请输入分类编码」，阻止提交。
- 分类编码超过 50 个字符：提示「分类编码不能超过 50 个字符」，阻止提交。
- 同一父级分类下已存在相同分类名称：提示「父级分类「XXX」下已存在相同分类名称，请修改」，文案中需列出所有存在重复的父级分类名称；若存在多个重复父级，全部点名展示，阻止提交。
- 同一父级分类下已存在相同分类编码：提示「父级分类「XXX」下已存在相同分类编码，请修改」，文案中需列出所有存在重复的父级分类名称；若存在多个重复父级，全部点名展示，阻止提交。

### 5.4 删除业务类型

#### 5.4.1 功能描述

用户可删除已有的业务分类，删除前需二次确认。

#### 5.4.2 入口

- 表格行内「删除」操作。

#### 5.4.3 交互规则

- 点击「删除」后弹出二次确认对话框。
- 对话框标题：`确认删除`。
- 对话框内容：`是否删除分类「${分类名称}」？`。
- 操作按钮：
  - 确认：执行删除，删除成功后刷新列表。
  - 取消：关闭对话框，无其他操作。

#### 5.4.4 删除后处理

- 删除成功后刷新列表，关闭确认框。
- 删除失败时在确认框内或页面上提示错误信息。

#### 5.4.5 边界情况

- 待删除分类存在子分类：允许删除，删除后其下所有子分类级联删除。
- 待删除分类已关联模板：允许删除，删除后模板与该分类的关联关系需解除或置为空。

---

## 6. 数据迁移要求

本系统为老系统重构项目，应用分类数据需从老系统完整清洗迁移至新系统。

- **全量迁移**：老系统中所有应用分类数据必须全部导入新系统，不允许遗漏。
- **关联关系保留**：分类与模板的关联关系需在迁移后正确保留或重新绑定。
- **迁移验证**：迁移完成后需进行数据对账，确保新系统中分类数量、层级结构、关键字段与老系统一致。
- **回滚方案**：迁移过程需提供回滚机制，确保出现异常时可恢复至迁移前状态。
