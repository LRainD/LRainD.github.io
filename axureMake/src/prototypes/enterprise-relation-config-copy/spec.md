# 企业关联-配置页面 迭代-增加配置

## 📋 业务与功能

### 1.1 核心目标

为企业关联检测提供配置入口，支持用户选择待检测企业、配置关联层级与关系类型，最终发起检测任务。

### 1.2 功能清单

- **检测企业配置**：手动添加或批量导入企业，支持企业名称搜索联想与统一社会信用代码回填。
- **关联层级设置**：选择关联路径层数（1-5 层）。
- **关系类型设置**：勾选人员关系（董监高、法定代表人、股东）、机构隶属（分支机构）及其他关系类型（相同电话号码/邮箱/地址、涉诉关联、知识产权公有）。
- **协议确认与检测**：阅读并同意服务协议后，满足条件即可开始检测。

### 1.3 交互要点

- 点击「批量导入企业」按钮，弹出批量导入企业弹窗。
- 弹窗顶部提供 Tab 切换：「手动输入企业名称」和「导入 Excel 文件」。
- 手动输入模式下，提供多行文本框，可换行批量输入企业名称；无内容时「确定提交」按钮禁用。
- 导入 Excel 模式下，支持上传导入文件、下载导入模版、查看已上传文件列表及删除操作。
- 已上传文件为空时，文件列表展示「暂无数据」空状态；「确定提交」按钮禁用。
- 企业名称输入时，满足条件（≥2 字符且不包含“公司”）触发 0.5s 防抖搜索，展示下拉联想列表。
- 勾选「股东」后展开持股比例范围输入，结束值必须大于起始值。
- 勾选「涉诉关联」后展开裁判文书份数输入。
- 勾选「知识产权公有」后展开软件著作权与专利份数输入。
- 上述额外配置项在关系类型行下方独立展开，不影响同一行高度，仅向下推开下方内容。
- 「开始检测」按钮在企业列表非空且已同意协议时可用。

### 2.2 数据来源

- **数据类型**：企业列表、搜索建议、配置参数
- **数据源**：页面内部状态生成示例数据
- **关键字段**：
  - `id`: 企业项唯一标识
  - `seq`: 序号
  - `name`: 企业名称
  - `creditCode`: 统一社会信用代码

### 2.3 内容示例

- 企业名称搜索示例：北京/上海/深圳等城市 + 关键词 + 科技有限公司 等后缀
- 默认关系类型：董监高、法定代表人、股东、分支机构
- 默认关联层级：5层

## 🎨 布局与结构

### 3.1 整体布局

- **布局模式**：双栏（左侧固定侧边栏 + 右侧主内容区）
- **容器宽度**：侧边栏展开 200px / 收起 64px；主内容区流式自适应
- **关键尺寸**：
  - 侧边栏：`w-[200px]` / `w-16`，固定高度
  - 主内容区：左侧预留 `ml-[200px]` / `ml-16`

### 3.2 响应式适配

- 桌面端：完整双栏布局
- 平板/移动端：可折叠侧边栏，主内容区随动

## 🎨 视觉规范

### 4.1 设计规范来源

**设计规范来源**：内置 interface-design

**说明**：采用 Tailwind CSS 原子类实现，主色调为 `#1677FF`，背景色 `#F5F5F5`，文本色 `#262626` / `#595959` / `#8C8C8C`。

### 4.2 自定义设计要点

**自定义色彩**：
- `#1677FF`：主按钮、选中态、链接
- `#FF4D4F`：删除、必填、错误提示
- `#FA8C16`：标签背景
- `#F5F5F5`：页面背景

**自定义尺寸**：
- 步骤条圆点：32px
- 面板标题左侧色块：4px × 16px

### 4.3 组件状态

- **默认态**：输入框、复选框未选中
- **选中态**：复选框选中、菜单项高亮
- **悬停态**：按钮、菜单项背景变化
- **禁用态**：开始检测按钮在条件不满足时禁用
- **错误态**：股东范围输入校验失败时标红
