# 资格审查条件配置页面

## 页面概述

运营解决方案配置子页面，用于配置不同采购品类、采购类型和招标方式下的资格审查条件。

## 页面结构

- 左侧边栏：集采运营后台菜单
- 顶部信息栏：平台选择、机构编码、上级组织
- 面包屑导航：解决方案 > 运营解决方案配置
- 主体左右布局：
  - 左侧：展示内容筛选 + 搜索 + 树形列表
  - 右侧：Tab 内容区（方案配置 / 配置下发 / 功能说明 / 操作日志）
- 底部提交按钮

## 方案配置 Tab 内容

### 资格审查条件

- 全局开关：控制整个模块启用/禁用
- 参数说明：在对应品类及采购类型条件下，可配置供应商需要满足哪些资格审查条件
- 适用组织范围：本级 / 本下级

### 主表格

列定义：
1. 采购品类（多选下拉）
2. 采购类型&组织形式（多选下拉）
3. 招标方式&采购方式（多选下拉）
4. 强制使用（Switch）
5. AI智能推荐资审条件（Switch）
6. 是否只使用AI智能推荐资审条件（Switch）
7. 资格后审是否开启资审（Switch）
8. 资格后审是否开启符合性审查（Switch）
9. 操作（添加资格审查条件 / 删除行）

### 子表格（资格审查条件项）

每行主数据下可展开配置多个资审条件项：
1. 资格审查条件项（下拉选择：自定义、未在经营异常企业名单等）
2. 资格审查强度（下拉选择：强制条件、推荐条件等）
3. 资格审查条件名称（输入框/下拉）
4. 资格审查条件分类
5. 审查方式（如：人工）
6. 映射编码（输入框）
7. 是否强制使用（下拉选择，带问号提示）
8. 操作（删除）

## 交互说明

- 主表格支持新增/删除行
- 每行主数据支持添加多个资审条件子项
- 子表格支持新增/删除条件项
- 全局开关关闭时，整个表格区域隐藏
- 底部固定提交按钮
