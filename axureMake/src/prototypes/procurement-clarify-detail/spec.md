# 专业分包-简版澄清详情（含审批记录）

## 📋 业务与功能

### 1.1 核心目标
> 采购商（经办人）在集采工作台查看某条「简版澄清」的详细内容与审批流转情况。

页面面向采购方经办人，用于确认已提交的澄清内容（澄清说明、提问截止时间、自动延时、澄清附件）与当前审批进度（审批节点、审批人、处理时间、审批结果、审批耗时），并支持催办/分享、撤销申请等后续操作。

### 1.2 功能清单
- **页面标题区**：品类标签（专业分包）+ 澄清标题（测试简版澄清答疑）。
- **废除截止倒计时**：以「天 + 时:分:秒」数字框形式展示距废除截止剩余时间。
- **采购信息区**：采购编号、组织机构、采购方式、项目、品类、经办人。
- **澄清详情**：澄清说明、**是否设置提问截止时间**、**提问截止时间（是否设置=是时展示）**、**自动延时（只读展示）**、澄清附件（.xlsx）。
- **审批记录**：审批流名称、催办/分享、撤销申请，以及审批流转表格。

### 1.3 交互要点
- 「澄清详情」标题栏右侧折叠图标：点击 → 收起/展开澄清详情内容区。
- 「是否设置提问截止时间」：单选（是/否），默认「是」，用于演示两种分支；选择「否」时，下方的「提问截止时间 + 自动延时」整块隐藏，不展示。
- 「提问截止时间」：**只读态**，以文本形式展示已设置的截止时间（`YYYY-MM-DD HH:mm:ss`），不提供编辑入口；仅当「是否设置提问截止时间」为「是」时展示。
- 「自动延时」：**只读态**，以禁用复选框展示勾选状态，右侧「审批通过后 N 天」以文本展示，均不可编辑。
- 「审批记录」标题栏右侧「切换样式」：点击 → 切换审批记录展示样式（原型中仅提供入口，不做实际切换）。
- 「审批记录」标题栏右侧折叠图标：点击 → 收起/展开审批记录内容区。
- 「催办/分享」：触发催办或分享审批（原型中为静态入口）。
- 「撤销申请」：触发撤销当前澄清申请（原型中为静态入口）。
- 自动延时问号图标：鼠标悬停 → 展示自动延时最终截止时间的计算规则说明。

## 📊 内容规划

### 2.1 信息架构

```
专业分包-简版澄清详情（含审批记录）
├── 页头区
│   ├── 品类标签 + 标题
│   ├── 距废除截止倒计时
│   └── 采购信息（4 列栅格）
└── 内容区
    ├── 澄清详情
    │   ├── 澄清说明
    │   ├── 是否设置提问截止时间（是/否）
    │   ├── 提问截止时间 + 自动延时（是否设置=是时展示）
    │   └── 澄清附件
    └── 审批记录
        ├── 审批流名称 + 操作按钮
        └── 审批流转表格
```

### 2.2 数据来源
> 数据源优先级：用户提供数据 > 项目数据表 > 生成示例数据

- **数据类型**：单据详情 + 审批流转记录
- **数据源**：用户提供的截图（页面文案与数值按截图还原）
- **关键字段**：
  - `category`：品类标签，如「专业分包」
  - `title`：澄清标题，如「测试简版澄清答疑」
  - `abolishCountdown`：距废除截止剩余时间（天 / 时 / 分 / 秒）
  - `purchaseNo` / `org` / `purchaseMode` / `project` / `categoryName` / `handler`：采购信息
  - `clarifyDesc`：澄清说明
  - `deadlineEnabled`：**是否设置提问截止时间**（单选，默认「是」；为「否」时隐藏提问截止时间与自动延时）
  - `questionDeadline`：**提问截止时间**（常量展示，口径与 `src/prototypes/procurement-qa` 一致，格式 `YYYY-MM-DD HH:mm:ss`）
  - `autoDelayEnabled` + `autoDelayDays`：**自动延时**（只读常量展示，勾选态 + 「审批通过后 N 天」）
  - `attachment`：澄清附件文件名
  - `flowName`：审批流名称
  - `approvalRows`：审批节点列表（审批层级、审批人、审批人信息、处理时间、审批结果、审批耗时、审批意见）

### 2.3 内容示例
- 澄清说明：123；澄清附件：斯里兰卡卢比_资审结果导入.xlsx
- 是否设置提问截止时间：是（切换为「否」时，提问截止时间与自动延时整块隐藏）
- 提问截止时间：2026-10-20 18:00:00；自动延时：审批通过后 2 天
- 审批流名称：FETEST-澄清提问简版
- 审批节点：开始节点（奥巴马，已提交，0 秒）→ 一级审批（admin1，审核中，28 分钟）→ 流程结束（系统，未结束）

## 🎨 布局与结构

### 3.1 整体布局
> 布局模式（单栏/双栏/网格/自由）、模块尺寸、比例约束

- **布局模式**：集采工作台框架 + 单栏内容区（顶部导航 + 左侧菜单 + 主内容区）
- **容器宽度**：流式
- **关键尺寸**：
  - 布局框架：顶部导航 56px，侧边栏默认收起为 64px（与截图一致）
  - 页头区：白底，标题行与倒计时/信息行之间以 1px 分割线分隔
  - 采购信息：4 列栅格，行间距 12px
  - 内容区：白底连续容器，内嵌「澄清详情」「审批记录」两个带 1px 边框的区块，间距 12px

### 3.2 响应式适配
> （如适用）断点、适配策略

- **桌面端（≥1200px）**：采购信息 4 列；审批表格完整展示 7 列
- **平板端（768-1199px）**：采购信息降为 2 列；审批表格横向滚动
- **移动端（<768px）**：侧边栏仅剩图标；采购信息单列；表格横向滚动

## 🎨 视觉规范

### 4.1 设计规范来源

**设计规范来源**：内置 interface-design

**说明**：设计令牌（Design Tokens）沿用 `src/components/centralized-procurement-layout` 集采工作台布局与 `src/prototypes/procurement-qa` 的既有视觉口径。

### 4.2 自定义设计要点

**自定义色彩**：
- `#1890ff`：主色（品类标签、倒计时数字框、标题竖条、链接、主按钮）
- `#333`：自动延时规则气泡底色（配合 `rgba(255,255,255,0.92)` 文字，保证不透明可读）
- `#fa8c16`：审批结果「审核中」文字色
- `#ff4d4f`：撤销申请按钮文字色
- `#3a7fc3`：布局侧边栏底色（复用布局组件）

**自定义尺寸**：
- 倒计时数字框：高 24px，最小宽 32px，1px 主色边框
- 是否设置提问截止时间：单选按钮（是/否），字号 14px，与表单标签同行展示
- 提问截止时间：只读文本，14px、`#333`，与自动延时控件同行展示
- 自动延时：只读禁用复选框（保持主色勾选外观）+ 只读文本天数，字体 14px、`#333`
- 自动延时规则气泡：最大宽度 420px，不透明深色底、浅色文字，避免与底层页面内容相互干扰
- 审批人标签：圆角胶囊，白字蓝底
- 审批表格：表头 `#fafafa` 底、单元格上下内边距 17px

### 4.3 组件状态

- **默认态（default）**：区块与表格正常展示
- **悬停态（hover）**：链接文字下划线、蓝色按钮加深、折叠图标变主色
- **聚焦态（focus）**：按钮保持 antd 默认聚焦态
- **禁用态（disabled）**：本期无禁用元素
