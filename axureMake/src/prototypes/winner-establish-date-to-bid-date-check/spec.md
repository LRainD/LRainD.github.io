# 中标人成立日期到开标日期过短（规则页迭代）

> 本文档仅记录**本次迭代**的新增内容，供研发评审使用。页面整体结构、左侧规则树、公共配置项、明细表格的公共列等通用能力均由组件 [risk-rule-config-page](file:///Users/liurundong/Desktop/云端演示项目/LRainD.github.io/axureMake/src/components/risk-rule-config-page/index.tsx) 提供，不在本文展开。

## 一、迭代目标

在风控预警中心「规则管理」下新增一条规则页：**校验中标人成立日期到开标日期的间隔天数是否过短**，间隔天数低于设置的阈值天数时触发预警/拦截，并支持个性化设置阈值天数。

## 二、规则信息

| 项 | 值 |
|----|----|
| 规则名称 | 中标人成立日期到开标日期过短 |
| 规则说明 | 校验中标人成立日期到开标日期的间隔天数，低于阈值天数将会预警/拦截 |
| 默认开关 | 开 |
| 挂载位置 | 规则树「招投标」分组，默认选中本规则 |
| 规则 key | `winner_establish_date_check` |

## 三、专有配置列（本次迭代重点）

在明细表格公共列之后追加 1 个必填列：

### 1. 阈值天数

- 控件：`InputNumber` 数字输入框（`suffix` 设置单位「天」）
- 约束：整数、最小值 0、`precision={0}`、步长 1（不可输入小数与非数字字符）
- 业务含义：支持个性化参数设置，中标人**成立日期到开标日期的间隔天数低于该阈值**时触发预警/拦截
- 默认值：空

## 四、规则配置项取值

本次迭代沿用组件公共配置项，取值如下（供评审确认）：

| 配置项 | 取值 |
|--------|------|
| 适用组织范围 | 本下级 |
| 下级独立配置 | 不允许 |
| 预警级别 | 中风险 |
| 是否去重 | 不去重 |
| 规则类型 | 合规风险 |

## 五、接入方式

整页复用 `RiskRuleConfigPage`，本次仅传入以下规则差异项：

| Prop | 值 |
|------|----|
| `ruleName` | 中标人成立日期到开标日期过短 |
| `ruleDescription` | 校验中标人成立日期到开标日期的间隔天数，低于阈值天数将会预警/拦截 |
| `defaultRuleEnabled` | `true` |
| `config` | 见上表 |
| `extraColumns` | 阈值天数 1 列 |
| `treeData` | 组件默认规则树 + 「招投标」分组追加本规则 |
| `defaultSelectedRuleKey` | `winner_establish_date_check` |
| `tableScrollX` | `1480` |
